# NRWの小学校入学2027/28｜対象年齢・申込期限・デュッセルドルフとケルンの手続き

ノルトライン＝ヴェストファーレン州（NRW）では、2027/28年度に小学校へ入る子どもの対象年齢と、入学前の登録時期が法律と自治体の案内で決まっています。2027/28年度の原則対象は、2020年10月1日から2021年9月30日までに生まれた子どもです。ここでは、デュッセルドルフとケルンの公式日程を分け、2026年11月12日時点で何を確認し、期限が近い家庭はどう動けばよいかを整理します。

## まず確認：2027/28年度の対象になる子ども

NRW州学校法では、州内に住所または通常の居所がある人を就学義務の対象とし、外国籍の子どもも同条の条件を満たす場合は対象に含めています。6歳の誕生日を迎える時期により、2027/28年度の扱いは次のように分かれます。

| 生年月日 | 2027/28年度の扱い |
| --- | --- |
| 2020年10月1日〜2021年9月30日 | 原則として2027年8月1日から就学義務が始まる |
| 2021年10月1日以降 | 保護者が早期入学を申請できる。就学準備が整っているかを学校が判断する |
| 2020年9月30日以前 | 原則として2026/27年度以前の対象。すでに就学しているか、健康上の理由による延期など個別事情を確認する |

根拠はNRW州学校法第34条・第35条です。第35条では、9月30日までに6歳になる子どもの就学義務が、その年の8月1日に始まると定めています。したがって、2027年に6歳になる子ども全員が同じ年度に入学するわけではありません。誕生日が2021年10月1日以降なら、原則の対象年度はその次です。

### 早く入学させたい場合・1年延期したい場合

2021年10月1日以降に生まれた子どもは、保護者が早期入学を申請できます。ただし、申請しただけで入学が決まるわけではありません。身体面・知的面・社会面で学校生活に必要な準備が整っているかを学校が判断し、学校医の意見も考慮します。

反対に、就学義務のある子どもを1年延期できるのは、重大な健康上の理由がある場合です。学校長が学校医の報告をもとに判断し、保護者の意見も聞きます。単に「もう1年、保育施設（Kita）に通わせたい」という希望だけで自動的に延期できる制度ではありません。

## 申込期限は州内で完全に同じではない

NRW州の法律そのものが、すべての自治体について同じ予約日を定めているわけではありません。自治体や学校の案内で登録日が指定されるため、住んでいる市の通知と希望する学校の情報を確認してください。

デュッセルドルフ市は、翌年9月30日までに6歳になる子どもの登録を11月15日までに済ませるよう案内しています。2027/28年度の指定日程はすでに終了しているため、まだ登録していない家庭は、11月15日を待たずに希望校へ連絡してください。

## デュッセルドルフ：指定日は2026年10月6〜8日

デュッセルドルフ市が2026年9月22日に公表した2027/28年度の登録時間は次のとおりです。

| 日付 | 受付時間 |
| --- | --- |
| 2026年10月6日（火） | 15:00〜18:00 |
| 2026年10月7日（水） | 11:00〜13:00、15:00〜18:00 |
| 2026年10月8日（木） | 11:00〜13:00 |

対象は2020年10月1日〜2021年9月30日生まれの子どもです。登録は、入学を希望する小学校で行います。学校を自由に選べる一方、希望校の定員を超える場合は必ずしも第一希望に入れるとは限りません。市のFAQでは、申込先は1校のみと案内されています。

**指定日を逃した場合**は、希望校に電話して個別の登録日時を相談してください。市のFAQは、指定日に都合がつかない場合も学校に連絡し、個別の登録日時を取るよう案内しています。ただし、登録が自動的に認められるわけではないため、できるだけ早く連絡してください。市の案内上の期限は11月15日です。

- 担当窓口：デュッセルドルフ市 学校・教育担当
- 電話：0211 89 24080

## ケルン：2026年10〜11月に登録する日程

ケルン市が公開している「入学前の重要日程」では、2027年9月入学に向けて、2026年9月に市から登録案内を送り、10〜11月に小学校で登録する予定を示しています。その後の流れは次のとおりです。

| 時期 | ケルン市の案内にある予定 |
| --- | --- |
| 2026年9月 | 市から小学校登録の案内を送付 |
| 2026年10〜11月 | 小学校で登録 |
| 2026年11〜12月 | 一部の子どもの学校医による早期検査 |
| 2027年1〜5月 | 学校医による入学前検査 |
| 2027年3月以降 | 学校から入学許可の通知 |
| 2027年6月 | 学校との顔合わせ行事 |
| 2027年9月 | 入学・初登校 |

注意したいのは、ケルン市の個別手続きページが2026年11月12日時点ではまだ2026/27年度の説明を表示していることです。同ページにある「2025年11月15日」という前年度の期限を、2027/28年度の期限として使わないでください。2027/28年度の正確な締切や予約方法は、市の入学担当に確認してください。

- 電話：0221 221-30199
- メール：einschulung@stadt-koeln.de
- [ケルン市の入学前日程PDF](https://www.stadt-koeln.de/mediaasset/content/pdf40/Regionale-Bildungslandschaft/einschulung-fahrplan-termine.pdf)

ケルン市の現行ページ（2026/27年度向け）には、出生証明書または家族手帳、保護者の身分証明書、市から届いた通知と記入済み申込書、麻しん（はしか）対策の証明が必要書類として掲載されています。宗教系の学校に申し込む場合は、洗礼証明書も案内されています。申込書は親権者全員の署名が必要とされています。これは前年度のページに掲載された情報なので、2027/28年度の書類一覧は新しい案内で再確認してください。

## 日本人家庭が準備しておきたいもの

自治体や学校で違いがあるため、次の一覧は準備用です。最終的には市から届いた通知と希望校の案内を優先してください。

- 子どもの出生証明書、または自治体が指定する家族関係の書類
- 保護者の身分証明書
- 市から届いた入学案内と申込書
- 麻しん（はしか）の予防接種・免疫などを示す証明
- 親権者全員の署名。単独親権など事情がある場合は、学校に必要な証明を確認
- 早期入学を希望する場合は、申請方法と学校医の確認方法

市から案内が届かない、転居直後で住所情報が反映されていない、申込書を紛失した、といった場合も、自己判断で待たずに学校または市の担当窓口へ連絡してください。

## ドイツ語がまだ十分でない子どもは？

NRW州学校法第36条では、小学校への登録時に、学校が子どものドイツ語力と学習の基礎を確認することを定めています。授業に参加するためのドイツ語力が十分でないと判断された場合、入学前年度に言語能力を伸ばすための事前コースへの参加を求められることがあります。

これは、外国籍の子どもを学校から除外するための仕組みではなく、入学後に授業へ参加できるよう準備するためのものです。家庭で日本語を使っていても、就学前の言語確認や支援の対象になる可能性があります。通知が届いたら、実施場所、曜日、期間、Kitaとの両立を学校に確認してください。

また、NRW州に住所や通常の居所がある子どもは、国籍にかかわらず州法上の就学義務の対象となる場合があります。日本人学校やインターナショナルスクールを選ぶ予定なら、その学校への通学がNRW州の就学義務を満たす扱いになるかを必ず学校監督当局に確認してください。外国の学校・国際学校なら自動的に認められるとは限りません。

## 学校医の検査と全日保育は別に確認する

入学前の学校医による検査は、学校への登録とは別の手続きです。ケルン市の案内では2027年1〜5月に検査を行う予定です。デュッセルドルフ市は登録後に健康局から案内を送るとしており、検査日が夏休み近くになる場合もあります。案内が届かない場合は、自治体の健康局に確認してください。

放課後の全日保育（Ganztag）は、学校への入学手続きと申込方法が異なる場合があります。NRW州の制度とデュッセルドルフの時間帯別モデルは、[NRWで小学1年生の全日保育が権利に](/germany/ja/events/news/ganztag-primary-school-nrw-2026/)で確認できます。学校選び全体は[ドイツで子どもの学校をどう選ぶ？](/germany/ja/living/schools-germany-japanese-families/)、休暇の日程は[NRWの学校休暇2026/27年度](/germany/ja/living/nrw-school-holidays-2026-2027/)も参考になります。

## よくある質問

### 2027/28年度の対象は、2021年生まれの子ども全員ですか？

いいえ。原則対象は2020年10月1日〜2021年9月30日生まれです。2021年10月1日以降に生まれた子どもは、通常は次の年度が対象ですが、早期入学を申請できます。

### 11月15日を過ぎたら、もう登録できませんか？

自治体の案内と個別事情によります。デュッセルドルフ市は指定日に都合がつかない場合、学校に連絡して個別の登録日時を相談するよう案内しています。期限後の扱いを推測せず、すぐに希望校と市の担当窓口へ連絡してください。

### 日本国籍なら日本人学校に通えばよいですか？

日本国籍だけでドイツの就学義務がなくなるわけではありません。NRW州に住所または通常の居所がある場合は州法の対象になる可能性があるため、日本人学校や国際学校で就学義務を満たせるか、学校監督当局に確認してください。

### 申し込みは複数の小学校に出せますか？

自治体の手続きによります。デュッセルドルフ市とケルン市の現行案内は、申込先を1校とする説明を掲載しています。希望順位や第二希望の書き方は、住んでいる市の最新フォームを確認してください。
