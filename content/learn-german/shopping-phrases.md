# 買い物で使うドイツ語｜スーパー・レジ・返品で役立つフレーズ

ドイツでの買い物は、セルフサービスだけで終わらず、パン・肉の量を伝える、青果を量る、Pfandを返す、レジで支払方法を答える、返品理由を説明する場面があります。

長い文は不要です。**探している物＋必要な量・条件＋確認したいこと**の順で伝えれば、短いドイツ語で対応できます。

## まず覚える10文

| 目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 探す | Wo finde ich [商品]? | [商品]はどこにありますか。 |
| 在庫 | Haben Sie das noch vorrätig? | これはまだ在庫がありますか。 |
| 値段 | Wie viel kostet das? | これはいくらですか。 |
| 別サイズ | Gibt es das auch in einer anderen Größe? | 別のサイズもありますか。 |
| 手伝い | Könnten Sie mir bitte helfen? | 手伝っていただけますか。 |
| 袋不要 | Ich brauche keine Tüte, danke. | 袋は要りません。 |
| カード | Ich möchte mit Karte zahlen. | カードで支払いたいです。 |
| レシート | Könnte ich bitte den Kassenbon bekommen? | レシートをいただけますか。 |
| 返品 | Ich möchte diesen Artikel zurückgeben. | この商品を返品したいです。 |
| 不良 | Der Artikel ist leider defekt. | 残念ですが、この商品は不良です。 |

## 商品を探す

| 場面 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 場所 | Wo finde ich Hafermilch? | オーツミルクはどこにありますか。 |
| 売場 | In welcher Abteilung finde ich das? | どの売場にありますか。 |
| 商品名不明 | Ich suche so etwas. | このような物を探しています。 |
| 写真を見せる | Haben Sie ein ähnliches Produkt? | 似た商品はありますか。 |
| 在庫切れ | Ist das ausverkauft? | 売り切れですか。 |
| 入荷 | Wann ist es wieder verfügbar? | いつ再入荷しますか。 |
| 他店舗 | Gibt es das in einer anderen Filiale? | 別店舗にはありますか。 |
| オンライン | Kann ich das online bestellen? | オンラインで注文できますか。 |

商品写真を見せる場合は、`Ich suche genau dieses Produkt.`（まさにこの商品を探しています）と添えます。

## 商品ラベル・成分を確認する

| 確認 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 砂糖なし | Ist das ohne Zuckerzusatz? | 砂糖不使用ですか。 |
| 乳糖なし | Ist das laktosefrei? | 乳糖不使用ですか。 |
| グルテン | Ist das glutenfrei? | グルテンフリーですか。 |
| 動物性原料 | Ist das vegan oder vegetarisch? | ヴィーガンまたはベジタリアンですか。 |
| アレルゲン | Enthält das [成分]? | [成分]が含まれていますか。 |
| 痕跡 | Kann das Spuren von Nüssen enthalten? | ナッツが微量に含まれる可能性がありますか。 |
| 使用期限 | Wo finde ich das Mindesthaltbarkeitsdatum? | 賞味期限はどこにありますか。 |
| 消費期限 | Ist das noch bis [日付] zu verbrauchen? | [日付]までに消費する商品ですか。 |
| 調理方法 | Wie wird das zubereitet? | これはどう調理しますか。 |

強いアレルギーがある場合は、店員の口頭説明だけでなく、包装の原材料・アレルゲン表示を自分でも確認します。

## スーパーの青果・量り売り

店舗によって、野菜や果物を自分で量ってラベルを貼る方式と、レジで計量する方式があります。

使える質問：

- `Muss ich das selbst wiegen?`（自分で量る必要がありますか）
- `Welche Nummer muss ich an der Waage eingeben?`（秤にどの番号を入力しますか）
- `Wird das an der Kasse gewogen?`（レジで量りますか）
- `Kann ich davon auch nur eine kleine Menge nehmen?`（少量だけ取ってもよいですか）

`lose Ware`はばら売り、`pro Stück`は1個あたり、`pro Kilogramm`は1kgあたりです。価格表示の単位を確認します。

## パン屋・肉売場で量を頼む

### パン屋

| 注文 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 1個 | Ein Brötchen, bitte. | パンを1個お願いします。 |
| 2個 | Zwei von diesen Brötchen, bitte. | このパンを2個お願いします。 |
| 指差し | Ich nehme das hier, bitte. | これをお願いします。 |
| スライス | Könnten Sie das Brot bitte schneiden? | パンを切っていただけますか。 |
| 持ち帰り | Zum Mitnehmen, bitte. | 持ち帰りでお願いします。 |

### 肉・チーズ売場

| 注文 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 200g | Zweihundert Gramm davon, bitte. | それを200gお願いします。 |
| 4枚 | Vier Scheiben, bitte. | 4枚お願いします。 |
| 薄く | Bitte dünn geschnitten. | 薄切りでお願いします。 |
| 少なめ | Etwas weniger, bitte. | もう少し少なくお願いします。 |
| それでよい | Ja, das passt so. | はい、その量で大丈夫です。 |

聞き返されたら、数字だけでなく単位も繰り返します。

## Pfandを返す

Pfand対象のボトル・缶は、店内の返却機へ入れ、`Pfandbon`を受け取ってレジで精算します。

| 場面 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 返却機 | Wo ist der Pfandautomat? | ボトル返却機はどこですか。 |
| 読取不可 | Der Automat nimmt diese Flasche nicht an. | 機械がこのボトルを受け付けません。 |
| 店員へ | Können Sie bitte prüfen, ob die Flasche hier zurückgegeben werden kann? | この店で返却できるか確認してもらえますか。 |
| 券 | Ich möchte diesen Pfandbon einlösen. | このPfand券を使いたいです。 |
| 現金 | Kann der Pfandbetrag ausgezahlt werden? | Pfand分を現金で受け取れますか。 |

すべての容器がすべての店で返却できるとは限りません。機械が拒否したら無理に押し込まず、店員へ確認します。

## レジでよく聞かれること

| 店員の表現 | 意味 | 答え方 |
| --- | --- | --- |
| Haben Sie eine Kundenkarte? | 会員カードはありますか。 | `Nein, danke.` / `Ja, hier.` |
| Sammeln Sie Punkte? | ポイントを集めていますか。 | `Nein, danke.` |
| Möchten Sie eine Tüte? | 袋は必要ですか。 | `Ja, bitte.` / `Nein, danke.` |
| Bar oder mit Karte? | 現金ですか、カードですか。 | `Mit Karte, bitte.` |
| Möchten Sie den Kassenbon? | レシートは必要ですか。 | `Ja, bitte.` |
| Haben Sie die App? | アプリはありますか。 | `Nein.` / `Ja.` |

### 会計の短い会話

**Kasse:** Haben Sie eine Kundenkarte?

**Ich:** Nein, danke.

**Kasse:** Möchten Sie eine Tüte?

**Ich:** Nein, danke. Ich habe eine Tasche dabei.

**Kasse:** Bar oder mit Karte?

**Ich:** Mit Karte, bitte. Und den Kassenbon hätte ich gern.

## カード・現金・支払いエラー

| 状況 | ドイツ語 | 日本語 |
| --- | --- | --- |
| カード可否 | Kann ich mit Karte zahlen? | カードで払えますか。 |
| タッチ | Kann ich kontaktlos zahlen? | タッチ決済できますか。 |
| 暗証番号 | Muss ich die PIN eingeben? | PIN入力が必要ですか。 |
| エラー | Die Zahlung wurde abgelehnt. Können wir es noch einmal versuchen? | 支払いが拒否されました。もう一度試せますか。 |
| 別カード | Ich nehme eine andere Karte. | 別のカードを使います。 |
| 現金 | Ich zahle bar. | 現金で払います。 |
| 高額紙幣 | Können Sie einen Fünfzig-Euro-Schein wechseln? | 50ユーロ札を崩せますか。 |
| 二重請求 | Wurde der Betrag zweimal abgebucht? | 金額が2回引き落とされましたか。 |

決済端末に `Vorgang abgebrochen`、`Zahlung abgelehnt`と表示された場合、アプリや銀行口座の最終状態も確認します。同じ支払いを繰り返す前に、レジで決済成立の有無を確認してください。

## セルフレジで困ったとき

- `Der Artikel lässt sich nicht scannen.`（商品をスキャンできません）
- `Ich habe den Artikel aus Versehen zweimal gescannt.`（誤って2回スキャンしました）
- `Wie löse ich den Pfandbon ein?`（Pfand券はどう使いますか）
- `Die Altersfreigabe muss bestätigt werden.`（年齢確認が必要と表示されています）
- `Könnten Sie den Artikel bitte entfernen?`（この商品を削除していただけますか）
- `Der Automat gibt keinen Beleg aus.`（機械からレシートが出ません）

店員の承認が必要な画面では、自分で別メニューを何度も押さず、`Ich brauche bitte Hilfe an der Selbstbedienungskasse.`（セルフレジで助けが必要です）と呼びます。

## 返品・交換・不良品

まず、理由を区別します。

| 状況 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 返品希望 | Ich möchte diesen Artikel zurückgeben. | この商品を返品したいです。 |
| 交換希望 | Ich möchte den Artikel umtauschen. | この商品を交換したいです。 |
| 不良 | Der Artikel ist defekt. | 商品が不良です。 |
| 部品不足 | Ein Teil fehlt. | 部品が一つ足りません。 |
| 動作しない | Das Gerät funktioniert nicht. | 機器が動作しません。 |
| サイズ不適 | Die Größe passt nicht. | サイズが合いません。 |
| 誤商品 | Ich habe den falschen Artikel erhalten. | 違う商品を受け取りました。 |
| レシート | Ich habe den Kassenbon dabei. | レシートを持っています。 |
| 返金 | Wird der Betrag auf meine Karte zurückgebucht? | カードへ返金されますか。 |
| 修理 | Kann der Artikel repariert werden? | 商品を修理できますか。 |

実店舗で「気が変わった」「サイズが合わない」という返品は、店の方針や任意対応（Kulanz）による場合があります。一方、不良品は別の扱いです。このページでは法的結論を断定せず、店員へ次の選択肢を確認します。

> Welche Möglichkeiten habe ich: Rückgabe, Umtausch oder Reparatur?
> 返品、交換、修理のどの選択肢がありますか。

## 価格表示・セールを確認する

| 表示・質問 | 日本語 |
| --- | --- |
| Ist der Rabatt schon im angezeigten Preis enthalten? | 割引は表示価格に含まれていますか。 |
| Gilt das Angebot nur mit der App? | この特売はアプリ利用時だけですか。 |
| Gilt der Preis pro Stück oder pro Packung? | 価格は1個あたりですか、1パックあたりですか。 |
| Der Preis an der Kasse ist höher als am Regal. | レジ価格が棚の表示より高いです。 |
| Könnten Sie den Preis bitte prüfen? | 価格を確認していただけますか。 |
| Ist dieser Gutschein noch gültig? | このクーポンはまだ有効ですか。 |

セール条件に `ab 2 Stück`（2個から）、`nur diese Woche`（今週のみ）、`mit Kundenkarte`（会員カード利用時）のような制限がないか確認します。

## 会話例：不良品を返す

**Ich:** Guten Tag. Ich möchte diesen Artikel reklamieren.

**Mitarbeiterin:** Was ist das Problem?

**Ich:** Das Gerät lässt sich nicht einschalten. Ich habe es gestern gekauft und den Kassenbon dabei.

**Mitarbeiterin:** Möchten Sie einen Austausch?

**Ich:** Ja, bitte. Falls das nicht möglich ist, möchte ich wissen, ob der Betrag zurückerstattet werden kann.

## よくある失敗

### `umtauschen`と`zurückgeben`を区別しない

- `umtauschen`：別商品・別サイズなどへの交換
- `zurückgeben`：商品を返す
- `reklamieren`：不良・問題を申し出る

希望する結果を言い分けます。

### 単位を言わない

`zwei`だけでなく、`zwei Stück`、`zweihundert Gramm`、`zwei Packungen`まで伝えます。

### レシートをすぐ捨てる

返品可能期間、保証、経費精算などで必要になるため、少なくとも商品を確認するまでは保管します。

### アレルギー情報を店員の記憶だけに頼る

包装表示や公式製品情報を自分でも確認し、不明なら購入を急がないようにします。
