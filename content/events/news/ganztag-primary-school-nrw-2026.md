# NRWで小1の全日保育が権利に｜2026年8月開始のOGSを保護者向けに解説

2026年8月1日から、ドイツで小学1年生の子どもに **ganztägige Förderung（全日保育・教育）を受ける法的権利** が始まりました。NRWでは、主にOffene Ganztagsschule（OGS）やHort、自治体が認める休暇プログラムなどを通じて提供されます。

これは、Kita卒園後に「授業は昼すぎに終わるのに、親の勤務は続く」という保育の空白を減らす重要な制度です。一方で、権利が始まったからといって、希望校のOGS席が自動的に割り当てられるわけではありません。**申込み、利用時間、休暇中の会場、費用、送迎を家庭ごとに確認する作業は残ります。**

この記事では、制度の意味だけでなく、入学前・在学中に何を確認し、満席と言われたときに誰へ何を聞くかまで順番に整理します。

## まず結論：家庭が押さえる6点

1. 2026/27学年度は、まず小学1年生が法的権利の対象
2. 原則1日8時間には授業時間も含まれ、授業後8時間という意味ではない
3. 権利は特定の一校・一施設・希望時間帯の席を必ず保証するものではない
4. 学校休暇中も対象だが、普段のOGSと別会場・別運営者になる場合がある
5. OGS利用料、昼食費、減免条件は自治体等により異なり、全国一律無料ではない
6. 口頭で「満席」と言われたら、正式申請・書面決定・代替案・期限を確認する

## 誰がいつ対象になる？

対象は学年ごとに段階的に広がります。

| 学年度 | 権利の対象となる学年 |
| --- | --- |
| 2026/27 | 小学1年生 |
| 2027/28 | 小学1〜2年生 |
| 2028/29 | 小学1〜3年生 |
| 2029/30 | 小学1〜4年生 |

連邦政府は、この権利は利用義務ではなく、保護者が利用するか、どの程度利用するかを選べると説明しています。家庭で対応できる日まで毎日OGSへ通わせなければならない制度ではありません。ただし、実際のOGS契約では一定の参加日数や退室時刻が定められることがあるため、**権利上の選択と施設の運営ルールは別に確認**します。

転校、飛び級、留年、特別支援学校、州をまたぐ引越し、学年度途中の入学などがある場合は、学校だけで判断せず、居住自治体のJugendamtまたはGanztag担当へ対象学年と担当機関を確認してください。

## 「1日8時間」を生活時間に置き換える

権利は原則として平日1日8時間を対象とし、授業時間も含まれます。たとえば8時に授業が始まるなら、単純計算では16時ごろまでが8時間の範囲です。通勤、引取り、延長時間は別に考える必要があります。

| 家庭の状況 | 確認すべき不足時間 |
| --- | --- |
| 8:00〜16:00勤務、通勤片道45分 | 朝の受入れ開始と16時以降の延長 |
| 早番が7:00開始 | Frühbetreuung（早朝保育）の有無 |
| 遅番・シフト勤務 | 17時以降、曜日変更、緊急時引取り |
| 在宅勤務あり | 利用曜日の固定・変更条件 |
| 習い事あり | 早退できる曜日・引渡し方法 |
| 兄弟が別施設 | 引取り順と代理人登録 |

「8時間の権利があるのでフルタイム勤務をすべてカバーできる」と決めつけず、玄関を出る時刻から職場を出て子どもを迎える時刻まで、15分単位で一度書き出すと不足が見えます。

## 学校休暇中はどうなる？

学校休暇中も権利の対象です。ただし、普段のOGSが全休暇期間を同じ場所・同じ職員で開くとは限りません。2026年8月からは、自治体等が公的または認定された青少年活動団体のFerienangebot、スポーツキャンプ、別校の合同保育などを組み合わせて権利を満たすこともできます。

NRWでは閉所期間が設定される場合があるため、少なくとも次を年間カレンダーへ入れます。

- OGSの閉所週
- 代替プログラムの申込開始日と定員
- 送迎先・集合時刻・終了時刻
- 昼食・水筒・服装・薬の扱い
- 参加費、キャンセル、きょうだい割引
- 家庭の休暇、勤務先の休業日、Homeoffice可能日

休暇保育は「権利があるから直前でも入れる」とは限りません。通常のOGSとは別申込みになる場合があるため、秋休み・クリスマス休暇・復活祭休暇・夏休みの順に、募集時期を年度初めに確認します。

## OGSとは：`offen` の誤解に注意

Offene Ganztagsschuleは、通常授業の後に昼食、宿題・学習支援、自由遊び、スポーツ、音楽、創作活動などを組み合わせる仕組みです。`offen` は「契約後も好きな時間に自由に出入りできる」という意味ではありません。

確認したい運営ルールは次のとおりです。

- 週何日以上の参加が必要か
- 通常の退室時刻と例外的な早退条件
- 保護者以外が迎える場合の登録方法
- 子どもが一人で帰宅できる年齢・同意書
- 宿題支援の範囲と、家庭で残る学習
- 昼食のアレルギー・宗教・菜食対応
- 投薬、吸入器、緊急薬の保管方法
- 欠席・病欠連絡を学校とOGSの両方へ送るか
- 学級閉鎖、教員研修日、短縮授業日の扱い

見学できる場合は、部屋や遊具だけでなく、子どもの人数、職員配置、静かに休める場所、屋外活動、宿題の進め方、保護者への連絡方法も確認します。

## 入学前年からの申込み手順

自治体ごとに順序は異なりますが、家庭では次の流れで漏れを防げます。

### 1. 担当窓口を確定する

学校、OGS運営者、Schulverwaltungsamt、Jugendamt、自治体オンラインポータルのどこが正式申請先かを確認します。説明会で希望を伝えただけでは正式申請にならない場合があります。

### 2. 締切と必要書類を一覧にする

入学申込みとOGS申込みの締切は同じとは限りません。就労証明、勤務時間、ひとり親であること、兄弟在籍、特別支援ニーズなど、優先順位判断に使う資料が必要かも確認します。

### 3. 受領記録を残す

オンライン送信完了画面、受付番号、メール、提出書類の写しを保存します。紙で出す場合は、受付印のあるコピーまたは受領メールを求めます。

### 4. 契約条件を読む

利用開始日、曜日、退室時刻、費用、昼食、解約・変更期限、休暇中の扱いを確認します。学校入学の決定とOGS契約は別の通知になることがあります。

### 5. 入学前に一日の動線を試す

自宅から学校、職場、引取り場所まで実際の時刻に移動し、渋滞・鉄道遅延・駐車・自転車置場を含めて余裕を見ます。

## 費用：請求を四つに分けて確認

法的権利が始まっても、すべて無料になるとは限りません。請求は次の四つに分けると理解しやすくなります。

| 費用 | 確認ポイント |
| --- | --- |
| 保護者負担金 | 所得区分、兄弟減免、ひとり親、変更時の再計算 |
| 昼食費 | 1食制・月額制、欠席時返金、アレルギー対応 |
| 休暇プログラム | 通常料金に含むか、別料金・材料費があるか |
| 追加活動 | 遠足、クラブ、送迎、教材の任意費用 |

所得証明を出さない場合に最高区分で暫定請求されることもあるため、提出期限と後日の精算可否を確認します。`beitragsfrei` と書かれていても昼食費等は別の場合があります。

## 満席・不承認と言われたときの動き方

口頭で「満席です」と言われたら、感情的に争う前に、何がまだ手続き上確定していないかを分けます。

1. 正式な申請が受理されているか
2. 単なる事前案内か、正式な不承認決定か
3. 決定を出す機関は学校・運営者・自治体のどこか
4. 待機リストの有無と連絡方法
5. 別校、別施設、Tagespflege、Ferienangebot等の代替案
6. 通学・送迎上、その代替案が家庭にとって利用可能か
7. 書面決定、理由、問い合わせ先、救済手続きの期限

法的権利は、希望する一つのOGS施設そのものに対する保証とは限りません。自治体が別の適切な提供方法を示すことがあります。ただし、遠距離、開始・終了時刻、障害・医療ニーズ、兄弟の送迎などで実際に利用困難なら、その事情を数字と書類で具体的に伝えます。

正式通知に `Rechtsbehelfsbelehrung`（不服申立て等の案内）がある場合は、記載された期限を優先してください。個別案件は自治体の相談窓口、Familienbüro、必要に応じて専門家へ相談します。

申請の受領、検討される代替案、不承認時の理由と救済手続き案内を文書で求める表現です。

## 特別な事情がある家庭

### ひとり親・共働き・シフト勤務

勤務時間だけでなく、通勤を含む不在時間を伝えます。勤務証明が必要か、夜勤明け・不規則シフトをどう示すかを確認してください。

### 障害・慢性疾患・アレルギー

支援員、バリアフリー、緊急薬、食事、疲労時の休憩場所を入学前に学校・OGS双方と打ち合わせます。診断名だけでなく、「いつ、誰が、何をする必要があるか」を書面にします。

### ドイツ語がまだ十分でない家庭

通訳同伴の可否、やさしいドイツ語、書類の説明予約を依頼します。分からない契約へその場で署名せず、持ち帰って確認します。

### 学年度途中の引越し

転出先の学校決定とOGS席は別進行になり得ます。新旧自治体へ、利用終了日、費用精算、待機リスト、休暇中の空白を確認します。

## 最初の2週間に確認すること

- 子どもが退室場所と迎えの人を理解しているか
- 学校とOGSの欠席連絡先を保護者が登録したか
- 昼食を食べられているか、アレルギー対応に齟齬がないか
- 宿題のどこまでをOGSで行い、家庭で何を確認するか
- 疲れすぎていないか、利用日数・習い事を詰めすぎていないか
- 緊急連絡先と代理迎えの登録が正しいか
- 請求額と契約内容が一致しているか

制度上8時間利用できても、子どもにとって毎日長時間が最適とは限りません。仕事との両立だけでなく、本人の疲れ、友人関係、食事、宿題、自由時間を見て利用方法を調整します。

## まとめ

2026年8月開始の全日保育の権利は、小学校入学後の保育ギャップを減らす大きな前進です。しかし、**法的権利、希望校の席、契約時間、休暇中の会場、費用は同じ話ではありません。**

家庭では、入学前年から申込先と締切を確認し、1日8時間を実際の勤務・通勤時間へ置き換え、休暇中の代替と費用を年間表にします。満席と言われたときは、正式申請、書面決定、代替案、期限を順に確認してください。

入学前の保育探しは[Kita・U3・Tagesmutterガイド](/germany/ja/living/kita-u3-tagesmutter-guide/)、問い合わせ表現は[Kita・学校で使うドイツ語](/germany/ja/learn-german/kita-school-inquiry-phrases/)も参考になります。

この記事は制度の一般的な説明で、個別案件への法的助言ではありません。正式な決定、期限、救済手続きは自治体の通知と公式情報を確認してください。
