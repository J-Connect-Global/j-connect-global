# ドイツの子どもの健診U1〜U9｜受診時期、黄色い冊子、予防接種の確認

ドイツでは、出生直後から5歳ごろまでに、子どもの成長と発達を確認する定期健診U1〜U9が設けられています。日本から移住した家庭にとっては、受診時期、予約先、黄色い健診冊子、予防接種の記録が分かりにくいことがあります。この記事では、年齢ごとの受診時期、退院後に必要な予約、2026年からの変更、保育施設に提出する証明を分けて説明します。

## まず押さえたいポイント

- U1〜U9は、U7aを含む10回の健診です。出生直後から5歳ごろまで、決められた期間内に受診します。
- U2は生後3〜10日、U3は生後4〜5週です。自宅出産や早期退院で病院内のU2を受けていない場合は、退院後すぐに小児科へ連絡してください。
- 黄色い健診冊子には、2026年1月1日から歯科健診Z1〜Z6の結果も記録されます。保険者によっては電子版も利用できます。
- 保育施設の入園時に必要な予防接種相談の証明と、麻疹の接種・免疫証明は別の要件です。
- 2026年8月に決定された新しいU10は、2026年11月9日時点ではまだ発効していません。

## U1〜U9の受診時期

次の表は、連邦保健省と連邦公衆衛生研究所が案内する標準的な受診期間です。誕生日から逆算して予約し、期間を過ぎそうな場合は小児科と健康保険者に早めに相談してください。

| 健診 | 標準的な受診時期 | 主な確認内容 |
|---|---|---|
| U1 | 出生直後 | 呼吸、心拍、皮膚の色、全身状態など。出生直後に行う初回確認 |
| U2 | 生後3〜10日 | 頭から足先までの診察、感覚器や反射、新生児スクリーニングの実施状況 |
| U3 | 生後4〜5週 | 体重、反射、運動、飲み方・睡眠など。股関節の状態も確認 |
| U4 | 生後3〜4か月 | 成長、運動、感覚器、臓器、神経系の発達 |
| U5 | 生後6〜7か月 | 成長、運動、感覚器、日常生活の発達 |
| U6 | 生後10〜12か月 | 運動、言葉、視覚、周囲とのやり取りなど |
| U7 | 生後21〜24か月 | 言葉、細かな動き、視覚、体の動かし方 |
| U7a | 生後34〜36か月 | 言葉の発達、視覚など |
| U8 | 生後46〜48か月 | 言葉、発音、行動、協調運動、歯の状態など |
| U9 | 生後60〜64か月 | 就学前の運動、聴力・視力、言葉の発達など |

U1〜U9という呼び方ですが、U7とU8の間にU7aがあるため、実際には10回です。U1〜U3は新生児期から乳児期初期の確認が中心で、その後は運動、言葉、視覚、行動など、年齢に応じた発達の確認が増えていきます。

## U2とU3は退院後の予約が特に重要

### 病院で出産し、入院中にU2を受ける場合

U1は出生直後、U2は通常、生後3〜10日に行われます。多くの赤ちゃんはU2を出産した病院で受けます。退院前に、U2が実施済みか、血液検査や聴覚検査などの新生児スクリーニングが済んでいるかを確認してください。

### 自宅出産・外来出産・U2前の早期退院の場合

U2を病院で受けずに自宅へ戻った場合は、保護者が小児科などの診療所へ予約を取る必要があります。BIÖGは、新生児スクリーニングや聴覚検査が未実施なら、出生後1〜2日以内を目安に診療所へ連絡するよう案内しています。U2自体は遅くとも生後10日までの期間に受けることが基本です。

血液検査や聴覚検査は、病気を早く見つけるために実施時期が重要なものがあります。退院時に「後で予約すればよい」とだけ考えず、未実施の検査と担当先を確認してください。

### U3は小児科での最初の受診になることが多い

U3は生後4〜5週で、通常は小児科の診療所で受けます。出生後できるだけ早く、今後通う予定の診療所へ連絡し、U3の予約を確保してください。股関節の超音波検査が含まれることも、予約時に確認しておくと安心です。

## 黄色い健診冊子は何に使う？

黄色い健診冊子は、子どもの健診結果、受診日、医師からの説明を記録する公式の記録帳です。通常は出産した病院から渡され、自宅出産では助産師などから受け取ります。紛失に備えて写真を撮るだけでなく、原本も保管してください。

### 2026年から歯科健診Z1〜Z6も記録

2026年1月1日から、乳幼児の歯科健診Z1〜Z6の結果も黄色い健診冊子に記録されるようになりました。対象は生後6か月から6歳までの6回です。

| 歯科健診 | 受診期間 |
|---|---|
| Z1 | 生後6〜9か月 |
| Z2 | 生後10〜20か月 |
| Z3 | 生後21〜33か月 |
| Z4 | 生後34〜48か月 |
| Z5 | 生後49〜60か月 |
| Z6 | 生後61〜72か月 |

2026年より前に冊子を受け取った家庭には、歯科健診用の追加ページが渡される場合があります。歯科医院へ行くときも黄色い冊子を持参し、Z1〜Z6の記録方法を確認してください。

### 電子版（eU-Heft）も選べる

法定健康保険者と多くの民間保険者は、電子患者記録（ePA）の中で使う電子版の健診冊子を提供しています。ただし、利用方法や設定は保険者によって異なります。自動的に全家庭で使えると考えず、加入先の保険者に、利用開始方法、医師側の対応、紙の冊子との併用方法を確認してください。

### 黄色い冊子の全部を保育施設へ渡す必要はない

冊子には診察結果などの機微な健康情報が含まれます。BIÖGによると、受診したことを示すための切り離し式の参加証明カードがあり、保育施設や学校などに提示できます。冊子全体を見せることと、受診した事実を証明することは別です。提出を求められた場合は、まず参加証明カードで足りるか確認してください。

## 2026年の新U10決定は、まだ実施前

2026年8月20日、連邦共同委員会は9〜10歳向けの新しいU10の内容を決定しました。テーマには、体重、身体活動、デジタルメディアの利用、心理面の気になる兆候、予防接種の相談などが含まれます。また、13〜14歳を対象とするJ1の結果を黄色い健診冊子に記録する変更も決定されました。

ただし、決定が公表されたことと、診療所で実際に受けられることは同じではありません。2026年11月9日時点で、この決定はまだ発効していません。連邦保健省の法的確認、官報への掲載、医師の報酬額を定める手続きが残っており、G-BAはそれらが終わってから新U10を実施できると説明しています。

一部の保険者は、従来から小学生向けのU10・U11などを任意の追加サービスとして提供しています。これは新たに決定された9〜10歳向けの標準U10とは区別してください。予約時には、受けようとしている健診の年齢、保険者の給付対象、現時点での制度上の位置づけを確認しましょう。

## 予防接種はU健診と別の予定も確認する

U健診では予防接種の記録や相談も行われますが、すべての予防接種がU健診当日に実施されるわけではありません。BIÖGの予定表には、乳児期の追加の予防接種予約も掲載されています。

最新の推奨時期は、ロベルト・コッホ研究所（RKI）が公表する2026年版の予防接種カレンダーで確認してください。予防接種の種類や回数は年齢、これまでの接種歴、健康状態によって異なるため、古い日本語記事や家族の記録だけで予定を決めず、小児科で接種記録を確認してもらいましょう。

日本語やスペイン語の母子手帳・予防接種記録がある家庭は、原本を持参してください。ワクチン名、接種日、回数が分かる資料があれば、医師がドイツの記録と照合し、必要な追加接種を判断できます。記録が外国語の場合、診療所に翻訳の要否を事前に尋ねてください。

## 保育施設に入るときの証明は2種類を区別する

### 1. 予防接種について医師から相談を受けた証明

感染症予防法第34条第10a項により、保育施設へ初めて入園するときは、子どもの年齢に合った予防接種について、入園前に医師から相談を受けたことを書面で証明する必要があります。これは「推奨される予防接種をすべて完了した」という証明とは異なります。

黄色い健診冊子の参加証明カードは、U健診の受診状況や予防接種相談を示す際に使えます。必要な書類の形式は保育施設や自治体の案内を確認してください。

### 2. 麻疹の接種・免疫証明

これとは別に、感染症予防法第20条第8項は、保育施設や学校などの対象施設に入る子どもについて、麻疹の予防接種または免疫の証明を求めています。原則として、1歳以上2歳未満では少なくとも1回、2歳以上では少なくとも2回の麻疹予防接種、または麻疹に対する免疫があることを証明します。医学的理由で接種できない場合は例外があります。

この要件は麻疹に関するものです。STIKOが推奨するすべてのワクチンが、同じ法律上の義務になっているという意味ではありません。必要な証明方法は、医師の証明書、予防接種記録、免疫の証明など、法令と施設の案内に従って確認してください。

## 予約前・受診当日のチェックリスト

1. 子どもの生年月日から、次のU健診とZ健診の期間を確認する。
2. U2が病院で終わっているか、新生児スクリーニングや聴覚検査が未実施でないか確認する。
3. U3を受ける小児科を早めに決め、予約する。
4. 黄色い健診冊子と参加証明カードを保管し、歯科受診にも持参する。
5. 子どもの健康保険証と予防接種記録を用意する。保険証がまだ届いていない場合は、加入先に仮証明の扱いを確認する。
6. 海外で受けた健診・予防接種の記録があれば、原本と接種日が分かる資料を持参する。
7. 保育施設に入る予定がある場合は、麻疹証明と医師による予防接種相談の証明を別々に確認する。

## 予約期間を過ぎた場合・案内状が届いた場合

U健診には受診すべき期間が定められています。予約が取れない、転居した、海外に滞在していた、子どもが病気だったなどの事情がある場合は、受診をあきらめず、小児科と健康保険者に連絡してください。期間を大きく過ぎた健診の費用負担や、州の通知・リマインダー制度の扱いは状況によって異なります。

州によってはU健診の受診状況を確認する通知・リマインダー制度があります。自治体や保健当局から手紙が届いたら、放置せず、指定された期限、提出先、必要な証明を確認してください。海外で受けた健診がある場合は、受診日と医療機関が分かる記録を用意し、どのように届け出るかを担当窓口に尋ねます。

## よくある質問

### U1とU2は必ず出産した病院で受けますか？

U1は出生直後に行われます。U2は出産した病院で受けることが多いものの、自宅出産や外来出産、早期退院などで未実施の場合は、保護者が診療所に予約する必要があります。新生児スクリーニングが残っている場合は、早めに連絡してください。

### U1〜U9は無料ですか？

法定健康保険では、U1〜U9とJ1が給付対象です。ただし、定められた受診期間を過ぎた場合の費用負担は確認が必要です。民間保険は契約内容によって扱いが異なるため、保険者に確認してください。

### 予防接種はすべて義務ですか？

すべてのSTIKO推奨ワクチンが一律に法律上の義務というわけではありません。一方、保育施設や学校などの対象施設では、麻疹の接種または免疫証明が必要です。入園時の医師による予防接種相談の証明も別に確認してください。

### 黄色い冊子を保育施設に預けてもよいですか？

冊子全体には診察結果などの情報が含まれます。BIÖGは、受診状況を示す参加証明カードを使えると案内しています。冊子全体を渡す前に、参加証明カードで足りるか確認してください。

### U10は2026年から受けられますか？

新しい9〜10歳向けU10は2026年8月20日にG-BAが決定しましたが、2026年11月9日時点ではまだ発効していません。法的確認、官報掲載、医師報酬の手続きが終わるまでは、実施開始済みと考えないでください。
