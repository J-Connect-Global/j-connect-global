AI Letter Helper

ドイツの手紙・役所の書類をAIが日本語で解説

役所、税務署、保険、銀行、大家さん、Kita から届いたドイツ語の手紙。写真を撮るか本文を貼り付けると、AIが「何の手紙か」「いつまでに何をすればいいか」を日本語で整理します。返信が必要なら、ドイツ語の返信文の下書きも作ります。

1. 撮る・貼る
手紙の写真、PDF、または本文のテキスト。
2. AIが整理
要点・期限・金額・やること・用語を日本語で。
3. 返信の下書き
必要な場合はドイツ語の返信文と日本語訳。
無料・保存しない
送信内容は当サイトに保存しません。

          利用上の注意
          
        
            
          
          • このツールは内容の理解を助けるものです。法律相談・税務相談ではありません。
            • 
          
          • 督促（Mahnung）、裁判所、罰金（Bußgeld）、異議申し立ての期限がある手紙は、早めに発行元・専門家・消費者センター（Verbraucherzentrale）に相談してください。

          • 送信内容は解説の作成のためだけに OpenAI の API に送られ、J-Connect では保存しません。

          よくある質問
          
        
          無料ですか？
          はい、無料です。登録も不要です。
          
        
          手書きの手紙も読めますか？
          はっきり写っていれば読めることが多いですが、印刷された書類のほうが正確です。
          
        
          複数ページの手紙は？
          PDFにまとめるか、1ページずつ送ってください。
