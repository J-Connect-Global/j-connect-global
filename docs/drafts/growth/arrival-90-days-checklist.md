# 登録特典PDF原稿：ドイツ到着後90日チェックリスト（下書き）

J-Connect編集部｜2026年版｜各項目の詳しい手順はJ-Connect Germanyの記事へ

> 期限・金額は2026年11月時点の記事と一次情報に基づきます。PDF化の前に、各記事の最新の内容と照らし合わせてください。

## 到着前
- [ ] パスポートの有効期限を確認する（日本の旅券の更新は在外公館でもできる）
- [ ] 日本で海外転出届、マイナンバーカード、年金、住民税、運転免許の手続きを済ませる → ドイツへ引っ越す前に日本でする手続き
- [ ] 住民登録できる住居か、入居証明を出してもらえるかを確認する

## 到着〜2週間
- [ ] 入居から**2週間以内**に住民登録をする（持ち物：パスポート、入居証明、申請書）→ 住民登録
- [ ] 郵便受けとドアベルに名前を出す（税務識別番号が郵送で届く）
- [ ] 健康保険に加入し、加入証明を勤務先に出す → 健康保険の選び方
- [ ] 在留届を出す（日本の在外公館）

## 2週間〜1か月
- [ ] 銀行口座を開く（通常の口座を断られたら基本口座を申請できる）→ 銀行口座の開設
- [ ] 税務識別番号を勤務先に伝える → 税務ID・税務署番号・給与税区分
- [ ] 携帯電話・SIMを契約する → 携帯電話・SIMの選び方
- [ ] 電気・インターネットを契約する → 電気・インターネットの契約
- [ ] 放送負担金の登録を確認する → 放送負担金

## 1〜3か月
- [ ] 滞在許可の申請・更新の期限を確認し、外国人局の予約を取る → 滞在許可の申請・更新
- [ ] かかりつけ医を探す → 医師の予約を取る方法
- [ ] 個人賠償責任保険と家財保険を検討する → 個人賠償責任保険と家財保険
- [ ] 日本の運転免許をドイツの免許に切り替えるか決める（試験なしで切り替えられる）→ 日本の運転免許とドイツ
- [ ] 家族がいる場合：児童手当、保育先の登録 → 児童手当の申請、Kitaと保育ママを探す
