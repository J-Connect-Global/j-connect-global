# ドイツの暖房ルールが2026年7月改正｜家主・持ち家・借主への影響

この記事は、2026年7月29日に施行された建物近代化法により、暖房の選択がどう変わったかを持ち家の人、分譲住宅の所有者、借主向けに説明します。動いている暖房を今すぐ交換する必要があるのか、ガス・石油暖房を選べば将来も安心なのかを整理します。設備の専門家でなくても、急いで契約する前に見るべき大きな判断軸が分かります。

## 何が変わった？

大きな変更は、新築・既存建物の暖房に対する「再生可能エネルギー65％」という全国一律の方式要件が廃止され、所有者が選べる方式の幅が広がったことです。ヒートポンプ、地域熱、複数方式の組合せ、バイオマスに加え、ガス・石油暖房も選択肢に残ります。

ただし、2045年へ向けて暖房用燃料を気候中立へ移す方向、地域ごとの熱供給計画、将来の燃料・二酸化炭素関連費用まで消えたわけではありません。**設置できることと、長く安く使えることは別**です。

## いま動いている暖房は？

今回の改正だけを理由に、正常に動く暖房を全家庭が直ちに交換する必要はありません。安定して動くなら点検を続け、故障時の代替、自治体の地域熱計画、建物の断熱状況を調べる時間にできます。

頻繁に故障する、部品が手に入りにくい、ガス臭や排気の問題がある場合は別です。安全上の問題は制度比較より先に資格ある業者へ連絡します。真冬の故障で選択肢が狭まる前に、交換候補を考えておく価値があります。

## 本体価格より長い時間で比べる

暖房は長期間使う設備です。本体と工事費だけでなく、燃料・電気、保守、修理、煙突や配管、将来の価格変化を含めます。

| 見ること | なぜ必要か |
| --- | --- |
| 過去のエネルギー使用量 | 建物が実際に必要とする熱を知る |
| 断熱、窓、暖房器具 | 同じ設備でも効率が変わる |
| 地域熱の計画 | 将来接続できる選択肢が変わる |
| 電気容量・設置場所 | 工事費や騒音へ影響する |
| 補助制度 | 申請時期と条件で自己負担が変わる |
| 15〜20年の運転費 | 安い本体が長期で安いとは限らない |

細かな計算式を自分だけで作るより、同じ前提を使った複数見積りを比べます。業者ごとに建物条件と使用量が違えば、価格だけを並べても比較できません。

## ガス・石油暖房が残る意味

法的な選択肢として残ることは、現在と同じ燃料と価格を長期間保証することではありません。将来必要になる気候中立燃料の供給、価格、ガス網の維持費は地域や時期で変わります。

「設置時に安い」だけで決めず、燃料が変わった場合、網の利用者が減った場合、建物を売る場合も考えます。反対に、古い家は必ずヒートポンプ不可という決め付けも避け、必要な供給温度や断熱を測って判断します。

## 持ち家・分譲住宅・賃貸の違い

### 一戸建ての所有者

設備、建物、地域熱、資金をまとめて判断できます。販売業者一社の診断だけで決めず、中立的なエネルギー相談と複数見積りを使います。

### 分譲住宅

暖房は共用設備や管理組合の決定に関係します。自分の住戸だけで方式を決められない場合があり、長期修繕計画と費用分担を確認します。

### 借主

設備を選ぶのは通常家主ですが、工事、家賃、暖房費の影響を受けます。改修の通知、工期、室温・給湯への影響、将来の共益費を確認します。家主の投資判断を借主が技術的に代行する必要はありません。

## 補助金だけで決めない

補助が使えるかは重要ですが、承認前に契約や工事を始めると対象外になる場合があります。条件、対象費用、申請順を公式案内で確認します。

高い補助率だけで不要な工事を選ぶ、補助がないから安全上必要な交換を先送りする、といった逆転を避けます。補助後の自己負担と長期の運転費で比較します。

## 契約前の注意

「法改正で今月中に交換が必要」「この方式だけが将来合法」「補助は必ず受けられる」と急がせる営業には注意します。提案の前提、工事範囲、保証、騒音、補助が不採択の場合の扱いを書面で確認します。

## まとめ

新しい法律は暖房方式の選択肢を広げましたが、長期費用や地域のエネルギー計画を考えなくてよくなったわけではありません。正常な設備を法改正だけで急いで交換せず、安全、残り寿命、建物の熱需要、地域インフラ、総費用を順に見ます。借主は技術選定より、工事と家賃・暖房費への具体的な影響を確認してください。
