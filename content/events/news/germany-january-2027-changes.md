# 【2027年1月から】ドイツで何が変わる？ 最低賃金・ドイツチケット・社会保険・児童手当まとめ

年末が近づくと、ドイツでは「来年から何が変わるか」というニュースが増えます。この記事では、2027年1月1日前後に変わる制度のうち、ドイツで働く・暮らす日本人に関係が深いものを整理しました。

ただし、すでに決まっているものと、まだ政府案・法案の段階のものが混ざっています。本記事では各項目に状況を明記しています（2026年10月21日時点）。

以下、項目ごとに見ていきます。

## 1. 最低賃金が時給14.60ユーロに（決定済み）

2027年1月1日から、法定最低賃金は**時給14.60ユーロ（額面＝税・社会保険料を引く前の金額）**になります。2026年の13.90ユーロから0.70ユーロの引き上げです。

これは2025年11月に公布された「第5次最低賃金調整令（Fünfte Mindestlohnanpassungsverordnung）」で、2026年分と2027年分がまとめて決まっています。法律上すでに確定しているため、今後変わる可能性は低い項目です。

### 在独日本人への影響

- 日系企業の現地スタッフ、飲食店・小売のアルバイト、ワーキングホリデーで働く方は、時給がこの水準を下回っていないか確認しましょう。
- 雇用主側の方は、1月分の給与計算で反映されているか事前にチェックが必要です。

## 2. ミニジョブの上限が月633ユーロに

ミニジョブ（Minijob）の月収上限は、法律で「最低賃金×週10時間相当」に連動する仕組みです。最低賃金の引き上げにより、2027年1月から月633ユーロ（2026年は603ユーロ）に上がります。

配偶者ビザで滞在しながらミニジョブで働いている方などは、上限が上がった分だけ勤務時間を増やせるかどうか、雇用主と相談する余地があります。

なお、雇用主が負担する一括税（Pauschsteuer）を2%から5%に上げる案が税制改正の政府案に含まれていますが、こちらは未成立です。

## 3. ドイツチケットは月66.80ユーロに値上げ

全国の近距離公共交通が乗り放題になる「ドイツチケット（Deutschlandticket）」は、2027年1月から月66.80ユーロ（現在63ユーロ）に値上げされると報じられています。年間では約45ユーロの負担増です。

報道によると、連邦州の交通大臣会議（Verkehrsministerkonferenz）が2026年9月末に決定しました。料金はコスト指数に基づいて算定する方式になっており、2028年以降も見直しが続く見込みです。

### チェックポイント

- サブスクリプション契約の場合、多くは自動で新料金に切り替わります。解約する場合は各交通事業者の締め切りを確認しましょう。
- Deutsche Bahn（DB）から購入した既存契約は、2026年11月30日までに新料金への同意が必要です（10月15日以降に注文した契約は申込時に新料金の案内を受けているため、別の同意は不要とされています）。手順は「[Deutschlandticketは2027年66.80ユーロへ｜DB利用者は11月30日までに確認](/germany/ja/events/news/deutschlandticket-2027-price-consent/)」で解説しています。
- 会社のジョブチケット（Jobticket）経由で利用している方は、自己負担額が変わるか人事部に確認を。

## 4. 社会保険料の「算定上限」が上がる（高所得者ほど負担増）

社会保険料は、給与のうち一定額（保険料算定上限、Beitragsbemessungsgrenze）までにしか掛かりません。この上限が2027年に引き上げられる予定で、上限付近以上の給与を受け取っている方は手取りが減ります。

![公的医療・介護保険と年金・失業保険の保険料算定上限を2026年と2027年で比べた棒グラフ](/assets/images/events/social-insurance-ceiling-2027.svg "図解：J-Connect。2027年の値は閣議決定済み・連邦参議院の同意待ち（2026年10月21日時点）。")

| 項目 | 2026年 | 2027年（予定） |
| --- | --- | --- |
| 公的医療・介護保険（月額） | 5,812.50ユーロ | 6,375ユーロ |
| 年金・失業保険（全国一律・月額） | 8,450ユーロ | 8,850ユーロ |
| 公的医療保険の加入義務上限（年額） | 77,400ユーロ | 84,150ユーロ |

連邦政府は2026年10月にこの「社会保険計算値令2027」を閣議決定しました。施行には連邦参議院（Bundesrat）の同意がまだ必要です。例年は大きな変更なく承認されています。

### 駐在員・現地採用の方へ

- 年収が84,150ユーロを超えないと、公的医療保険（GKV）から民間医療保険（PKV）へ移れなくなります。2027年にPKVへの切り替えを検討している方は、この新しい基準額を前提に判断してください。
- 医療保険の追加保険料率（Zusatzbeitrag）は保険組合ごとに決まり、2027年の水準は例年秋〜年末に発表されます。加入している保険組合からの通知を確認しましょう。

## 5. 児童手当・基礎控除の引き上げは「まだ案」

2027年に向けた所得税改革（Einkommensteuerreform 2027）の政府案が、2026年9月に閣議決定されました。主な内容は次のとおりです。

- 児童手当（Kindergeld）：子ども1人あたり月259ユーロ → 267ユーロ（2028年に272ユーロ）
- 基礎控除（Grundfreibetrag）：12,348ユーロ → 12,564ユーロ（2028年に12,900ユーロ）
- 被用者概算控除（Arbeitnehmer-Pauschbetrag）：1,230ユーロ → 1,430ユーロ
- 家事・修理などの手工業者費用控除（Handwerkerbonus）：控除率20%・上限1,200ユーロ → 15%・上限900ユーロに縮小

ただし、これらは連邦議会・連邦参議院で可決されるまで確定ではありません。金額や時期が変わる可能性があります。特に「Handwerkerbonus」は縮小方向の案なので、リフォームなどを予定している方は、成立状況を見ながら支払時期を検討するとよいでしょう。

成立した時点で、J-Connectでも続報をお届けします。

## 6. 2027年中のその他の変更

- **EU域内の現金払い上限（2027年7月10日〜）**：EUのマネーロンダリング対策規則により、事業者との取引で現金払いできるのは最大10,000ユーロまでになります。個人間の取引は対象外です。
- **新しい私的年金制度**：リースター年金（Riester-Rente）に代わり、ETFなどで運用できる国の補助付き「老後資産形成口座（Altersvorsorgedepot）」が2027年から始まる予定です。

## まとめ：年末までにやっておきたいこと

1. **給与明細を確認**：最低賃金・ミニジョブ上限の変更が1月分の給与に反映されているか。
2. **ドイツチケットの契約を確認**：値上げ後も継続するか、ジョブチケットの自己負担額はどう変わるか。
3. **医療保険の通知をチェック**：保険組合から届く2027年の追加保険料率のお知らせを見落とさない。
4. **児童手当・税制は続報待ち**：政府案の段階なので、成立を確認してから家計の計画に組み込む。
