# ドイツの祝日は州ごとに違う？｜国が決めた祝日は1日だけ、NRWの2027年の祝日一覧つき

11月1日、デュッセルドルフのお店はすべて閉まっているのに、同じ日にベルリンに住む友人は普通に仕事をしている。ドイツで暮らしていると、こんな「祝日のずれ」に出会うことがあります。

このコラムでは、ドイツで暮らす方や出張・旅行で州をまたいで移動する方に向けて、祝日が州ごとに違う理由、どの祝日が全国共通でどれが州だけのものか、そして州ごとの珍しい祝日を紹介します。最後に、ノルトライン＝ヴェストファーレン州（NRW）の2027年の祝日一覧もまとめました。

## 国の法律が決めた祝日は「10月3日」だけ

意外に思われるかもしれませんが、ドイツで国（連邦）の法律が決めている祝日は、10月3日の「ドイツ統一の日」ただ1日だけです。連邦内務省は、ほかの祝日はすべて州が決めているとしています（[連邦内務省：国の祝日](https://www.bmi.bund.de/DE/themen/verfassung/staatliche-symbole/nationale-feiertage/nationale-feiertage-node.html)）。

理由は、ドイツの憲法（基本法）の仕組みにあります。基本法では、国が法律を作れる分野がはっきり決められていて、それ以外は州の担当です。全国一律の祝日を決める権限は、国に明確に与えられていないため、祝日を決めるのは州の仕事になっています（[連邦内務省 用語集](https://www.bmi.bund.de/DE/service/lexikon/functions/bmi-lexikon.html?lv3=9398012&lv2=9391102)）。

10月3日だけが例外なのは、1990年8月31日に結ばれた東西ドイツの統一条約で、この日を法律上の祝日と定めたからです。それまで西ドイツでは、6月17日が「ドイツ統一の日」とされていました（[連邦政府：ドイツ統一の日](https://www.bundesregierung.de/breg-de/schwerpunkte/deutsche-einheit/tag-der-deutschen-einheit-243150)）。

### それでも「全国共通」の祝日は多い

国が決めていないからといって、州ごとにばらばらというわけではありません。元日、聖金曜日、復活祭の翌月曜日、5月1日のメーデー、キリスト昇天祭、聖霊降臨祭の翌月曜日、クリスマスの2日間は、どの州も祝日にしています。各州の法律がそろって同じ日を定めているので、実際には全国共通の祝日になっているのです。

違いが出るのは、それ以外の祝日です。

## 宗教の地図が、祝日の地図になる

州ごとの違いの多くは、キリスト教のカトリックとプロテスタントの分布と重なっています。

- **カトリックの祝日**：聖体祭（Fronleichnam）や11月1日の万聖節（Allerheiligen）は、カトリックの信者が多い南部や西部の州で祝日になっています。NRWもその一つです。
- **プロテスタントの祝日**：10月31日の宗教改革記念日（Reformationstag）は、ルターの宗教改革にちなむ日で、東部の州のほか、2018年からは北部のいくつかの州でも祝日になりました。

つまり、NRWでは10月31日は平日で、翌日の11月1日が祝日。北部の州では10月31日が祝日で、11月1日は平日。たった1日違いで、休みが入れ替わるのです。

## 州ごとの、ちょっと珍しい祝日

ほかにも、その州だけの祝日があります。

- **ザクセン州：贖罪と祈りの日（Buß- und Bettag）**：11月の水曜日。かつては全国の祝日でしたが、1995年に介護保険の財源を確保するため、ほとんどの州で廃止されました。ザクセン州だけは祝日として残し、そのかわり働く人が介護保険料を多めに負担する仕組みになっています（[ザクセン州 日曜・祝日法](https://www.revosax.sachsen.de/vorschrift_gesamt/3997/26160.pdf)）。
- **ベルリン：国際女性デー（3月8日）**：2019年から、ベルリンでは国際女性デーが祝日になりました。ドイツで初めてのことで、その後メクレンブルク＝フォアポンメルン州も続きました（[ベルリン市](https://www.berlin.de/en/events/specials/womens-day/)）。
- **テューリンゲン州：世界子どもの日（9月20日）**：子どもの権利を考える日として、州の祝日になっています（[テューリンゲン州 祝日法](https://landesrecht.thueringen.de/jportal/?aiz=true&max=true&psml=bsthueprod.psml&quelle=jlink&query=FeiertG+TH)）。
- **アウクスブルク市：平和祭（8月8日）**：バイエルン州のアウクスブルク市だけの祝日で、宗教の違いを越えた平和を記念する日です。「州」ではなく「市」だけの祝日という、とても珍しい例です。

## NRWの祝日：2027年の一覧

NRW州の日曜・祝日法が定める祝日は、次の11日です（[NRW州 日曜・祝日法](https://recht.nrw.de/lrgv/gesetz/01012000-bekanntmachung-der-neufassung-des-gesetzes-ueber-die-sonn-und-feiertage/)）。復活祭に合わせて動く祝日の2027年の日付は、ケルン大司教区の一覧で確かめています（[ケルン大司教区](https://www.erzbistum-koeln.de/presse_und_medien/magazin/Katholische-bewegliche-Feiertage-und-Hochfeste/)）。

| 祝日 | 2027年の日付 |
| --- | --- |
| 元日 | 1月1日（金） |
| 聖金曜日 | 3月26日（金） |
| 復活祭の翌月曜日 | 3月29日（月） |
| メーデー | 5月1日（土） |
| キリスト昇天祭 | 5月6日（木） |
| 聖霊降臨祭の翌月曜日 | 5月17日（月） |
| 聖体祭 | 5月27日（木） |
| ドイツ統一の日 | 10月3日（日） |
| 万聖節 | 11月1日（月） |
| クリスマス | 12月25日（土） |
| クリスマス第2日 | 12月26日（日） |

2027年の復活祭は3月28日で、比較的早い年です。そのため、キリスト昇天祭と聖体祭がどちらも5月の木曜日にあたります。木曜日が祝日だと、金曜日に休みを取って4連休にする「橋渡しの日（Brückentag）」を作る人も多く、5月は旅行の計画が立てやすい月になりそうです。

一方で、2027年はメーデー、ドイツ統一の日、クリスマスの2日間が土曜日か日曜日にあたります。ドイツには、日本のように祝日が日曜日と重なったら翌日を休みにする「振替休日」の仕組みがありません。休みが少なく感じる年かもしれません。

![NRW州の2027年の祝日11日をカレンダー形式で並べ、土日と重なる日と木曜日の祝日を色分けした図](/assets/images/events/nrw-public-holidays-2027.svg "図解：J-Connect。NRW州日曜・祝日法とケルン大司教区の移動祝日の一覧に基づく（2026年10月27日参照）。")

### 祝日ではないけれど、静かに過ごす日

NRWでは、11月の国民哀悼の日（Volkstrauertag）や、プロテスタントの死者の日曜日（Totensonntag）は祝日ではなく、追悼の日とされています（[NRW州 日曜・祝日法](https://recht.nrw.de/lrgv/gesetz/01012000-bekanntmachung-der-neufassung-des-gesetzes-ueber-die-sonn-und-feiertage/)）。どちらも日曜日なのでお店はもともと閉まっていますが、静かに過ごす日として、大きな音の出る催しなどが制限されることがあります。

## 暮らしのヒント

1. **職場の所在地の祝日が基準**：休みになるかどうかは、住んでいる場所ではなく、働いている場所の州の祝日で決まるのが一般的です。州をまたいで通勤している人は、職場の州の祝日を確認しましょう。
2. **子どもの学校**：学校の休みも州ごとに違います。祝日と合わせて、州の学校休暇の日程も確認しておくと安心です。
3. **祝日の前は買い物を早めに**：祝日はお店が閉まります。聖金曜日から復活祭の翌月曜日までのように、休みが続く時期は特に注意が必要です。日曜日のお店のルールは「[ドイツの日曜日はなぜこんなに静か？](/germany/ja/events/columns/germany-sunday-rest-shops-closed/)」で紹介しています。
4. **旅行先の祝日にも注意**：南ドイツへの旅行中に、地元だけの祝日でお店が閉まっていた、ということもあります。

祝日の違いを知ると、ドイツが「州の集まり」でできた国だということが実感できます。11月1日の静かな街を歩くときは、少しだけ、その背景にある歴史や宗教の地図を思い浮かべてみてください。
