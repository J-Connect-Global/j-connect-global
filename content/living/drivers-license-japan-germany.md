# 日本の運転免許とドイツ｜ドイツの免許への切り替え（試験なし）と、海外にいる間の日本の免許の期限切れ

日本の運転免許を持っている人は、ドイツで試験を受けずに、ドイツの運転免許に切り替えられます。ドイツの運転免許規則では、日本はすべての車種について、学科試験も技能試験も免除される国になっています（[運転免許規則 別表11](https://www.gesetze-im-internet.de/fev_2010/anlage_11.html)）。

この記事の前半では、ドイツの免許への切り替えの手順を、後半では、ドイツにいる間に日本の免許の期限が切れそうなときの考え方を説明します。

## ドイツに住み始めてから6か月は、日本の免許で運転できる

外国の免許でドイツを運転できるのは、ドイツに住み始めて（住民登録をして）から**6か月**までです（[運転免許規則 第29条](https://www.gesetze-im-internet.de/fev_2010/__29.html)）。

その間は、日本の免許といっしょに、**免許のドイツ語訳**を持って運転します。ドイツ語訳は、ドイツにある日本の総領事館などが発行する「運転免許証抜粋証明」が使えます（[在デュッセルドルフ日本国総領事館](https://www.dus.emb-japan.go.jp/itpr_ja/k_certification_menkyo.html)）。ADAC（ドイツ自動車連盟）や、ドイツの公認翻訳者の翻訳を使う方法もあります（[在ミュンヘン日本国総領事館](https://www.muenchen.de.emb-japan.go.jp/itpr_ja/menkyokakikae.html)）。

6か月を過ぎても運転を続けるには、ドイツの免許への切り替えが必要です。

## ドイツの免許への切り替えの手順

| ステップ | やること |
| --- | --- |
| 1 | 日本の免許のドイツ語訳（運転免許証抜粋証明など）を用意する |
| 2 | 市の運転免許の窓口（Führerscheinstelle）に予約する |
| 3 | 必要書類を出す：パスポート、日本の免許、ドイツ語訳、証明写真など |
| 4 | 数週間後に、ドイツの免許を受け取る |

ケルン市の案内では、必要なものはパスポートまたは身分証、外国の免許、写真で、免許に交付日が書かれていない場合は、免許を持っている期間の証明も必要です。手続きには2〜3週間ほどかかります。**申請するときに、日本の免許がまだ有効である必要があります**（[ケルン市](https://www.stadt-koeln.de/artikel/60839/index.html)）。

窓口によっては、総領事館の抜粋証明に加えて、ADACの車種の証明（Klassifizierung）を求められることがあります（[在ミュンヘン日本国総領事館](https://www.muenchen.de.emb-japan.go.jp/itpr_ja/menkyokakikae.html)）。視力検査や応急手当の講習の証明を求める窓口もあるので、予約のときに確認しましょう。

### 切り替える前に知っておきたいこと

- **日本の免許は返ってこないことがある**：切り替えのとき、日本の免許はドイツ側に提出し、日本に返されることがあります。手元に戻るまで時間がかかる場合があります。
- **住民登録の後に日本で免許を取ったり更新したりした場合**：在ミュンヘン日本国総領事館は、ドイツに住民登録した後に日本で免許を取得・更新すると、原則としてドイツの免許に切り替えられなくなると注意を呼びかけています（[在ミュンヘン日本国総領事館](https://www.muenchen.de.emb-japan.go.jp/itpr_ja/menkyokakikae.html)）。
- **一時帰国で日本を運転するとき**：ドイツの免許で日本を運転するには、ドイツの免許の日本語訳が必要です。日本の免許も持っているかどうかで、方法が変わります。

## ドイツにいる間に、日本の免許の期限が切れそうなとき

### 出国前、または一時帰国のときに更新する

海外に長く住む人は、更新の期間の前でも、出国前に更新できる特例があります。ただし、早く更新すると、次の有効期間が短くなります（[警察庁](https://www.npa.go.jp/bureau/traffic/menkyo/syuuseimatome.pdf)）。更新の期間に海外にいた人は、一時帰国のときに更新できる場合もあります（[外務省](https://www.mofa.go.jp/mofaj/toko/kaigai/licence/index.html)）。

### 期限が切れてしまった場合

海外にいたために更新できなかった場合は、帰国後の手続きで、試験が免除されることがあります。

| 期限が切れてからの期間 | 手続き |
| --- | --- |
| 6か月以内 | 手続きをすれば、もとの免許に近い形で再び受け取れる |
| 6か月を超えて3年以内 | 帰国した日から**1か月以内**に手続きすれば、学科試験と技能試験が免除される |
| 3年を超える | 失効の手続きはできない（新しく免許を取り直す） |

（出典：[警視庁](https://www.keishicho.metro.tokyo.lg.jp/menkyo/koshin/shikko/shikko05.html)、[外務省](https://www.mofa.go.jp/mofaj/toko/kaigai/licence/index.html)）

手続きには、海外にいたことを示す書類が必要です。パスポートの出入国のスタンプ、搭乗券、航空券の控えなどを捨てずに保管しておきましょう。細かい扱いは都道府県によって違うので、手続きの前に、住む地域の運転免許センターに確認してください。
