# ドイツの日曜日はなぜこんなに静か？｜お店が閉まる理由と、日曜に開いている場所

ドイツに来て最初の日曜日、「スーパーが開いていない」と驚いた人は少なくないはずです。日本ではコンビニも大型店も年中無休が当たり前ですが、ドイツでは日曜日になると、街の多くのお店がシャッターを下ろします。

その理由は、憲法、州の閉店法、働く人のルール、騒音のルールという4つの層に分けると分かりやすくなります。日曜でも開いている場所も紹介するので、週末の買い物の計画に役立ててください。

## 日曜日を守る決まりは、憲法に書かれている

ドイツの日曜日の静けさは、単なる習慣ではありません。国の憲法にあたる基本法（Grundgesetz）に根拠があります。

基本法第140条は、1919年のワイマール憲法の一部の条文を、そのまま今の基本法の一部として取り込んでいます。その一つが第139条で、「日曜日と国が認めた祝日は、労働を休み、心を高める日として法律で守られる」という趣旨が書かれています（[基本法 第140条](https://www.gesetze-im-internet.de/gg/art_140.html)）。100年以上前の条文が、今も効力を持っているのです。

連邦議会の調査資料によると、連邦憲法裁判所はこの規定を、国に「日曜日と祝日を守る最低限の仕組み」を用意させる制度的な保障だと位置づけています（[連邦議会調査局の資料](https://www.bundestag.de/resource/blob/408418/9e116846d839bd07b64611d575b18108/WD-6-217-14-pdf-data.pdf)）。

ここで大切なのは、日曜日の保護が宗教だけの話ではないことです。連邦憲法裁判所は、この規定にはキリスト教の伝統に根ざした意味と同時に、「みんなが同じ日に休み、家族や友人と過ごせるようにする」という社会的な目的もあると述べています（[連邦憲法裁判所 2009年12月1日判決](https://www.bundesverfassungsgericht.de/SharedDocs/Entscheidungen/DE/2009/12/rs20091201_1bvr285707.html)）。信仰を持たない人にとっても、日曜日は「社会全体で一緒に休む日」なのです。

## お店の営業時間は、州ごとに決まる

かつてお店の営業時間は、国の閉店法（Ladenschlussgesetz）でドイツ全国一律に決められていました。2006年の連邦制度改革で、この分野の法律を作る権限が各州に移り、今は州ごとに営業時間のルールが違います（[連邦議会：連邦制度改革の影響](https://www.bundestag.de/resource/blob/422950/69afcd55ff349d7005103a402efcab6c/wd-3-255-09-pdf-data.pdf)）。

同じ資料によると、ほとんどの州が平日の営業時間を大きく自由にした一方で、日曜日と祝日の営業は引き続き厳しく制限されました。バイエルン州は独自の法律を作らず、国の閉店法が引き続き適用されてきた州として紹介されています。

デュッセルドルフやケルンがあるノルトライン＝ヴェストファーレン州（NRW）の閉店法では、次のように決められています（[NRW州 閉店法](https://recht.nrw.de/lrgv/gesetz/30032018-gesetz-zur-regelung-der-ladenoeffnungszeiten-ladenoeffnungsgesetz-loeg-nrw/)）。

- **平日（月〜土曜日）**：お店は時間の制限なく営業できます。法律上は0時から24時まで開けられます。
- **12月24日**：平日にあたる場合、営業は14時まで。
- **日曜日と祝日**：原則として営業できません。

つまりNRWでは、平日なら深夜営業のスーパーがあっても法律上は問題ありません。それでも日曜日だけは、はっきりと線が引かれているのです。

## 日曜日でも開いているお店

日曜日は「すべてのお店が閉まる日」ではありません。NRW州の閉店法には、暮らしに欠かせないものを扱うお店の例外があります（[NRW州 閉店法](https://recht.nrw.de/lrgv/gesetz/30032018-gesetz-zur-regelung-der-ladenoeffnungszeiten-ladenoeffnungsgesetz-loeg-nrw/)・[ケルン商工会議所の解説](https://www.ihk.de/koeln/hauptnavigation/recht-steuern/ladenoeffnungszeiten-in-nrw-5224656)）。

| お店の種類 | 日曜・祝日の営業 |
| --- | --- |
| パン屋・ケーキ屋 | 1日5時間まで営業できる |
| 花屋 | 1日5時間まで営業できる |
| 新聞・雑誌の売店 | 1日5時間まで営業できる |
| 薬局 | 交代制の当番薬局が開く |
| ガソリンスタンド | 終日営業できるが、売れるのは燃料、車の部品、旅行に必要なもの（新聞、地図、飲み物など）に限られる |

ただし、パン屋・花屋・新聞の売店の例外は、復活祭の翌月曜日、聖霊降臨祭の翌月曜日、12月26日には使えません。また12月24日が日曜日にあたる年は、パン屋は14時まで営業できます。

日曜の朝、焼きたてのパン（ブレートヒェン）を買いに近所のパン屋さんへ行くのは、ドイツの週末らしい光景の一つです。開いている時間はお店ごとに違うので、普段使うお店の日曜の営業時間を一度確かめておきましょう。ドイツのパンについては「[ドイツのパンは、なぜこんなに違う？](/germany/ja/events/columns/german-bread-culture/)」で紹介しています。

## 年に数回の「日曜営業日」

街の中心部で、日曜日なのにお店が開いていて人であふれている日があります。これが「日曜営業日」（verkaufsoffener Sonntag）です。

NRW州では、市や町が条例で日曜営業日を決めます。ルールは次のとおりです（[NRW州 閉店法](https://recht.nrw.de/lrgv/gesetz/30032018-gesetz-zur-regelung-der-ladenoeffnungszeiten-ladenoeffnungsgesetz-loeg-nrw/)・[ケルン商工会議所](https://www.ihk.de/koeln/hauptnavigation/recht-steuern/ladenoeffnungszeiten-in-nrw-5224656)）。

- 1つのお店が開けるのは、**1年に最大8回**の日曜・祝日まで。2日続けては開けない。
- 営業は**13時から、最大5時間**。
- 1つの市町村の中で、地区ごとに別々の日を合わせても、**年間16日**まで。
- 市町村全体で開ける場合、待降節（クリスマス前の4回の日曜日）のうち選べるのは**1日だけ**。
- 開くには「公共の利益」が必要。たとえば街のお祭りやイベントと同じ日・近い場所で開く場合などです。

### 「買い物したい人がいる」だけでは足りない

この厳しさの背景には、2009年の連邦憲法裁判所の判決があります。当時ベルリンでは、待降節の4回の日曜日すべてにお店を開けられる決まりがありました。これに対しキリスト教の教会が憲法違反だと訴え、裁判所は訴えを認めました（[連邦憲法裁判所 プレスリリース](https://www.bundesverfassungsgericht.de/SharedDocs/Pressemitteilungen/DE/2009/bvg09-134.html)）。

裁判所は、日曜日は「原則として休む日」でなければならず、例外には十分な理由が必要だとしました。そして、お店の売上を伸ばしたいという利益や、買い物をしたいという一般的な気持ちだけでは、原則として例外の理由にならないと述べています（[連邦憲法裁判所 プレスリリース](https://www.bundesverfassungsgericht.de/SharedDocs/Pressemitteilungen/DE/2009/bvg09-134.html)）。「原則は休み、例外は理由があるときだけ」という考え方が、今の日曜営業日のルールにつながっています。

## 働く人の日曜日も守られている

お店が閉まるのは、働く人を休ませるためでもあります。労働時間法第9条は、働く人を日曜日と祝日の0時から24時まで働かせてはならないと定めています（[労働時間法](https://www.gesetze-im-internet.de/arbzg/BJNR117100994.html)）。

もちろん、病院、警察や消防、鉄道やバス、レストランやホテルのように、日曜日も止められない仕事があります。法律はこうした仕事を例外として認めています。そのかわり、日曜日に働いた人には、2週間以内に代わりの休日を与えることになっています（同法第11条）。

日曜日の駅やレストランで働く人がいるのは、この例外のおかげです。日曜の静けさは、休む人と支える人の両方によって成り立っています。

## 芝刈り機も日曜日はお休み

日曜日の静けさは、お店だけの話ではありません。住宅地では、庭仕事の機械の音にもルールがあります。

国の機械騒音防止令（32. BImSchV）第7条は、住宅地で芝刈り機などの機械を、**日曜日と祝日は終日、平日は20時から翌朝7時まで**使ってはならないと定めています（[機械騒音防止令 第7条](https://www.gesetze-im-internet.de/bimschv_32/__7.html)・[連邦環境庁：庭仕事の機械](https://www.umweltbundesamt.de/themen/laerm/nachbarschaftslaerm-laerm-von-anlagen/gartengeraete)）。州や市がさらに細かいルールを決めていることもあります。

集合住宅では、建物の利用規則（Hausordnung）で、日曜日の大きな音や、夜の洗濯機の使用について決めていることもあります。日本の感覚では気にしないような生活音が、ドイツでは近所とのトラブルの種になることがあります。引っ越したら、近所とのトラブルを避けるために、一度利用規則を読んでおきましょう。住まい探しの基本は「[ドイツで賃貸住宅を借りる](/germany/ja/living/rent-apartment-germany/)」で紹介しています。

## では、ドイツの人は日曜日に何をしている？

お店が閉まっている日曜日、ドイツの人たちは何をしているのでしょうか。よく見かけるのは、こんな過ごし方です。

- **散歩**：森や公園、川沿いを家族でゆっくり歩く。秋の森の楽しみ方は「[ドイツの秋の森を歩く](/germany/ja/events/columns/germany-autumn-forest-walk/)」でも紹介しています。
- **コーヒーとケーキ**：午後に家族や友人とコーヒーとケーキを囲む。カフェは日曜日も開いているところが多くあります。
- **美術館・博物館**：日曜日に開いている施設が多く、日曜日の方がにぎわうこともあります。
- **スポーツ観戦や運動**：地域のスポーツクラブの試合や練習も、日曜日によく行われます。

最初は不便に感じる日曜日も、「買い物ができない日」ではなく「予定を入れなくていい日」と考えると、見え方が変わってきます。

## 暮らしのコツ：日曜日に困らないために

1. **土曜日に買い物をまとめる**：土曜日の夕方のスーパーは混み合います。できれば午前中か、平日の夜に。
2. **祝日の前に注意**：日曜日と祝日が続く連休（復活祭やクリスマス）は、2日以上お店が閉まることがあります。祝日は州ごとに違うので、住んでいる州の祝日を確認しておきましょう。
3. **12月24日は午後から閉まる**：NRW州では、平日でも14時までです。
4. **急な薬は当番薬局へ**：日曜日や夜間に開いている当番薬局は、薬局の入口の掲示や、地域の薬剤師会のウェブサイトで確認できます。
5. **ガソリンスタンドと駅の売店は「最後の手段」**：飲み物や軽食なら手に入りますが、品数は限られ、値段も高めです。

ドイツの日曜日は、少し不便で、とても静かです。その静けさが憲法から近所の芝刈り機までつながっていると知ると、日曜の朝の散歩が、少し違って見えてくるかもしれません。

### 年末の買い物は、日曜ルールに加えて州の祝日と店舗時刻を確認

2026年は12月24日が木曜日、25日が金曜日、26日が土曜日、27日が日曜日です。NRWでは12月24日の一般小売店は法律上14時まで営業できますが、店舗ごとに早く閉まる場合があります。25日と26日は法定祝日、27日は日曜日のため、通常のスーパーが営業すると考えない方が安全です。薬局の緊急当番や公共交通の確認方法は、[NRWのクリスマス2026・営業日チェック](/germany/ja/living/nrw-christmas-opening-hours-2026/)にまとめました。州によって規則は異なるため、他州へ移動する場合は現地の案内を確認してください。
