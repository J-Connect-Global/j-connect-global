# メールマガジンの設計（下書き）

## 目的と読者
- 目的：検索に頼らず、毎月戻ってくる読者を作る。期限のある手続きを、期限の前に知らせる。
- 読者：ドイツに住む日本人（到着1年以内の人、子育て中の家庭、永住・帰化を考える人）。

## 配信の形
| 項目 | 案 |
| --- | --- |
| 頻度 | 月2回（第1・第3木曜） |
| 長さ | 3〜5本の話題。1本は2〜3行と記事へのリンク |
| 固定の枠 | 1）今月の期限 2）制度の変更 3）新しい記事・改訂した記事 4）季節のイベント 5）読者の体験の募集 |
| 差出人 | J-Connect編集部 |
| 登録特典 | 「到着後90日チェックリスト」PDF（原稿は arrival-90-days-checklist.md） |

## 法律上の前提（実行前の確認事項）
- 登録は**ダブルオプトイン**（確認メールのリンクを押して登録完了）にする。広告を含める場合は、登録時にその旨を書く。
- すべてのメールに配信停止のリンクと運営者情報（インプレッサム）を入れる。
- 配信サービスの選定・アカウント登録、データ処理契約（AVV）の締結は Yoshiさんの判断（未実施）。

## 第1号の原稿案（2026年12月第1木曜）

件名：【J-Connect】12月の期限：共益費の精算、年末の荷物、2027年1月からの変更

1. **共益費（Nebenkosten）の2025年分の精算は12月31日まで**：家主が精算書を送る期限です。届いたら内容を確認しましょう。→ ドイツの2025年共益費精算
2. **日本への年末の荷物は締切に注意**：クリスマス・年末に間に合わせるための発送の目安。→ ドイツから日本へクリスマス・年末の荷物と手紙を送る2026
3. **年末年始の営業日**：スーパー・薬局・公共交通の営業日を確認。→ NRWのクリスマス2026
4. **新しい記事**：Kitaと保育ママの探し方を、編集部の照会記録をもとに全面改訂しました。→ NRWでKitaと保育ママを探す
5. **体験を教えてください**：住民登録の予約が取れるまで何日かかりましたか？ 地域と時期だけで十分です。→ 体験を送る

（各記事のリンクは公開時のURLに差し替え。期限・日付は送信前に記事と一次情報で再確認）
