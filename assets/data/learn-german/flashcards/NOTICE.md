# Flashcard data notice

The public A1–C2 flashcard JSON in this directory contains J-Connect editorial content only. Every public card must include a reviewed Japanese meaning, an original German example with Japanese translation, relevant grammar information, and an individually assigned study level.

CEFR level assignments are J-Connect study classifications informed by the Council of Europe CEFR Companion Volume, Goethe-Institut examination contexts, and DAFlex / CEFRLex methodology. They are not official word-level certifications.

Unreviewed dictionary entries and mechanically inferred level assignments are not included in public decks.
