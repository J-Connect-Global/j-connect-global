# ドイツの学校は「成績1」が一番いい？｜1〜6の成績の意味と、高校の「15点満点」

ドイツの学校に通う子どもが、テストを持って帰ってきて「1だった！」と喜んでいる。日本の感覚だと心配になりますが、ドイツでは「1」が一番よい成績です。

このコラムでは、ドイツで子どもを学校に通わせている方や、これから通わせる予定の方に向けて、ドイツの学校の成績の付け方を紹介します。1〜6の成績がそれぞれ何を意味するのか、小学校の低学年で成績がないこと、高校の上の学年で使われる「15点満点」の仕組みまで、デュッセルドルフやケルンがあるノルトライン＝ヴェストファーレン州（NRW）の決まりを例に整理します。

## 1が一番よく、6が一番悪い

ドイツの学校の成績は、**1から6までの6段階**です。数字が小さいほど成績がよく、日本の5段階評価（5が一番よい）とは数字の向きが逆になっています。

NRW州の学校法は、6つの成績の意味を次のように定めています（[NRW州 学校法 第48条](https://recht.nrw.de/lmi/owa/br_bes_detail?sg=0&menu=1&bes_id=7345&anw_nr=2&aufgehoben=N&det_id=703715)）。

| 成績 | ドイツ語 | 意味 |
| --- | --- | --- |
| 1 | sehr gut（とてもよい） | 求められることに、特に優れた形でこたえている |
| 2 | gut（よい） | 求められることに、十分にこたえている |
| 3 | befriedigend（満足できる） | 求められることに、おおむねこたえている |
| 4 | ausreichend（足りている） | 不十分な点はあるが、全体としてはまだ求められることにこたえている |
| 5 | mangelhaft（不十分な点が多い） | 求められることにこたえていないが、基本的な知識はあり、近いうちに不足を補える |
| 6 | ungenügend（不十分） | 求められることにこたえておらず、基本的な知識も足りず、近いうちに不足を補えない |

覚えておきたいのは、**4までが「合格ライン」**だということです。5や6は「求められることにこたえていない」成績で、成績表に5や6が多いと、次の学年に進めない（留年する）理由になることがあります。

また、学校法は、生徒が理由なく課題を出さなかったり、テストを受けなかったりした場合は、成績6として扱うと定めています（同上）。

### 「1-」や「2+」とは？

テストの答案には、「1-」「2+」のように、プラスやマイナスが付いていることがあります。これは、同じ成績の中での細かい位置を示すものです。「2+」は「2の中でも1に近い」、「2-」は「2の中でも3に近い」という意味です。成績表（Zeugnis）に書かれる成績は、プラスやマイナスの付かない1〜6の数字になるのが一般的です。

## 成績は、テストだけで決まるわけではない

NRW州学校省によると、成績表の成績は、筆記のテスト（Klassenarbeit）だけでなく、授業中の発言や取り組み、宿題、小さなテスト、発表などの「その他の成績（Sonstige Mitarbeit）」もあわせて決まります（[NRW州学校省：成績表の成績はどう決まる？](https://www.schulministerium.nrw/wie-kommt-eine-zeugnisnote-zustande)）。

授業中に手を挙げて発言することが、成績に大きく影響することがあるのは、日本の学校との違いの一つです。子どもが「授業で発言するのが苦手」という場合は、先生との面談で、どのように評価されているかを聞いてみるとよいでしょう。

## 小学校1・2年生では、成績を付けない

NRW州の小学校（Grundschule）では、低学年のうちは数字の成績を付けません。

NRW州学校省によると、小学校の最初の2年間（入学期）は、成績を数字で付けずに評価します。成績表では、子どもの学びの様子や、それぞれの教科でどこまでできるようになったかを、文章などで伝えます。各学校の学校会議（Schulkonferenz）は、3年生まで数字の成績を付けないと決めることもできますが、遅くとも4年生の前期の成績表からは、教科ごとに数字の成績が付きます（[NRW州学校省：小学校のAからZ](https://www.schulministerium.nrw/die-grundschule-von-bis-z)）。

4年生の成績は、5年生からどの種類の中等学校（ギムナジウムなど）に進むかを考えるときの材料にもなります。

## 高校の上の学年は「15点満点」

ギムナジウムの上級段階（大学入学資格「アビトゥーア」を目指す最後の学年）になると、成績の付け方が変わります。1〜6の代わりに、**0〜15点**の点数が使われるのです。

常設各州文部大臣会議（KMK）の協定では、1〜6の成績と0〜15点は、次のように対応しています（[KMK：ギムナジウム上級段階とアビトゥーアに関する協定](https://www.kmk.org/fileadmin/Dateien/pdf/PresseUndAktuelles/2023/2023_03_16-Vereinb-GymnOberstufe-Abitur.pdf)）。

| 成績 | 点数 |
| --- | --- |
| 1（とてもよい） | 15・14・13点 |
| 2（よい） | 12・11・10点 |
| 3（満足できる） | 9・8・7点 |
| 4（足りている） | 6・5・4点 |
| 5（不十分な点が多い） | 3・2・1点 |
| 6（不十分） | 0点 |

同じ成績の中の3つの点数は、プラス・ちょうど・マイナスにあたります。たとえば「2+」は12点、「2」は11点、「2-」は10点です。

アビトゥーアの最終的な成績は、上級段階での成績と卒業試験の点数を合計して計算され、「1.0」から「4.0」までの数字で表されます。ドイツの大学の一部の学部では、この数字が入学の選考に使われるため、生徒たちにとってはとても大切な数字です。

## 保護者が知っておきたいこと

1. **数字の向きに注意**：日本の感覚で「5」を見て喜ばないように。ドイツでは5は「不十分な点が多い」成績です。
2. **州によって細かい決まりが違う**：成績の基本は全国でほぼ同じですが、成績表の形や留年の決まりは州ごとに違います。この記事はNRW州の例です。
3. **成績表は年に2回が基本**：多くの学校では、学年の前期の終わり（1月〜2月ごろ）と学年末（夏休みの前）に成績表が渡されます。学校の休みの日程は「[NRWの学校休暇2026/27年度](/germany/ja/living/nrw-school-holidays-2026-2027/)」で確認できます。
4. **気になることは早めに面談で**：成績が下がってきたときは、先生との面談（Elternsprechtag など）で、どの教科のどの部分に課題があるかを聞いてみましょう。

小さな子どもの保育については「[ドイツのKita・U3申込み](/germany/ja/living/kita-u3-tagesmutter-guide/)」で紹介しています。「1が一番」と分かれば、子どもが持ち帰ったテストの数字を、一緒に喜べるようになるはずです。
