# なぜカーニバルは11月11日11時11分に始まる？｜ケルンとデュッセルドルフの「第5の季節」

11月11日の午前、ケルンやデュッセルドルフの街を歩くと、仮装した人たちが広場に集まり、11時11分になると大きな歓声が上がります。ラインラント地方では、この瞬間からカーニバルのシーズンが始まるのです。

このコラムでは、NRWに住む方や、初めてカーニバルを見てみたい方に向けて、「なぜ11月11日の11時11分なのか」という疑問を入口に、「11」という数の意味、キリスト教の暦とのつながり、ケルンとデュッセルドルフそれぞれの始まり方、そして掛け声「アラーフ」と「ヘラウ」の違いを紹介します。2026/27年シーズンの主な日程もまとめました。

## 「11」は道化の数

カーニバルでは、「11」という数がいたるところに登場します。始まりは11月11日の11時11分、カーニバルの団体を率いる役員会は「11人委員会」（Elferrat）と呼ばれます。

ラインラント地域連合（LVR）の地域研究所によると、キリスト教の数の象徴では、「12」が使徒の数のように完全さや秩序を表すのに対し、それに一つ足りない「11」は、道化（あるいは悪魔）の数とされてきました（[LVR 地域研究所](https://rheinform.lvr.de/de/nav_main/beitraege/inhaltsseite_2.html)）。秩序からはみ出した数が、ふだんの決まりごとをひっくり返すお祭りにふさわしい、というわけです。

もう一つよく語られるのが、ドイツ語の「ELF（11）」を、フランス革命の標語「平等・自由・友愛」（Égalité, Liberté, Fraternité）の頭文字に見立てる説です。ラインラントはかつてフランスの支配を受けた地域で、カーニバルには権力者をからかう伝統もあります。ただしLVRは、これはあくまで一つの解釈で、はっきりした証拠があるわけではないとしています（同上）。

## 11月11日と、クリスマス前の断食

では、なぜ「11月」なのでしょうか。ここには、キリスト教の暦が関係しています。

カーニバル（ケルンの言葉ではFastelovend）は、もともと復活祭の前の40日間の断食期間（四旬節）に入る直前のお祭りです。たくさん食べて、飲んで、騒いでから、静かな季節に入るのです（[LVR 地域研究所](https://rheinische-landeskunde.lvr.de/de/institut/institut_kamellebueggel/fastelovend/fastelovend_beitrag.html)）。

一方、11月11日の始まりは、昔のクリスマス前の断食の名残だと考えられています。LVRによると、11月11日のシーズン開始は、かつての待降節（クリスマス前の期間）の断食に由来するもので、ラインラントのカーニバルでは、19世紀半ばから11月11日がシーズンの始まりになりました。そして11月12日から1月6日の公現祭（三賢王の日）までは、カーニバルはお休みになります。死者を悼む11月、待降節、クリスマスの季節には、カーニバルの催しをしないのです（[LVR 地域研究所](https://rheinform.lvr.de/de/nav_main/beitraege/inhaltsseite_2.html)）。

つまり、11月11日に「始まる」といっても、本格的な盛り上がりは年が明けてから。11月11日は、いわば「今シーズンもやりますよ」という開会宣言の日です。

### 聖マルティン祭と同じ日

11月11日は、子どもたちがランタンを持って歩く聖マルティン祭の日でもあります。LVRの「ラインラントの暮らしの文化」は、この二つは日にちが同じだけで、まったく別の習慣だと説明しています（[LVR ラインラントの暮らしの文化](https://alltagskulturen.lvr.de/de/themen/Von-Laternenzug-und-Narrenkappe/LVR/lido/5654752c6362c7.69245602)）。朝は道化の帽子、夕方はランタンの灯り。ラインラントの11月11日は、一日で二つの顔を見せます。聖マルティン祭については「[コメルンの聖マルティン祭2026](/germany/ja/events/kommern-saint-martin-2026-guide/)」で紹介しています。

## ケルン：1823年に生まれた「整えられたカーニバル」

今のようなラインラントのカーニバルは、19世紀初めのケルンで形づくられました。LVR地域研究所は、ラインラントのカーニバルは19世紀初めにケルンで生まれ、驚くほどの速さで地域全体に広がったとしています（[LVR 地域研究所](https://rheinform.lvr.de/de/nav_main/beitraege/inhaltsseite_2.html)）。

きっかけは1823年です。ケルンの市民たちが、カーニバルを秩序あるお祭りとしてよみがえらせようと、祭りを運営する委員会を作りました。これが今のケルン・カーニバル祭典委員会（Festkomitee Kölner Karneval）の始まりで、1823年には最初の「バラの月曜日の行列」がケルンの街を練り歩きました（[ケルン市：カーニバルの歴史](https://www.stadt-koeln.de/artikel/05206/index.html)・[ケルン・カーニバル祭典委員会 年表](https://koelnerkarneval.de/fileadmin/user_upload/Pressemitteilungen/Jubilaeumspressemappe/FK_Jubilaeumspressemappe_Historie_Chronik.pdf)）。

ケルンのカーニバルの主役は、「三人組」（Dreigestirn）と呼ばれる王子・農夫・乙女の3人です。乙女の役も、伝統的に男性が演じます。今のような三人組の形が定着したのは、1870年代のことです（[ケルン・カーニバル祭典委員会](https://koelnerkarneval.de/koelner-dreigestirne/koelner-dreigestirne)）。

11月11日には、ケルン旧市街の広場などで、シーズンの始まりを祝う催しが開かれ、多くの人が仮装して集まります。

## デュッセルドルフ：マスタードの壺から目覚める道化

デュッセルドルフのシーズン開始は、少し変わっています。主役は「ホッペディッツ」（Hoppeditz）という道化の人形です。

11月11日の11時11分、市庁舎前の広場で、ホッペディッツがマスタードの壺から目を覚まし、街の出来事や市長を皮肉る演説をします。市長も市庁舎のバルコニーから言い返すのが恒例です（[デュッセルドルフ市](https://www.duesseldorf.de/aktuelles/news/detailansicht/newsdetail/der-hoppeditz-ist-erwacht-auftakt-des-karnevals/)）。マスタードの壺から出てくるのは、デュッセルドルフがマスタードの街として知られていることにちなんだものだといわれます。

観光局の案内によると、2026年のホッペディッツの目覚めは、11月11日（水）11時11分、市庁舎前の広場で行われます（[デュッセルドルフ観光局](https://www.visitduesseldorf.de/event/hoppeditz-erwachen-f5ee3197a3)）。当日のプログラムは、主催者や市の案内で確認してください。

権力者を笑いの種にし、言われた側も笑って返す。カーニバルの「ふだんの上下関係をひっくり返す」精神が、よく表れた行事です。

## 「アラーフ」と「ヘラウ」、どこで何と言う？

カーニバルの掛け声は、地域によって違います。ケルンでは「アラーフ！」、デュッセルドルフでは「ヘラウ！」。間違えると笑われる……というのは半分冗談ですが、地元の人にとっては大切な違いです。

LVR地域研究所によると、「アラーフ」はもともとカーニバルとは関係のない、一般的な「万歳」のような言葉でした。最も古い例は1550年ごろのケルン周辺の陶器のジョッキに刻まれた言葉で、「何よりも」といった意味だと考えられています。それがいつ、どのようにカーニバルの掛け声になったのかは、分かっていません（[LVR：アラーフとヘラウ](https://rheinische-landeskunde.lvr.de/de/institut/institut_kamellebueggel/alaaf_und_helau/alaaf_helau_beitrag.html)）。

「ヘラウ」の由来は、さらに謎が多いようです。最初の記録は1603年のチロル地方とされますが、教会の「ハレルヤ」から来たという説、「やあ（ハロー）」から来たという説などがあり、どれが正しいかはまだ分かっていません（同上）。

地図にすると、ケルンとその周りの「アラーフ」の地域を、デュッセルドルフ、下ライン地方、ルール地方などの「ヘラウ」の地域が取り囲むような形になっています。なぜ境界がそこにあるのかも、はっきりしていません（同上）。

## 2026/27年シーズンの主な日程

カーニバルの日程は、復活祭の日にちによって毎年変わります。2027年の復活祭は3月28日なので、今シーズンのカーニバルは比較的早い2月に最高潮を迎えます（[ケルン市：カーニバルシーズンの日程](https://www.stadt-koeln.de/artikel/08212/index.html)）。

| 日にち | 出来事 |
| --- | --- |
| 2026年11月11日（水）11時11分 | シーズン開始 |
| 2026年11月12日〜2027年1月6日 | カーニバルのお休み期間 |
| 2027年1月 | 各地の団体の催しが本格的に始まる |
| 2027年2月4日（木） | 女性のカーニバルの日（Weiberfastnacht）。ここから街頭のカーニバルが始まる |
| 2027年2月8日（月） | バラの月曜日（Rosenmontag）。ケルンやデュッセルドルフで大きな行列 |
| 2027年2月10日（水） | 灰の水曜日（Aschermittwoch）。カーニバルが終わり、断食期間に入る |

女性のカーニバルの日には、女性たちが市庁舎に「押し寄せる」伝統行事が各地で行われます。バラの月曜日の行列では、山車から観客にお菓子や花が投げられ、街全体がお祭りの空気に包まれます。

## 初めて行く人へ

カーニバルは、見るだけでも十分楽しめるお祭りです。ただ、特に女性のカーニバルの日とバラの月曜日は、街の中心部が非常に混み合います。小さな子ども連れの場合は、中心から少し離れた沿道や、地域の小さな行列から楽しむのもおすすめです。電車や道路の運行も大きく変わるので、当日の交通案内を確認しておきましょう。

仮装は、特別な衣装でなくても大丈夫です。帽子やかつら、顔に小さな絵を描くだけでも、街の空気に溶け込めます。

11月11日の11時11分は、そんな長いお祭りの、最初の合図です。今年は平日の水曜日ですが、ケルンやデュッセルドルフで働いている方は、昼休みに少しだけ広場の様子をのぞいてみてはいかがでしょうか。
