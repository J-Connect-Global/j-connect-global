## 更新する理由

現行記事はDBの既存契約に関する11月30日の回答期限を説明している。2026年11月5日公表の連邦政府「Deutschlandticket：質問と回答」ページは、2027年1月から66.80ユーロになることに加え、交通事業者から連絡があった場合は継続への同意が必要で、連絡がない場合は新料金で自動継続すると明記している。全国共通の期限と誤読されないよう、DBの期限と全国的な説明を並べて示す。

## 追加する本文案

連邦政府も2026年11月5日公表の公式FAQで、Deutschlandticketは2027年1月1日から月額66.80ユーロになると説明しています。交通事業者から継続への同意を求める連絡が届いた場合は、その事業者の期限までに手続きが必要です。一方、事業者から連絡がない場合は、新料金で自動的に継続されると連邦政府は案内しています。

したがって、2026年11月30日を全ての利用者に共通する全国一律の回答期限と考えないでください。本文で説明している11月30日はDBの対象契約に関する期限です。Rheinbahn、KVB、VRR内の別事業者、大学経由の学生向け券などは、実際の販売元から届くメール、アプリ、契約者ページの案内を優先してください。

## 2026-11-09 DB FAQの追加照合：対象契約ごとの例外

DBの最新FAQを再確認したところ、既存契約と新規契約、Jobticketで必要な操作が異なる。本文を実装する際は、次の区分を加える。

| 対象 | 2027年の継続手続き |
| --- | --- |
| 2026年10月14日までにDBで購入した既存契約 | 66.80ユーロと追加運賃条件への同意または解約を、原則2026-11-30までに契約者本人が回答。回答がなければ2026-12-31で終了 |
| 2026年10月15日以降にDBで購入した契約 | 購入時と注文確認で新価格・追加条件を通知済みのため、別途同意は不要。自分で解約しない限り新条件で継続 |
| DBのJobticket | 原則として通常のDB契約と同じく11月30日までに回答。月額を勤務先が全額負担し、勤務先が枠組み契約を継続する場合は、本人の追加同意は不要 |
| DB以外の交通事業者から購入した契約 | DBの11月30日期限を流用しない。事業者から同意を求める連絡が届いたか、契約者ページ・メール・アプリを確認する |

追加で明記する実務上の注意：

- DBのFAQは、同意・解約の操作を契約者本人が行うよう案内している。家族や勤務先が購入者の場合は、利用者本人ではなく契約者に確認する。
- 11月30日までに回答せず終了扱いになったDB契約は、2026年12月31日まではAbo PortalまたはDB Navigatorから再有効化できる。12月31日を過ぎた後は、2027年分を新規購入する必要がある。
- DB Jobticketの利用者負担額は勤務先との補助契約による。DBのFAQは2027年の月額を最大63.46ユーロ（個別の勤務先補助を差し引く前）と案内している。勤務先が全額負担するケースは、会社の枠組み契約が継続するかを確認する。
- 2026年10月15日以降の購入に関する例外はDBのFAQに基づく。全国の他事業者の購入日・同意方法へ一般化しない。
