1. 最低賃金が時給14.60ユーロに（決定済み）

2027年1月1日から、法定最低賃金は時給14.60ユーロ（額面＝税・社会保険料を引く前の金額）になります。2026年の13.90ユーロから0.70ユーロの引き上げです。

これは2025年11月に公布された「第5次最低賃金調整令（Fünfte Mindestlohnanpassungsverordnung）」で、2026年分と2027年分がまとめて決まっています。法律上すでに確定しているため、今後変わる可能性は低い項目です。

在独日本人への影響

  • 日系企業の現地スタッフ、飲食店・小売のアルバイト、ワーキングホリデーで働く方は、時給がこの水準を下回っていないか確認しましょう。
  • 雇用主側の方は、1月分の給与計算で反映されているか事前にチェックが必要です。

2. ミニジョブの上限が月633ユーロに

ミニジョブ（Minijob）の月収上限は、最低賃金に連動する法定計算式で決まります。2027年1月1日からの上限は、時給14.60ユーロを式に当てはめると月633ユーロです（2026年は月603ユーロ）。これは自動的に非課税になる枠ではありません。

勤務時間の目安、掛け持ち、税金・年金・健康保険の扱いは、ドイツのMinijob 2027ガイドでケース別に整理しました。収入上限だけでなく、他の仕事を含めた見込み収入も雇用主に伝えて確認してください。

3. ドイツチケットは月66.80ユーロに値上げ

全国の近距離公共交通が乗り放題になる「ドイツチケット（Deutschlandticket）」は、2027年1月から月66.80ユーロ（現在63ユーロ）に値上げされると報じられています。年間では約45ユーロの負担増です。

報道によると、連邦州の交通大臣会議（Verkehrsministerkonferenz）が2026年9月末に決定しました。料金はコスト指数に基づいて算定する方式になっており、2028年以降も見直しが続く見込みです。

チェックポイント

  • サブスクリプション契約の場合、多くは自動で新料金に切り替わります。解約する場合は各交通事業者の締め切りを確認しましょう。
  • Deutsche Bahn（DB）から購入した既存契約は、2026年11月30日までに新料金への同意が必要です（10月15日以降に注文した契約は申込時に新料金の案内を受けているため、別の同意は不要とされています）。手順は「Deutschlandticketは2027年66.80ユーロへ｜DB利用者は11月30日までに確認」で解説しています。
  • 会社のジョブチケット（Jobticket）経由で利用している方は、自己負担額が変わるか人事部に確認を。

4. 社会保険料の「算定上限」が上がる（高所得者ほど負担増）

社会保険料は、給与のうち各保険の保険料算定上限（Beitragsbemessungsgrenze）までを基礎に計算します。2027年の上限引き上げで影響を受けるのは、原則として2026年の上限をすでに超える給与を受け取っていた人です。連邦労働社会省（BMAS）は、被保険者の大多数には変化がないと説明しています。

2026年10月7日、連邦内閣は2027年の社会保険計算値令を閣議決定しました。2026年11月2日時点で、BMASの制度ページは連邦参議院（Bundesrat）の同意が必要と案内しており、正式な公布前です。施行予定日は2027年1月1日です。BMASによると、引き上げの影響を受けるのは従来の上限を超えていた人で、被保険者の大多数には変化がありません。

会社員として働く人が確認したいこと

  • 公的医療保険の一般加入義務上限は、保険料算定上限とは別の基準です。2027年は年84,150ユーロ（月7,012.50ユーロ）になる予定です。会社員の加入義務が年末で終了するかどうかは、当年と翌年の基準、および継続的な給与見込みなどで判定されます。基準を超えても自動的に民間保険へ移るわけではなく、条件を満たす人は公的保険の任意加入として残るか、民間保険へ移るかを選べます。民間保険から公的保険への復帰には厳しい条件があるため、保険料だけで決めず、保障内容と将来の選択肢を確認してください。
  • 医療保険の追加保険料率（Zusatzbeitrag）は保険組合ごとに異なります。平均値の意味や乗り換え条件は2027年の健康保険追加保険料率ガイドを、公的保険と民間保険の違いはドイツの健康保険ガイドを確認してください。

5. 児童手当の支給額引き上げは「まだ案」／申請なし支給は導入決定

2027年に向けた所得税改革（Einkommensteuerreform 2027）の政府案が、2026年9月に閣議決定されました。主な内容は次のとおりです。

  • 児童手当（Kindergeld）：子ども1人あたり月259ユーロ → 267ユーロ（2028年に272ユーロ）
  • 基礎控除（Grundfreibetrag）：12,348ユーロ → 12,564ユーロ（2028年に12,900ユーロ）
  • 被用者概算控除（Arbeitnehmer-Pauschbetrag）：1,230ユーロ → 1,430ユーロ
  • 家事・修理などの手工業者費用控除（Handwerkerbonus）：控除率20%・上限1,200ユーロ → 15%・上限900ユーロに縮小

この表の金額変更は、2026年10月27日時点で連邦議会・連邦参議院の最終承認を経ていない法案の内容です。金額や時期が変わる可能性があります。特に「Handwerkerbonus」は縮小方向の案なので、リフォームなどを予定している方は成立状況を見ながら支払時期を検討してください。

これとは別に、Kindergeldを申請なしで支給する手続きの改正は、連邦議会が2026年7月9日に可決し、連邦参議院も9月25日に同意しました。政府の公式案内では2027年1月1日施行予定で、実際の自動支給は2027年3月頃に第2子以降、11月頃に第1子へ段階的に広げる見込みです。ただし、第1子の段階では国内居住、既知のIBAN、少なくとも親の一人の国内就労などの条件があり、情報が不足する場合は従来どおり申請が必要になることがあります。支給日・番号末尾別の日程・条件はKindergeld 2027年の支給日一覧で確認してください。

6. 2027年中のその他の変更

  • EU域内の現金払い上限（2027年7月10日〜）：EUのマネーロンダリング対策規則により、事業者との取引で現金払いできるのは最大10,000ユーロまでになります。個人間の取引は対象外です。
  • 新しい私的年金制度：リースター年金（Riester-Rente）に代わり、ETFなどで運用できる国の補助付き「老後資産形成口座（Altersvorsorgedepot）」が2027年から始まる予定です。

まとめ：年末までにやっておきたいこと

  1. 給与明細を確認：最低賃金・ミニジョブ上限の変更が1月分の給与に反映されているか。
  2. ドイツチケットの契約を確認：値上げ後も継続するか、ジョブチケットの自己負担額はどう変わるか。
  3. 医療保険の通知をチェック：保険組合から届く2027年の追加保険料率のお知らせを見落とさない。
  4. 児童手当・税制は続報待ち：政府案の段階なので、成立を確認してから家計の計画に組み込む。
