# ドイツの銀行口座開設｜必要書類・選び方・Basiskonto

ドイツで長く暮らすなら、給与、家賃、保険料、公共料金に使う日常決済口座（Girokonto）を用意します。銀行ごとに必要書類と本人確認方法が異なるため、まず本人確認書類、ドイツの住所、住民登録証明などを準備し、月額料金だけでなくカード、ATM、現金入金、問い合わせ方法まで比較してください。通常口座を開けない場合は、条件を満たせば基本口座（Basiskonto）を申請できます。

## まず結論：渡独直後はこの順番で進める

1. 郵便を確実に受け取れる住所を整え、可能なら[住民登録](/germany/ja/living/anmeldung-guide/)を済ませる。
2. 日本のパスポート、住民登録証明、滞在資格、税務情報、電話・メールを準備する。
3. 支店が必要か、現金をどの程度使うか、毎月いくらまで払えるかを決める。
4. [BaFinの公的な口座比較](https://kontenvergleich.bafin.de/)で候補を絞り、各銀行の最新料金表と本人確認条件を確認する。
5. 口座開設後は少額でログイン、振込、カード、ATMを試し、給与や家賃の登録を順番に移す。

「無料」「英語対応」「アプリだけで開設」といった一つの条件だけで決めないでください。無料には入金条件が付くことがあり、日本のパスポートをオンライン本人確認で受け付けるかも、銀行と確認方法によって変わります。

## 口座開設に必要になりやすい書類

必要書類は銀行と口座商品で異なります。申込み前に銀行の公式ページで確認してください。

| 準備するもの | 確認するポイント |
| --- | --- |
| 有効な日本のパスポート | 氏名をパスポートのローマ字表記と完全にそろえる |
| ドイツの住所 | カード・暗証番号を受け取れるか。郵便受けに氏名があるか |
| 住民登録証明 | 必須でない銀行もあるが、登録後の方が選択肢は広がりやすい |
| ビザ・滞在許可証 | 国籍、滞在目的、確認方法により提示を求められることがある |
| 税務識別番号・税務上の居住国 | 番号が未着の場合に後日提出できるか確認する |
| 電話番号・メール | アプリ認証、本人確認、緊急連絡に使う |
| 収入・在学の証明 | 給与口座、学生向け条件、貸越などを希望する場合に求められることがある |

住民登録証明や税務識別番号がまだないことを自己判断で空欄にせず、「後日提出できるか」「別の商品なら申し込めるか」を確認します。渡独直後の準備全体は[最初の30日チェックリスト](/germany/ja/living/germany-first-30-days/)で確認できます。

![ドイツで書類を確認しながら生活口座を検討する日本人居住者](/assets/images/living/japanese-resident-paperwork-editorial-v1.webp "口座選びでは、毎月の費用と普段の使い方を先に整理したい")

## Girokontoとは：ドイツ生活で口座が必要になる理由

長く暮らす場合、銀行口座は単なる貯金場所ではなく、生活の連絡先に近い存在です。勤務先は給与の振込先を求め、家賃や電気・通信費は振込または口座引き落としで支払います。税金や保険料の還付、家族向け給付の受取にも口座番号を使います。

最初に用意するのは、日本の普通預金口座に近い**日常決済口座（Girokonto）**です。短期的には日本のカードや海外送金サービスでしのげても、ドイツでの収入と毎月の支出を一つの口座にまとめると、未払いの発見や住所変更も楽になります。貯蓄口座や証券口座とは役割が異なるため、まず日常の入出金を安定させます。

## 口座選びは「自分がどう使うか」から始める

銀行を比べるとき、最初に見るべきなのは広告の「無料」ではありません。給与が毎月入るか、現金を使うか、困ったときに窓口が必要かという日常の姿です。

| 自分の使い方 | 重視したい条件 |
| --- | --- |
| 渡独直後で手続きに不安がある | 対面窓口、本人確認の選択肢、問い合わせの分かりやすさ |
| スマートフォンで完結したい | アプリの言語、認証方法、障害時の連絡手段 |
| 現金をよく使う | 無料で使えるATM、現金を入金できる場所と費用 |
| 旅行や出張が多い | 海外決済、外貨手数料、ホテルやレンタカーで使えるカード |
| 夫婦で生活費を分けたい | 共同名義口座、追加カード、双方が明細を見られるか |

支店のある銀行は、書類の不足やカードの受取トラブルを人に相談しやすい一方、口座維持費がかかることがあります。オンライン銀行は費用を抑えやすい反面、本人確認に失敗したときやスマートフォンを紛失したときの復旧方法まで確認しておく必要があります。

公的な比較をしたい場合は、ドイツ連邦金融監督庁（BaFin）の[口座比較サービス](https://kontenvergleich.bafin.de/)を使えます。GirokontoとBasiskontoを、口座維持費、カード、振込、現金の取扱いなど同じ軸で比較できます。最終判断では比較結果から各銀行の公式料金表へ進み、申込条件と更新日を確認してください。

### 支店型とオンライン型の比較

| 比較軸 | 支店型が合いやすい人 | オンライン型が合いやすい人 |
| --- | --- | --- |
| 本人確認 | 対面で書類を見てもらいたい | 対応書類を確認済みでスマートフォンで進めたい |
| 問い合わせ | 店舗で相談したい | チャット・電話・メールで解決できる |
| 現金 | 入出金の機会が多い | 現金入金をほとんどしない |
| 費用 | 窓口やATM網に料金を払う価値がある | 条件を満たして固定費を抑えたい |
| 復旧 | 端末紛失時に店舗を使いたい | 予備の連絡手段や復旧手順を自分で管理できる |

特定の銀行名を先に決めるより、生活圏のATM、対応言語、本人確認、現金入金、端末紛失時の復旧という順に候補を減らす方が失敗を避けやすくなります。

## 「無料口座」で見落としやすい費用

無料と表示された口座でも、毎月一定額の入金、学生などの年齢条件、オンライン利用といった条件が付く場合があります。申し込む前に、銀行が公開する料金表を保存しておくと、後から条件を確認できます。

特に比べたいのは次の費用です。

- 毎月の口座維持費と無料になる条件
- デビットカードや追加カードの年会費
- 自行以外のATMで現金を下ろす費用
- 現金を入金する費用
- ユーロ以外で支払うときの手数料
- 残高を超えて借りる機能の金利
- 紙の振込や明細を依頼する費用

月額料金が少し高くても、近所のATMや窓口を頻繁に使う人には結果的に安いことがあります。逆に、ほぼカード払いで現金を入れない人は、支店の多さに料金を払う必要がないかもしれません。

## カードと現金は両方を想定する

口座に付く**デビットカード**は、支払額が銀行口座から直接引かれるカードです。国際ブランド付きデビットカードはオンライン購入や旅行で使いやすい一方、ドイツ国内ではGirocardには対応し、国際ブランドのカードを受け付けない小規模店もあります。カード名だけで判断せず、発行されるカードの種類と年会費を確認してください。

ドイツではカード決済が広がっていますが、週末市場、小さな飲食店、地方の店舗などでは現金が役立ちます。最初から多額の現金を持つ必要はありませんが、普段利用する地域に無料ATMがあるか、必要なら現金を口座へ戻せるかを確かめておくと安心です。

ホテルやレンタカーでは、デビットカードが保証金用カードとして認められないことがあります。旅行が多い人は、口座付帯カードとは別に、利用条件を確認したクレジットカードを持つ選択肢もあります。

## 本人確認で止まったときの確認順

本人確認には、ビデオ通話、郵便局、支店、電子身分証などが使われます。オンラインで失敗しても「日本人は開設できない」とは限りません。次の順で切り分けます。

1. 氏名、生年月日、住所が証明書と一致しているか確認する。
2. 使用中の日本のパスポートが、その本人確認方法の対応書類に含まれるか確認する。
3. 光の反射、通信、カメラ、読み取り不良など技術的な原因を除く。
4. 郵便局や支店など別の確認方法へ変更できるか聞く。
5. 同じ申込みを繰り返す前に、不足書類と再申込条件を確認する。

氏名はパスポートのローマ字表記に合わせます。銀行カードや暗証番号が別々の郵便で届くこともあるため、郵便受けに自分の名前を表示しておくことが重要です。

本人確認の対応国・書類は変わります。個人ブログの成功例だけを根拠にせず、銀行が現在示している対応書類と問い合わせ回答を優先してください。

## 口座を開いた後、生活とどうつなぐか

![ドイツの銀行口座を暮らしの支払いへつなぐ考え方](/assets/images/living/bank-account-choice.svg "給与、家賃、現金、カードという日常の流れで口座を考える")

口座番号が発行されたら、まず少額を入金し、アプリへのログインとカード決済を試します。そのうえで、給与、家賃、健康保険、電気、通信など、生活に欠かせない順に登録します。

毎月同額の家賃は定額の自動振込、請求額が変わる電気や通信費は口座引き落としがよく使われます。引き落としは便利ですが、残高不足になると未払いと手数料につながるため、支払日の前後に通知を設定しておくと管理しやすくなります。

ドイツ以外のEU加盟国のIBANでも、SEPA送金の受取や口座引き落としに使えるのが原則です。口座の国だけを理由に拒否される問題は**IBAN discrimination**と呼ばれます。拒否された場合は相手先へ書面で理由を確認し、必要に応じて[欧州委員会が案内する各国の相談先](https://finance.ec.europa.eu/consumer-finance-and-payments/payment-services/payment-services/iban-discrimination_en)を確認してください。

夫婦やパートナーの場合、すべてのお金を最初から共同口座へ集める必要はありません。各自の口座を持ち、家賃や食費だけを共同口座から出す方法なら、日常費と個人費を分けやすくなります。

## Basiskonto：通常の口座を開けなかったとき

住所確認や本人確認、銀行独自の審査などにより、通常口座の申込みが断られることがあります。まず入力した氏名・住所が証明書と一致しているかを確認し、可能なら別の本人確認方法や別の銀行を検討します。

EU域内に合法的に滞在し、ドイツで利用できる支払い口座をまだ持っていない人には、一定の条件で**基本口座（Basiskonto）**を申し込む権利があります。これは入出金、振込、口座引き落とし、カード払いなど、暮らしに必要な基本機能を備える口座です。ただし、残高を超えて借りる機能やクレジットカードが必ず付くわけではなく、無料とも限りません。

通常のGirokontoへの申込みと、Basiskontoとしての正式な申請は分けて考えます。基本口座を希望する場合は、Basiskontoとして申請したことが分かる書類の控えを残してください。断られた場合は理由が書かれた通知を保管し、[BaFinの案内](https://www.bafin.de/DE/Verbraucher/Bank/Produkte/Basiskonto/basiskonto_node.html)で申立ての対象になるかを確認します。

## 預けたお金を守る仕組み

ドイツの法定預金保護では、対象となる預金は原則として一人・一銀行あたり10万ユーロまで保護されます。銀行名とアプリのサービス名が違う場合は、実際に預金を預かる銀行と、どの国の制度が適用されるかを確認します。

この保護は銀行預金のためのもので、株式、投資信託、暗号資産の値下がりを補う制度ではありません。大きな資金を置く場合は、[ドイツ連邦銀行の預金保護解説](https://www.bundesbank.de/en/tasks/financial-supervision/individual-aspects/deposit-protection-622748)で範囲を確認してください。

## 渡独直後の現実的な順番

1. 郵便を受け取れる住居と郵便受けの表示を整える
2. 住民登録を行い、発行された書類を保管する
3. 支店の必要性、現金の頻度、毎月の費用という三つの条件を決める
4. 公的比較サイトと各行の料金表で候補を二つ程度に絞る
5. 本人確認を済ませ、口座とカードを少額で試す
6. 給与と家賃から順に支払い先を移す
7. 一か月使った後、通知、ATM、手数料が生活に合うか見直す

最初から貯蓄口座や証券口座までそろえる必要はありません。まず毎日の入出金が安定する口座を一つ作り、生活が落ち着いてから目的別に増やす方が分かりやすいでしょう。

## よくある疑問

### 住民登録前でも開設できますか

銀行によって異なります。住民登録証明を必須にしない銀行もありますが、カードを受け取れる住所と本人確認は必要です。給与開始が迫っていなければ、住民登録後の方が選択肢は広がります。

### 日本のパスポートだけで開設できますか

一律には言えません。口座商品と本人確認方法によって、住民登録証明、滞在許可証、税務情報などを追加で求められます。「以前は開設できた」という体験談ではなく、申込時点の対応書類を確認してください。

### 日本のカードだけで生活できますか

旅行中は可能でも、給与、家賃、保険料、税金の還付などを考えると長期生活には不向きです。日本のカードは、ドイツの口座やカードが使えないときの予備として残すと役立ちます。

### 信用情報がまだなくても開設できますか

日常決済だけの口座と、借入れやクレジット機能の審査は同じではありません。渡独直後は、貸越やクレジットカードを付けず、入金した範囲で使う口座から始めるのが現実的です。信用情報については[ドイツの信用情報ガイド](/germany/ja/living/schufa-guide/)で詳しく説明しています。

### 銀行でのドイツ語が不安です

この記事では制度と選び方を日本語で説明しています。窓口や問い合わせで使う短い表現は、[銀行口座のドイツ語](/germany/ja/learn-german/bank-account-phrases/)に分けて掲載しています。

### ドイツ以外のEU口座を給与や引き落としに使えますか

SEPAの対象口座なら、IBANの国だけを理由に送金・引き落としを拒否することは認められていません。実際に拒否された場合は、相手先へ理由と修正を求め、記録を残します。口座サービス自体の機能、通貨、手数料、本人確認条件は別に確認してください。

## 申込み直前の比較チェックリスト

- 毎月の口座維持費と、無料になる条件
- デビットカード・Girocard・追加カードの有無と料金
- 普段使うATMでの引出し条件
- 現金入金の場所、回数、費用
- ユーロ以外の決済・引出し手数料
- 本人確認で使える日本の書類と代替手段
- 問い合わせ言語、受付時間、緊急停止の方法
- スマートフォン紛失・番号変更時の復旧手順
- 実際に預金を預かる銀行と預金保護制度
- 解約方法と残高・定期振込の移し方

## まとめ

ドイツの銀行口座は、銀行名や広告の無料表示よりも、自分の暮らしに必要な機能で選びます。必要書類、本人確認、現金、カード、問い合わせ、郵便の受取まで比較し、BaFinの公的比較と銀行の最新料金表を併用してください。通常口座を開けない場合にもBasiskontoという制度があるため、申請と拒否理由を記録しながら次の選択肢へ進みます。
