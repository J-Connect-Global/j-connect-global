# ドイツで仕事を辞めるときの解約の期間｜原則4週間、試用期間は2週間、退職届は「手書きの署名」が必要

転職が決まった、日本に帰ることになった、あるいは会社から突然、解雇を告げられた。仕事が終わるときには、いつまで働くのか、どんな手続きが必要なのかが気になります。

ドイツでは、法律で決まった解約の期間と、書面で通知するというルールを守る必要があります。試用期間中の扱いと、仕事が終わる前に職業安定所に届け出る期限もあわせて説明します。日本の会社とは違う点も多いので、辞めると決める前に確認しておきましょう。

## 解約の期間は原則「4週間」

ドイツの民法では、働く人も会社も、労働関係を**4週間の期間を置いて、月の15日か月末に**解約できると決めています（[民法 第622条](https://www.gesetze-im-internet.de/bgb/__622.html)）。

たとえば、10月29日に退職の通知を出した場合、4週間後は11月26日です。この後で一番近い「15日か月末」は11月30日なので、11月30日付けで仕事が終わる計算になります。

ただし、労働契約や労働協約で、もっと長い期間（たとえば3か月）を決めていることがよくあります。まずは**自分の労働契約を確認**しましょう。

### 試用期間中は「2週間」

試用期間（Probezeit）中は、どちらからでも**2週間の期間**で解約できます。試用期間は最長6か月までです（[民法 第622条](https://www.gesetze-im-internet.de/bgb/__622.html)）。この場合は、「15日か月末」に合わせる必要はありません。

## 会社から解約する場合は、勤めた年数で長くなる

会社から解約する場合は、働いた年数が長いほど、解約の期間が長くなります（[民法 第622条](https://www.gesetze-im-internet.de/bgb/__622.html)）。

| 勤めた年数 | 会社から解約するときの期間 |
| --- | --- |
| 2年 | 1か月（月末付け） |
| 5年 | 2か月（月末付け） |
| 8年 | 3か月（月末付け） |
| 10年 | 4か月（月末付け） |
| 12年 | 5か月（月末付け） |
| 15年 | 6か月（月末付け） |
| 20年 | 7か月（月末付け） |

この長い期間は、法律では会社から解約する場合のものです。ただし、契約で、働く人から辞める場合の期間を会社より長くすることはできません（[民法 第622条](https://www.gesetze-im-internet.de/bgb/__622.html)）。

## 退職の通知は「紙に手書きの署名」

ここは特に注意が必要です。労働関係の解約は、**紙に書いて、自分で手書きの署名をした書面**で出す必要があります（[民法 第623条](https://www.gesetze-im-internet.de/bgb/__623.html)）。

メール、チャット、SMS、スキャンしたPDFでは、解約として認められません。会社から解約を告げられる場合も同じで、メールだけで届いた解雇の通知は無効です。

退職の通知を出すときは、

- 名前、日付、「労働関係を解約します」という内容、いつ付けで辞めるのかを書く
- 手書きで署名する
- 上司や人事に**直接手渡しし、受け取ったことの署名をもらう**か、届いたことが分かる方法で送る

のが確実です。

## 解雇を告げられたら「3週間」が大切

会社から解雇を告げられ、その解雇に納得できない場合は、**解雇の通知を受け取ってから3週間以内**に、労働裁判所に訴えを起こす必要があります（[解雇保護法 第4条](https://www.gesetze-im-internet.de/kschg/__4.html)）。この期間を過ぎると、原則として解雇は有効なものとして扱われます。

解雇を告げられたら、まずは労働法の専門家（弁護士）や、加入していれば労働組合に早めに相談しましょう。

## 仕事が終わる前に、職業安定所へ届け出る

次の仕事が決まっていない場合は、**職業安定所（Agentur für Arbeit）に求職者として届け出る**必要があります。期限は次のとおりです（[連邦雇用エージェンシー](https://www.arbeitsagentur.de/arbeitslos-arbeit-finden/arbeitslosengeld/ihre-schritte-wenn-sie-arbeitslos-werden/wie-sie-sich-arbeitsuchend-melden)）。

- 仕事が終わる日が**3か月以上先**に分かっている場合：遅くとも**3か月前**まで
- 仕事が終わる日まで3か月ない場合：仕事が終わると分かってから**3日以内**

届け出が遅れると、失業手当が1週間止められること（Sperrzeit）があります（[連邦雇用エージェンシー](https://www.arbeitsagentur.de/arbeitslos-arbeit-finden/arbeitslosengeld/ihre-schritte-wenn-sie-arbeitslos-werden/wie-sie-sich-arbeitsuchend-melden)）。届け出はオンラインでもできます。

## 外国籍の人が気をつけたいこと

滞在許可が仕事と結びついている場合（EUブルーカードや、特定の仕事のための滞在許可など）は、仕事が変わったり終わったりすることで、滞在許可に影響が出ることがあります。転職や退職が決まったら、**早めに外国人局（Ausländerbehörde）に確認**しましょう。滞在許可の更新については「[ドイツの滞在許可の更新](/germany/ja/living/residence-permit-renewal-germany/)」で紹介しています。

残っている有給休暇の扱いは「[残った有給休暇は年末で消える？](/germany/ja/events/columns/unused-vacation-days-germany/)」でまとめています。
