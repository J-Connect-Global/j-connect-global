# ドイツの最低賃金2027｜時給14.60ユーロの対象者・例外・給与明細の確認方法

ドイツの一般法定最低賃金は、2026年は時給13.90ユーロ、2027年1月1日から14.60ユーロ（いずれも税・社会保険料を引く前の総支給額）になります。ドイツで雇用されて働く日本人にも、国籍やフルタイム・パートタイムの違いを理由に適用を外すことはできません。この記事では、対象者と例外、月給への換算、給与明細の確認、賃金不足が疑われるときの対応を整理します。

<text>確認日：2026年11月13日。2027年の金額は、すでに公布された連邦法令に基づくものです。</text>

## まず結論

| 期間 | 一般法定最低賃金（総支給額） | 適用開始 |
| --- | ---: | --- |
| 2026年 | 時給13.90ユーロ | 2026年1月1日 |
| 2027年 | 時給14.60ユーロ | 2027年1月1日 |

- 2027年の14.60ユーロは、提案段階ではありません。第5次最低賃金調整令に明記された金額です。
- 原則として、ドイツ国内で雇用されるフルタイム、パートタイム、ミニジョブ、季節労働の従業員に関係します。外国籍であることや、雇用主が国外にあることだけで適用対象から外れるわけではありません。
- 金額は手取りではなく、税金・社会保険料を引く前の総支給額です。
- 職業訓練や一部のインターンなど、法律上の例外があります。
- 業種別の賃金下限や労働協約が、一般最低賃金より高い場合があります。

## 14.60ユーロは法令で決まった金額

第5次最低賃金調整令は2025年11月5日付で公布され、2026年1月1日に施行されました。同令第1条は、2026年を13.90ユーロ、2027年1月1日からを14.60ユーロと定めています。したがって、2027年の金額を「検討中」「予定」と表現するのは正確ではありません。

一般最低賃金の権利は最低賃金法第1条に定められています。雇用主が支払うべき最低額は、実際の労働時間と賃金の扱いを踏まえて確認します。

## 誰に適用される？

最低賃金法は、原則として労働者に適用されます。連邦労働社会省は、国籍や雇用形態の規模にかかわらず、ドイツで働く外国籍の従業員、季節労働者、ミニジョブの従業員にも適用されると説明しています。

| 働き方 | 一般最低賃金の扱い |
| --- | --- |
| フルタイム・パートタイム | 原則として対象 |
| ミニジョブ | 対象。月収上限とは別に、時給の最低額を守る必要がある |
| 学生アルバイト・ワークスチューデント | 雇用される従業員であれば原則対象 |
| 季節労働 | 原則として対象 |
| 職業訓練（Ausbildung） | 一般最低賃金ではなく、別の最低訓練手当の制度が適用される |
| 法律上の例外に該当するインターン | 条件を満たす場合は対象外 |

ミニジョブの月額上限は2027年に633ユーロへ上がりますが、これは最低賃金とは別の制度です。勤務時間や掛け持ち、税金・保険は[ミニジョブの2027年ガイド](/germany/ja/living/minijob-grenze-2027/)で確認してください。学生の働き方は[ワークスチューデント・ミニジョブ・インターンの比較](/germany/ja/living/werkstudent-student-jobs-germany/)も参考になります。

## 月給の場合はいくらになる？

月給制でも、最低賃金は時間単位で確認します。週40時間の勤務を1年52週で平均し、12か月に割ると、2027年の月額換算は次のようになります。

| 週の労働時間 | 2027年の月平均労働時間 | 最低賃金での月平均総支給額 |
| ---: | ---: | ---: |
| 40時間 | 約173.33時間 | 約2,530.67ユーロ |
| 30時間 | 約130時間 | 1,898ユーロ |
| 20時間 | 約86.67時間 | 約1,265.33ユーロ |

計算式は「時給14.60ユーロ × 週の労働時間 × 52 ÷ 12」です。これは年間を通じて同じ週労働時間で働く場合の平均値であり、各月の実際の勤務日数や残業、賃金項目によって確認額は変わります。月給が固定されている場合は、連邦労働社会省の[最低賃金計算ツール](/)で時給換算を確認できます。

**注意：** 2,530.67ユーロは手取り額ではありません。所得税、教会税（該当する場合）、年金・健康・介護・失業保険料などが差し引かれます。また、すべての手当や賞与が最低賃金の計算に含まれるわけではありません。賃金項目の扱いに迷う場合は、公式計算ツールと雇用契約を照らし合わせてください。

## 最低賃金の例外

最低賃金法第22条には、適用対象から外れるケースが定められています。契約書に「インターン」と書いてあるだけで例外になるわけではなく、実際の内容と期間が重要です。

| ケース | 一般最低賃金の扱い |
| --- | --- |
| 18歳未満で、職業訓練を修了していない人 | 原則として対象外 |
| 職業訓練を受けている人 | 一般最低賃金ではなく、最低訓練手当の制度 |
| 学校・大学の規則や訓練規則で必修とされるインターン | 対象外 |
| 進路選択のための3か月以内のインターン | 条件を満たせば対象外 |
| 大学・職業訓練に付随する3か月以内の任意インターン | 同じ雇用主のもとで以前に同種のインターンをしていない等の条件を満たせば対象外 |
| 就業直前に長期失業者だった人 | 雇用開始後の最初の6か月は対象外となる場合がある |
| 自営業者・ボランティア | 雇用される労働者ではないため、原則として最低賃金法の対象外 |

長期失業者の例外は、雇用開始の直前に法律上の長期失業者に該当していた場合に限られます。インターンの例外は、学校・大学の必修か、任意か、期間が3か月以内か、同じ雇用主で過去に同じ種類のインターンをしていないかを確認してください。

## 業種別の賃金下限は14.60ユーロより高いことがある

一般最低賃金は最低ラインです。法律や労働協約によって、特定の業種・働き方にさらに高い賃金下限が設定されている場合があります。

例えば、派遣労働の賃金下限は、連邦労働社会省の一覧では2026年9月1日から時給15.33ユーロ、2027年4月1日から15.87ユーロとされています。これは派遣労働の対象者に限る金額で、すべての従業員に適用される一般最低賃金ではありません。自分の業種に別の下限があるかは、[連邦労働社会省の業種別一覧](https://www.bmas.de/DE/Arbeit/Arbeitsrecht/Mindestlohn/Branchenmindestlohn/Branchenmindestlohn-art.html)で確認してください。

## 給与明細を確認する手順

1. **契約書を確認する。** 時給か月給か、週の所定労働時間、残業の扱い、給与の支払日を確認します。
2. **実際の労働時間を記録する。** シフト表、勤務開始・終了時刻、休憩、残業を月ごとに残します。
3. **総支給額を時間で割る。** 月給制なら、固定月給と週の労働時間から平均時給を計算し、実際の労働時間とも照らし合わせます。
4. **手当の扱いを確認する。** すべての手当や賞与が最低賃金の計算に含まれるとは限りません。自己判断せず、公式計算ツールや専門窓口を使います。
5. **不明点を会社に書面で確認する。** 給与担当者に計算根拠を尋ね、回答と給与明細を保存します。

ミニジョブや特定業種では、法律上、勤務開始・終了・労働時間の記録義務があります。対象となる雇用では、原則として勤務日の翌日から7日目までに記録し、少なくとも2年間保存する必要があります。すべての会社員に同じ記録方式が適用されるわけではないため、対象範囲は公式の[記録義務の説明](https://www.bmas.de/DE/Arbeit/Arbeitsrecht/Mindestlohn/Dokumentationspflicht/dokumentationspflicht-art.html)で確認してください。

## 賃金が最低額を下回ると思ったら

- 契約書、給与明細、シフト表、勤務記録、会社とのメールを保存します。
- まず会社の給与担当者に、対象期間・労働時間・計算方法を示して書面で確認します。
- 解決しない場合は、労働組合、従業員代表、労働相談窓口、労働法を扱う弁護士などに相談します。
- 最低賃金法第3条では、最低賃金を下回る合意や請求を制限する合意は原則として無効です。契約に書いてあるからといって、当然に権利を失うわけではありません。

最低賃金の支払日は、契約上の支払日が定められていればその日です。別の合意がない場合でも、法律上は原則として労働した月の翌月の最終銀行営業日までに支払う必要があります（最低賃金法第2条）。書面で合意した労働時間口座などには別の条件があるため、残業の精算が遅れている場合は契約と記録を確認してください。

## よくある質問

### 日本国籍でもドイツの最低賃金は適用されますか？

ドイツ国内で雇用されて働く場合、国籍だけを理由に適用対象から外れることはありません。外国籍の従業員や、一定の条件で国外に本店がある雇用主の従業員にも関係します。ただし、就労できる滞在資格があるかどうかは別に確認が必要です。

### 14.60ユーロは手取りですか？

いいえ。税金や社会保険料を差し引く前の総支給額です。実際の手取りは税区分、家族状況、保険料率、教会税の有無などで異なります。

### ミニジョブでも14.60ユーロを受け取れますか？

一般最低賃金の対象となるミニジョブなら、2027年1月1日以降は原則として時給14.60ユーロ以上が必要です。月633ユーロの収入上限は別の制度で、働ける時間の上限を考えるときに両方を確認します。

### 必修インターンにも最低賃金は必要ですか？

学校や大学の規則などで必修とされるインターンは、最低賃金法第22条の例外に該当します。任意インターンは、目的・期間・同じ雇用主での過去の実施歴によって扱いが変わります。
