# ドイツの2022年分の所得税申告｜任意申告の期限は2026年12月31日

ドイツで所得税申告の義務がない人が2022年分を任意に提出する場合、ノルトライン＝ヴェストファーレン州税務当局の案内では、期限は**2026年12月31日**です。これはすべての納税者に共通する期限ではなく、義務申告が必要な人には別の期限とルールが適用されます。この記事では、自分が任意申告に該当するかを確認し、提出までに必要な書類と手順を整理します。

## 先に確認：任意申告か、義務申告か

最初に、自分が「申告したい人」なのか、「法律上、申告しなければならない人」なのかを確認してください。4年間の期限は、申告義務がない人が還付などを求めて任意に申告する場合の案内です。義務申告の期限を過ぎた場合に、同じ4年間の猶予があるとは限りません。

| 状況の例 | まず確認すること |
| --- | --- |
| 給与を受け、通常は給与税が差し引かれていた | 申告義務がある事情がないか確認したうえで、任意申告の可能性を調べる |
| 同時に複数の勤務先から給与を受け、税クラスVIが使われた | 義務申告に該当する可能性がある |
| 夫婦で税クラスIII/V、またはIV・要素方式を利用している | 夫婦の就労状況などにより義務申告となる場合がある |
| 給与から源泉徴収されていない所得が年間410ユーロを超えた | 義務申告の対象か確認する |
| 失業給付、傷病手当、育児手当、母性手当などの賃金代替給付を年間410ユーロ超受けた | 義務申告の対象か確認する |
| 税務上の控除額を給与税の計算に登録した | 申告義務の例外に当たらないか確認する |

これは主な例であり、完全な一覧ではありません。収入の種類、婚姻状況、税クラス、外国所得、税務上の居住地などによって結論が変わります。迷う場合は、税務当局の公式案内や税理士に確認してください。

## 2022年分の任意申告は、なぜ2026年末が期限？

州税務当局のFAQは、申告義務がない人が任意に申告する場合、対象年の後の4年間に提出できると説明しています。同じ案内で、**2022年分は2026年12月31日まで**と明示されています。

この日付は、2022年分の任意申告に関する期限です。2025年分や2026年分の期限を意味するものではありません。また、義務申告をしなければならない人が、未提出の申告を任意申告として扱えるという意味でもありません。

## 還付の可能性がある人が、先に集めたい書類

還付があるかどうかは個々の収入・控除・すでに納めた税額によって決まり、申告しただけで必ずお金が戻るわけではありません。2022年にドイツで働いた人は、まず次の資料を探してください。

- **給与所得の証明書：** 2022年に働いた各勤務先からの年次給与税証明書
- **通勤・在宅勤務・仕事関連の支出：** 対象年の通勤日数、仕事用機器、研修などの記録
- **保険料や寄付などの資料：** 税務フォームの該当欄に関係する証明書
- **子どもや家族に関する資料：** 該当する場合の保育費や扶養関係の記録
- **特別な支出：** 医療費、家事サービスなど、控除の対象となる可能性がある支出の記録

ここに挙げた費用がすべて控除できるわけではありません。支出の種類、金額、証明方法、他の制度で補填されたかなどにより扱いが異なります。申告書に記載する前に、ELSTERの説明や税務専門家の案内で要件を確認してください。

## ELSTERで提出する手順

### 1. 電子申告のアカウントを確認する

ELSTERは、ドイツの税務当局が提供する電子申告サービスです。アカウントがない場合は、登録と本人確認に時間がかかることがあります。期限直前に初めて登録するのではなく、早めに利用可能か確認してください。

### 2. 2022年分の申告フォームを選ぶ

申告する年を間違えないよう、対象年が2022年になっていることを確認します。複数の勤務先があった場合や、夫婦で共同申告する場合は、必要な情報がすべてそろっているか確認してください。

### 3. 証明書と申告内容を照合する

給与証明書の金額、銀行口座、住所、勤務期間、家族情報などを確認します。過去の情報が自動入力される場合も、2022年当時の状況と一致するとは限りません。入力内容を一つずつ確認してください。

### 4. 期限前に送信し、受付記録を保存する

下書きを作成しただけでは提出したことになりません。送信を完了し、電子申告の送信記録や受付情報を保存してください。12月31日ぎりぎりまで待たず、アカウントや書類の不足があれば早めに対処するのが安全です。

## 証憑はすべて最初から添付する必要がある？

税務当局の案内では、一般に証憑は申告書と一緒にすべて提出するのではなく、問い合わせに備えて保管しておく扱いです。ただし、特別な事情がある場合や税務当局から求められた場合には、書類の提出・提示が必要になることがあります。申告内容を説明できるよう、証明書と計算の根拠は整理しておいてください。

## 義務申告の期限とは違う

比較のために、州税務当局が案内する2025年分の義務申告期限も確認しておきます。原則として自分で申告する場合は2026年7月31日、税理士などの支援を受ける場合は2027年3月1日と案内されています。これは2022年分の任意申告期限とは別の制度です。

2022年分を任意に申告するつもりでも、実際には義務申告の対象だった場合は、通常の任意申告の4年ルールだけを根拠に判断しないでください。提出が遅れている場合は、放置せず税務当局や税務専門家に相談してください。

## よくある質問

### 2022年分は12月31日に郵送すれば間に合いますか？

期限は対象年の任意申告を提出する期限です。郵送の消印だけで間に合うと自己判断せず、提出方法ごとの要件を公式案内で確認してください。電子申告を使う場合は、送信完了と受付記録を確認します。

### 申告すれば必ず税金が戻りますか？

いいえ。還付があるかは、実際の所得、給与から差し引かれた税額、控除対象となる支出などで変わります。申告をしても還付がない場合や、状況によっては追加納税が生じる場合があります。

### 税務IDが分からない場合は？

まず[ドイツの税務識別番号・税務署番号・給与税区分の違い](/germany/ja/living/tax-id-steuernummer-steuerklasse/)を確認してください。税務識別番号と税務署の管理番号は別のものです。
