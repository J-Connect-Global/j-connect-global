# 書類解説・フォーム補助のAPIコスト制御

この文書は、Apps Script版の書類解説・フォーム補助ツールを再デプロイする前のコスト設定を記録する。リポジトリへの変更だけでは本番Apps Scriptは更新されない。

## 安全側の既定値

| Script Property | 既定値 | 意味 |
| --- | --- | --- |
| `WEB_SEARCH` | `off` | チャットのWeb検索を無効にする。検索APIの追加利用を避ける |
| `HEAVY_EFFORT` | `medium` | 手紙解説・フォーム補助の推論強度 |
| `REASONING_EFFORT` | `low` | 通常ツールの推論強度 |
| `DAILY_LIMIT` | `200` | 全ツール合計の1日リクエスト上限 |
| `BURST_LIMIT` | `20` | 全ツール合計の10分あたりリクエスト上限 |

`WEB_SEARCH=on` は明示的なオプトインとする。Web検索は通常の回答に比べて追加のAPI利用を生む可能性があるため、費用を確認してから有効にする。`HEAVY_EFFORT=high` も必要性と利用量を確認してから明示的に設定する。リクエスト上限は金額上限ではない。

## 再デプロイ前の手順

1. Apps Scriptの認証済み管理画面で、既存の書類解説プロジェクトを開く。
2. リポジトリの `apps-script/letter-explainer/Code.gs` を反映する。
3. Script Propertiesを確認する。追加費用を避ける場合は `WEB_SEARCH` を未設定または `off`、`HEAVY_EFFORT` を未設定または `medium` にする。
4. 既存Webアプリのデプロイを編集し、新しいバージョンを作成する。URLを変更しない。
5. 非機密のテスト文書で通常回答・書類解説・フォーム補助を確認する。実際の送信や個人情報を含む書類では試験しない。

## 現在の制約

このリポジトリ接続からApps Script管理画面・Script Properties・本番デプロイ履歴にはアクセスできない。したがって、この変更はソース上の安全設定であり、本番に反映済みとは扱わない。デプロイには管理画面での認証と手動操作が必要。
