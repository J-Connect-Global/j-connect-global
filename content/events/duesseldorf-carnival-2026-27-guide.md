# デュッセルドルフのカーニバル2026/27｜ホッペディッツの目覚めから、風刺の山車が進むバラの月曜日まで

デュッセルドルフのカーニバルは、2026年11月11日（水）、市庁舎前で道化の「ホッペディッツ」が目を覚ますところから始まり、2027年2月4日から10日にかけて街頭で最高潮を迎えます。デュッセルドルフやその近くで暮らす人、特に初めてこの街のカーニバルを見る人向けに、どの日に何があり、どこにこの街らしさがあるのかを紹介します。今季のモットーと日程、旧市街のガラス瓶の持ち込み禁止など、出かける前に知っておきたい公式情報もまとめました。

11月11日に始まる理由や、掛け声「ヘラウ」と「アラーフ」の違いは、コラム「[なぜカーニバルは11月11日11時11分に始まる？](/germany/ja/events/columns/rhineland-carnival-11-11/)」で説明しています。この記事では、2026/27年のデュッセルドルフでの楽しみ方に絞ります。

## 風刺と社交の街のカーニバル

デュッセルドルフのカーニバルをまとめているのは、1825年に創立されたデュッセルドルフ・カーニバル委員会（Comitee Düsseldorfer Carneval、略称CC）です。市内のカーニバル団体が加わる上部団体で、11月の開幕から2月の行列まで、主な行事を主催しています（[CC：2026/27年シーズンの催し](https://www.helau.cc/de/pages/veranstaltungen-3)）。

2026/27年シーズンのモットーは「Karneval – grenzenlos vereint」。「カーニバル――境界を越えて、ひとつに」という意味です。シーズンの顔は、王子と「ヴェネツィア」（Venetia）と呼ばれる女性の二人組で、今季はイェンスとヴァレリーの二人が務めます。ケルンが王子・農夫・乙女の三人組なのに対し、デュッセルドルフは男女の二人組。隣り合う街でも、カーニバルの形はこれだけ違います。

二人組は、2026年11月13日（金）にライン川沿いの会場ラインテラッセで開かれる式典で正式に選ばれます（有料、CCの案内では19時から）。

## 11月11日（水）：マスタードの壺から目覚める道化

デュッセルドルフのシーズン開幕は、市庁舎前のマルクト広場で行われる「ホッペディッツの目覚め」（Hoppeditz-Erwachen）です。CCによると、2026年は11月11日（水）、11時から広場でプログラムが始まり、入場は無料です。夕方17時30分からは、同じ広場で夜の催しも予定されています（[CC：11月11日の案内](https://www.helau.cc/de/News/231,am-1111-erwacht-unser-hoppeditz-in-dusseldorf)）。

11時11分、ホッペディッツはマスタードの壺から這い出して、長い眠りから目を覚まします（[デュッセルドルフ観光局](https://www.visitduesseldorf.de/event/hoppeditz-erwachen-f5ee3197a3)）。そして始まるのが、市政や街の出来事を遠慮なく皮肉る演説です。市長も市庁舎のバルコニーから言い返すのが恒例で、2025年には平日にもかかわらず、広場と旧市街の路地に多くの仮装した人が集まりました（[デュッセルドルフ市：2025年の様子](https://www.duesseldorf.de/medienportal/pressedienst-einzelansicht/pld/karneval-in-duesseldorf-der-hoppeditz-ist-erwacht-2)）。

### ホッペディッツとは何者か

CCによると、ホッペディッツは19世紀に生まれた風刺の道化で、赤と白の衣装にとがった帽子、いたずらっぽい笑顔がトレードマークです。権力者に鏡を突きつけ、ユーモアと皮肉で人々に考えさせる役目を持っています（[CC：ホッペディッツ](https://www.helau.cc/de/pages/hoppeditz)）。

名前の由来ははっきりしていません。CCは、「跳ねる」を意味する言葉と、「小さな子ども」を意味する言葉を合わせた「跳ねまわる子ども」とする説などを紹介しています。1841年には、今のカールス広場（当時は「ホッペディッツ広場」）に、デュッセルドルフ美術アカデミーゆかりの画家たちが描いた像が建てられました。今は2008年に作られた新しい像が、旧市街のカーニバル博物館の裏に立っています。

子ども向けには、11月14日（土）11時11分から、旧市街のランベルトゥス広場で「子どものホッペディッツの目覚め」も開かれます（入場無料）。

## 2月4日〜10日：街頭のカーニバル

年明けの1月7日には、CCのテレビ中継されるシッツング（Sitzung、歌や漫談、ダンスの舞台）が開かれ、2月に入ると街頭のカーニバルが始まります。CCが発表している2027年の主な日程は次のとおりです（[CC：2026/27年シーズンの催し](https://www.helau.cc/de/pages/veranstaltungen-3)）。

| 日にち | 出来事 |
| --- | --- |
| 2027年2月4日（木）11時11分 | 女性のカーニバルの日（Altweiber）。女性たちが市庁舎に「突入」 |
| 2027年2月6日（土）14時 | 子どもと若者の行列（旧市街） |
| 2027年2月7日（日）11時から | ケー通りの仮装散歩（Kö-Treiben） |
| 2027年2月8日（月） | バラの月曜日の行列（Rosenmontagszug） |
| 2027年2月9日（火）19時 | 王子とヴェネツィアの見送りの式典（市庁舎前） |
| 2027年2月10日（水） | 灰の水曜日。カーニバルが終わる |

### 女性のカーニバルの日：市庁舎への「突入」

2月4日（木）11時11分、カーニバルの女性たち（地元ではMöhnenと呼ばれます）が市庁舎に「突入」し、街頭のカーニバルが始まります。市庁舎前のマルクト広場では、音楽や舞台のプログラムが続きます。

女性たちが市の中枢に乗り込み、一日だけ主導権を握る。ふだんの上下関係をひっくり返す、カーニバルの精神がよく表れた始まり方です。

### 日曜：ケーニヒスアレーを歩く、街の仮装散歩

2月7日（日）の「ケー・トライベン」（Kö-Treiben）は、デュッセルドルフらしい行事です。CCによると、何千人もの仮装した人たちが、子ども連れや手押し車を引いて、高級店が並ぶ大通りケーニヒスアレー（通称ケー）を一日じゅう歩き、音楽に合わせて楽しみます。行列を「見る」のではなく、自分たちが主役になって歩く日です。家族で初めて仮装してみたい人に向いています。

### バラの月曜日：風刺の山車が進む行列

2月8日（月）のバラの月曜日の行列は、デュッセルドルフのカーニバルの最大の山場です。デュッセルドルフ市の発表では、2026年の行列にはCCの集計で約70万人が集まり、約1万1,000人が124台の山車や116の徒歩グループとともに練り歩きました（[デュッセルドルフ市：2026年の行列](https://www.duesseldorf.de/medienportal/pressedienst-einzelansicht/pld/mer-bliewe-bunt-ejal-wat-kuett-700000-feierten-beim-rosenmontagszug-in-duesseldorf)）。

この行列の名物は、時事問題を鋭く風刺した山車です。CCは、デュッセルドルフの行列を「ドイツで最も政治的な行列の一つ」と紹介しています。テーマを掲げた山車は、山車職人で美術家のジャック・ティリー（Jacques Tilly）が毎年手がけ、気候変動や社会の公正、国際紛争など、人々が気にかけるテーマを、ユーモアと皮肉をこめて形にします（[CC：バラの月曜日の行列](https://www.helau.cc/de/pages/rosenmontagszug)）。2026年には、過去の作品を理由にモスクワで訴追されているティリーが、それに応える山車を出しました。ロシアの大統領の剣に刺されながらも、ホッペディッツが笑って道化の打ち棒でやり返す姿で、市はこれを「風刺の自由」を示すものと紹介しています。

CCが公表している2027年のルートでは、行列はヘルツォーク通りを出発し、コルネリウス通り、ケーニヒスアレー、ハインリッヒ・ハイネ・アレーなど、市中心部の大通りを進みます（[CC：2027年のルート](https://www.helau.cc/de/pages/zugweg)）。市庁舎前には有料の観覧席も設けられます。

### 灰の水曜日：ホッペディッツの「お葬式」

カーニバルの終わりとともに、ホッペディッツも再び眠りにつきます。CCによると、かつては灰の水曜日に魚料理を食べたあと、上着を裏返しに着た道化たちが松明行列でカールス広場へ向かい、ホッペディッツをかたどったわら人形を、次の11月11日の再会を願いながら燃やしていました（[CC：ホッペディッツ](https://www.helau.cc/de/pages/hoppeditz)）。今も、いくつかの団体がこの「お葬式」を行い、シーズンを締めくくります。

## 行く前に知っておきたいこと

- **旧市街はガラス瓶禁止**：デュッセルドルフ市は2011年から、カーニバルの日に旧市街の中心部で、ガラス容器の持ち込みと使用を禁止しています。2026年の対象は、女性のカーニバルの日（朝8時から翌朝5時まで）と、日曜の正午から火曜の朝5時までで、旧市街への16か所の入口で確認が行われました（[デュッセルドルフ市：2026年のカーニバルの案内](https://www.duesseldorf.de/medienportal/pressedienst-einzelansicht/pld/karneval-alle-infos-zu-glasverbot-mobilen-toiletten-und-mehrweggeschirr-auf-einen-blick-1)・[ガラス禁止の案内](https://www.duesseldorf.de/ordnungsamt/service/scherbenfrei/)）。2027年の内容は、市の告示で発表されます。2026年の告示は前年の11月15日に出されました（[デュッセルドルフ市の告示](https://www.duesseldorf.de/stadtrecht/3/32/32-303)）。2026年の告示の対象に11月11日は含まれていませんでしたが、当日の案内は市の発表で確認してください。
- **祝日ではありません**：バラの月曜日は、NRW州の法定祝日ではありません。勤務先によって休みになるかどうかは異なります（[NRWの祝日2027年](/germany/ja/living/nrw-public-holidays-2027/)）。
- **学校休暇でもありません**：NRW州は2027年に独立した冬休みを設けていません（[NRWの学校休暇2026/2027](/germany/ja/living/nrw-school-holidays-2026-2027/)）。学校が独自に休みにする場合があるため、学校の年間予定を確認してください。
- **混雑を避けたい場合**：女性のカーニバルの日とバラの月曜日の旧市街は、特に混み合います。子ども連れなら、日曜のケー通りの仮装散歩や、土曜の子どもと若者の行列から楽しむのがおすすめです。

## 誰に向いている？

- **この街の文化に触れたい人**：11月11日のホッペディッツの演説は、デュッセルドルフの人が何を笑い、何を気にしているのかが分かる行事です。
- **家族で参加したい人**：11月14日の子どものホッペディッツの目覚めや、2月7日のケー通りの仮装散歩がおすすめです。
- **時事風刺を見たい人**：バラの月曜日の山車は、ドイツの社会や世界の出来事を読み解く手がかりになります。

デュッセルドルフで暮らす日本人にとって、カーニバルは職場や学校、近所の人との距離が少し縮まる季節でもあります。ライン川の上流のケルンでは、同じ時期にまったく違う顔のカーニバルが開かれます。比べてみたい人は「[ケルンのカーニバル2026/27](/germany/ja/events/cologne-carnival-2026-27-guide/)」も参考にしてください。
