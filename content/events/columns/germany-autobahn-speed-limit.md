# アウトバーンは本当に速度無制限？｜「推奨130km/h」の意味と、最初のアウトバーンがケルンにあった話

「ドイツの高速道路は速度無制限」という話を、日本で聞いたことがある人は多いと思います。実際にアウトバーンを走ってみると、制限速度の標識がある区間も多く、「無制限」という言葉だけでは実態がつかめません。

法律では130km/hが「推奨速度」とされ、車種によっては上限も決まっています。制限のない区間がどれくらいあるのか、速度制限をめぐる最近の議論はどうなっているのかを整理しました。世界で最も有名な高速道路が、ケルンとボンの間から始まった話も紹介します。

## 法律にあるのは「制限」ではなく「推奨」

アウトバーンには、ドイツ全体で一律に決まった最高速度がありません。そのかわりにあるのが、1978年11月21日の「アウトバーン推奨速度令」です（[アウトバーン推奨速度令](https://www.gesetze-im-internet.de/babrigeschwv_1978/BJNR018240978.html)）。

この政令は、アウトバーンや、市街地の外で上下線が分かれている道路、片側2車線以上の道路について、「130km/hを超えて走らないことが推奨される」としています。標識で速度制限が決まっている場所では、もちろんその制限が優先です。

連邦議会の調査資料によると、この推奨速度を超えても、罰金などの処分はありません（[連邦議会調査局](https://www.bundestag.de/resource/blob/410890/ab90e4bc194556eb937ca97470b5dd00/WD-5-162-09-pdf.pdf)）。つまり、標識のない区間で140km/hや160km/hで走っても、それだけで違反にはならないのです。

### 「推奨」を超えると、事故のときに不利になることも

ただし、推奨速度を超えて走ることに、まったく意味がないわけではありません。ドイツ自動車連盟（ADAC）の解説によると、推奨速度を超えて走っていて事故に巻き込まれた場合、130km/hで走っていれば事故を避けられたと判断されると、相手に過失があっても、損害の一部を自分で負担しなければならないことがあります（[ADAC：推奨速度](https://www.adac.de/verkehr/recht/verkehrsvorschriften-deutschland/richtgeschwindigkeit/)）。

「罰金はないが、何かあったときの責任は重くなりうる」。これが「推奨」の実際の意味です。

## 制限のない区間は、全体の約7割

では、アウトバーンのどれくらいが「制限なし」なのでしょうか。

連邦交通省によると、ドイツの連邦アウトバーンの総延長は2024年時点で13,210kmです（[連邦交通省：インフラ統計](https://www.bmv.de/SharedDocs/DE/Artikel/G/infrastruktur-statistik.html)）。連邦道路研究所（BASt）が2015年に調べたところ、上り・下りを別々に数えた約25,767kmのうち、工事区間を除いて速度制限がなかったのは約18,115km、割合にして**約70.4%**でした（[BASt：アウトバーンの速度制限](https://www.bast.de/DE/Publikationen/BerichteBASt/Fachveroeffentlichungen/Verkehrstechnik/Downloads/V1-BAB-Tempolimit-2015.pdf?__blob=publicationFile&v=1)）。

残りの約3割には、次のような制限があります。

- **常設の制限**：カーブが多い区間、都市の近く、騒音対策が必要な区間など。120km/hや100km/h、80km/hの標識が立っています。
- **変わる制限**：電光掲示の標識で、渋滞・工事・天候に合わせて制限速度が変わる区間。交通が少ない時間帯は制限がなくなることもあります。
- **工事区間**：60〜80km/hに抑えられることが多く、車線も狭くなります。

制限の終わりは、白い円に黒い斜線が入った標識で示されます。斜線の入った標識を見たら、そこから先は推奨速度130km/hの区間です。

![アウトバーンのうち速度制限のない区間が約70.4%、常設・可変の制限がある区間が約3割であることを示す図](/assets/images/events/autobahn-speed-limit-share.svg "図解：J-Connect。連邦道路研究所（BASt）2015年の調査に基づく（工事区間を除く）。")

## 車種や天気によっては、はっきり制限がある

「制限なし」はあくまで乗用車の話です。道路交通規則（StVO）は、次のような車には、アウトバーンでもはっきりした最高速度を決めています（[StVO 第18条](https://www.gesetze-im-internet.de/stvo_2013/__18.html)）。

| 車の種類 | アウトバーンでの最高速度 |
| --- | --- |
| 総重量3.5トンを超えるトラック | 80km/h |
| トレーラーやキャンピングトレーラーを引く乗用車 | 80km/h（条件を満たし認可を受けた場合は100km/h） |
| バス | 80km/h（条件を満たす場合は100km/h） |

キャンピングトレーラーを引いて100km/hで走るには、トレーラーが認可を受け、後ろに「100」の表示を付けるなど、細かい条件があります（[StVO例外令 第9号](https://www.gesetze-im-internet.de/stvoausnv_9/BJNR317100998.html)）。

天気による制限もあります。霧・雪・雨で見通せる距離が50mより短いときは、どの道路でも50km/hを超えて走ってはいけません（[StVO 第3条](https://www.gesetze-im-internet.de/stvo_2013/__3.html)）。タイヤにチェーンを付けているときも50km/hまでです。そもそもStVOは、「見通せる範囲で止まれる速度で走ること」を、すべての運転の大原則にしています。

冬に運転するなら、冬用タイヤのルールも確認しておきましょう。「[ドイツの冬タイヤ](/germany/ja/living/winter-tires-germany-2026/)」で詳しく紹介しています。

## 実際にはどれくらいの速さで走っている？

「無制限」と聞くと、みんなが200km/hで走っているように思えるかもしれません。実際に走ってみると、景色はもっと落ち着いています。

制限のない区間でも、右側の車線にはトラックが80km/hで連なり、真ん中の車線には推奨速度前後で流れる車が多く見られます。渋滞や工事も多く、平日の昼間に長い距離を速く走り続けられる区間は、それほど多くありません。

むしろアウトバーンで大切なのは、速さよりも走り方のルールです。

- **右側を走るのが原則**：追い越しが終わったら右の車線に戻ります。
- **右からの追い越しは禁止**：左の車線が遅くても、右から抜いてはいけません。
- **後ろの車にも注意**：追い越し車線に出るときは、ずっと後ろから非常に速い車が近づいていることがあります。ミラーで距離だけでなく速さも確かめましょう。
- **渋滞では緊急車両のための道をあける**：救急車や消防車が通れるよう、一番左の車線の車は左へ、それ以外の車は右へ寄って、すき間をつくります。

## 速度制限をめぐる、長い議論

アウトバーンに一般的な速度制限を設けるべきかどうかは、1970年代から続くドイツの大きな論争の一つです。

連邦環境庁（UBA）は、速度制限が温室効果ガスの削減につながるとしています。2020年の試算では、アウトバーンで120km/hの制限を設けると、年間約260万トン（CO₂換算）の削減になるとしました。その後の試算では、計算の方法を見直した結果、削減量はより大きくなるとしています（[UBA：速度制限](https://www.umweltbundesamt.de/themen/verkehr/nachhaltige-mobilitaet/tempolimit)）。一方、連邦道路研究所（BASt）は2025年の研究で、130km/hの制限による削減量を年間約130万〜200万トンと見積もっています（[連邦交通省：BAStの研究](https://www.bmv.de/SharedDocs/DE/Artikel/StV/bast-studie-co2-einsparmoeglichkeiten-tempolimit-autobahnen.html)）。前提が違うため、数字には幅があります。

国会でも議論は続いています。2026年4月、緑の党の会派は、すべての道路で最高速度を130km/h以下にする法案を連邦議会に提出しました。この法案は2026年7月9日の採決で、賛成137票、反対467票で否決されました（[連邦議会 審議記録](https://dip.bundestag.de/vorgang/gesetz-zur-%C3%A4nderung-des-stra%C3%9Fenverkehrsgesetzes-tempolimit/333696)）。少なくとも当面は、「推奨130km/h」の仕組みが続くことになります。

## 最初のアウトバーンは、ケルンとボンの間にあった

最後に、NRWに住む人にうれしい雑学を一つ。ドイツで最初の「自動車専用の高速道路」は、ケルンとボンを結ぶ道路でした。

ラインラント地域連合（LVR）のアーカイブによると、この道路は1932年8月6日に開通しました。開通式を行ったのは、当時のケルン市長だったコンラート・アデナウアー（のちの西ドイツ初代首相）と、ラインラント州の行政を率いていたヨハネス・ホリオンです。全長は約20km、踏切や交差点がなく、途中の出入口はブリュールの1か所だけ。一般の車が走れるようになったのは、8月8日からでした（[LVRアーカイブ](https://afz.lvr.de/de/archiv_des_lvr/dokument_des_monats/dokument_2014_08/2014_08.html)）。

当時はまだ「アウトバーン」という言葉ではなく、「自動車だけが走る道路」と呼ばれていました。ボン市の年表は、この道路を「ドイツ最初のアウトバーンの先駆け」と紹介しています（[ボン市 年表](https://www.bonn.de/themen-entdecken/bildung-lernen/zeittafel.php)）。今ではケルンとボンの間には複数のアウトバーンが走っていますが、その出発点がこの20kmだったのです。

![1932年のケルン〜ボン自動車道路の開通、1978年の推奨速度令、2015年の調査、2026年の国会採決までの流れを示す年表](/assets/images/events/autobahn-history-timeline.svg "図解：J-Connect。LVRアーカイブ、推奨速度令、BASt、連邦議会の資料に基づく（2026年10月26日参照）。")

## アウトバーンを走るときのひと言

アウトバーンは、制限のない区間があるからこそ、速度の差が大きい道路です。180km/hで走る車と、80km/hのトラックが同じ道路を走っています。「速く走っていい道路」ではなく、「自分で速度を選ぶ責任がある道路」と考えると、運転がぐっと楽になります。

車を使わない人には、鉄道での移動も便利です。「[ドイツの鉄道旅行ガイド](/germany/ja/living/germany-train-travel-guide/)」もあわせてどうぞ。
