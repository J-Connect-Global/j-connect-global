# ドイツの育児給付ガイド｜受給条件・金額・受給月・申請期限

<small>編集用ドラフト。現行サイトには未登録・未公開。確認日：2026年11月4日。給付・在留資格の専門レビュー後に公開可否を判断する。</small>

ドイツの育児給付（Elterngeld）は、子どもの出生後に減る収入を補う制度です。受給条件、基本給付とプラス給付の違い、夫婦での受給月の組み方、外国籍の親の条件、申請期限を日本語で整理します。出産前に受給月の案を作り、出生後に必要書類をそろえて申請するためのガイドです。

## まず結論

- 子どもと同じ世帯で暮らし、自分で養育し、ドイツに居住し、受給中の就労が原則週32時間以下であることが基本条件です。外国籍の親には在留資格に関する追加条件があります。
- 2025年4月1日以降に生まれた子どもについては、前年の課税所得が17万5,000ユーロを超えると、原則として受給対象外です。夫婦・別居している親は両親の課税所得を合算します。
- 基本給付は月300〜1,800ユーロ、プラス給付は月150〜900ユーロです。実際の金額は、出生前後の所得差などで決まります。
- 給付は暦月ではなく、誕生日から数える「生活月」で支給されます。申請は出生後に行い、遡って支給されるのは最大3生活月です。

## 育児休業と育児給付は別の制度

育児休業（Elternzeit）は、雇用関係を維持したまま仕事を休む権利です。育児給付は、出生後に減る所得を補う金銭給付です。育児給付を受けるために必ず育児休業を取る必要はありませんが、給付を受けている間の就労は原則週32時間までです。

育児休業は勤務先への通知が必要で、給付とは申請先も期限も異なります。両方を利用する場合は、勤務先に伝える休業期間と、給付を申請する生活月を分けて計画してください。育児休業の通知期限は[ドイツの妊娠・出産全体ガイド](/germany/ja/living/pregnancy-birth-germany/)でも確認できます。

## 受給できる人の基本条件

親は、次の条件を満たす必要があります。

1. 子どもを自分で養育する。
2. 子どもと同じ世帯で暮らす。
3. ドイツに居住する。
4. 給付を受けている期間の就労が原則週32時間以下である。
5. 所得制限と、外国籍の場合は在留資格に関する条件を満たす。

保育施設や親族の助けを一部利用しても、それだけで受給資格を失うわけではありません。就労していない人も、条件を満たせば最低額を受け取れる場合があります。

### 所得制限は額面年収ではなく課税所得で判断する

2025年4月1日以降に生まれた子どもについて、前年の課税所得が17万5,000ユーロを超えると、原則として受給できません。夫婦や別居している両親は両親の課税所得を合算し、ひとり親は本人の課税所得で判断します。

この基準は給与明細の額面年収と同じではありません。課税所得は税務上の控除などを反映した金額です。前年の税務通知書を確認し、境界に近い場合は給付窓口へ問い合わせてください。2024年4月1日から2025年3月31日までの出生には、異なる所得基準が適用されます。

### 外国籍の親は在留資格も確認する

EU、アイスランド、リヒテンシュタイン、ノルウェー、スイスの国籍者は、通常、ドイツに居住または就労していれば受給できます。

それ以外の国籍者は、在留資格と就労許可の条件を確認する必要があります。連邦家族ポータルは、定住許可、EU長期居住許可、EUブルーカード、ICTカードなどを対象となり得る資格として挙げています。その他の滞在許可でも、ドイツで少なくとも6か月働くことが認められている場合などは対象となる可能性がありますが、追加条件があります。

通常の庇護申請中の滞在許可や一般的な猶予滞在は、原則として対象外です。就労が認められた特別な猶予滞在には例外があります。許可証の名称だけで自己判断せず、滞在許可証、補足書類、就労制限を給付窓口へ示して確認してください。

## 3つの受給方法

| 種類 | 月額の範囲 | 主な使い方 |
| --- | ---: | --- |
| 基本給付 | 300〜1,800ユーロ | 出生後に仕事を休む、または収入を大きく減らす期間 |
| プラス給付 | 150〜900ユーロ | 給付を長めに分ける、または部分的に働きながら受け取る期間 |
| パートナーシップボーナス | 150〜900ユーロ | 両親が同じ時期に一定時間のパートタイム勤務をする期間 |

基本給付は、出生前後の所得差の原則65％を基準に計算されます。所得が低い場合は、所得差に対する割合が高くなる仕組みです。最低額と最高額があるため、給与の65％がそのまま支給されるとは限りません。

プラス給付は、基本給付の1か月分を2か月分に置き換えて、受給期間を長くする方法です。出生後に収入がない場合は月額が基本給付の半分になりますが、部分的に働いて収入がある場合は必ずしも半額にはなりません。

パートナーシップボーナスは、両親が同じ2〜4生活月の間、平均して週24〜32時間働く場合に、それぞれ追加で受け取れる制度です。勤務時間が条件を外れた場合の返還が生じることがあるため、勤務先の予定と実績を月ごとに確認してください。

## 受給月は誕生日から数える

育児給付はカレンダーの1日から末日までではなく、子どもの誕生日を起点とする生活月で数えます。たとえば15日に生まれた場合、最初の生活月は15日から翌月14日までです。給付と育児休業の期間を同じ暦月で考えると、想定と違う月数になることがあります。

夫婦は、基本給付を合計14生活月まで分けて利用できます。原則として、各親は少なくとも2生活月を申請し、一人の親が基本給付を受けられるのは最大12生活月です。追加の2か月を得るには、少なくとも一方の親について、出生後の2生活月で出生前より所得が減っている必要があります。

2024年4月1日以降に生まれた子どもについて、両親が同時に基本給付を受けられるのは、原則として子どもの最初の12生活月のうち1か月です。予定日より6週間以上早い出生、多胎児、所定の障害・きょうだい加算に該当する場合などは例外があります。片方がプラス給付を受ける場合は、同時受給の扱いが異なります。

14生活月を過ぎた後は、プラス給付またはパートナーシップボーナスを最長32生活月まで利用できます。ただし、14生活月の後に両親とも給付を受けない生活月があると、その後に残りの月を再開できない場合があります。後から変更できると思い込まず、最初の申請前に月の並びを確認してください。

### 出産手当を受ける親は、最初の月の扱いに注意

同じ子どもについて母親が出産手当などの給付を受ける生活月は、原則として基本給付を受けた月として数えられます。実際の育児給付が出産手当と相殺される場合でも、基本給付の月数を消費する点が重要です。その期間にプラス給付やパートナーシップボーナスを選べない場合もあります。

## 給付額の計算で見るもの

給付窓口は、実際の給与明細に書かれた手取り額をそのまま使うのではなく、総支給額から税金・社会保険料などを簡略化した方法で差し引く「給付計算上の手取り」を計算します。そのため、給与明細の手取り額と給付計算上の手取り額は一致しないことがあります。

雇用されている人の所得計算期間は、母親の場合は通常、産前保護期間が始まる月より前の12暦月、もう一方の親の場合は通常、出生月より前の12暦月です。自営業者は原則として、出生前の直近の確定済み課税期間を基準にします。妊娠に伴う病気、以前の育児給付、出産手当などがある場合は、計算期間や控除の扱いが変わることがあります。

連邦家族ポータルの例では、出生前の給付計算上の手取りが月2,000ユーロ、出生後が月1,200ユーロの場合、所得差は800ユーロです。その65％にあたる520ユーロが基本給付の計算例になります。これは説明用の例であり、個人の実際の支給額を保証するものではありません。

### 日本などEU域外で働いていた期間がある場合

過去の海外所得が、給付額の計算にそのまま含まれるとは限りません。連邦家族ポータルは、外国で得た所得を給付額に反映するのは、EU、アイスランド、リヒテンシュタイン、ノルウェー、スイスのいずれかでその所得に課税されていた場合と説明しています。それ以外の国で課税された所得しかない場合でも、受給資格があれば最低額を受け取れる可能性があります。

ドイツに住みながら別のEU加盟国で働く場合などは、家族給付の優先順位を国ごとに調整する規則があります。勤務国、居住国、両親それぞれの就労先を示して給付窓口に確認してください。

## 申請の流れ

1. **出生前：受給資格と月の案を確認する。** 前年の課税所得、在留資格、勤務時間、両親の休業予定を整理します。公式の給付計算ツールで複数の組み合わせを試し、最終的な判断は給付窓口に確認します。
2. **出生後：出生証明書を取得する。** 育児給付は出生前に正式申請できません。出生後、子どもの出生証明書と必要書類をそろえます。
3. **子どもの居住地を管轄する給付窓口へ申請する。** 申請先は勤務先ではなく、原則として子どもの居住地を管轄する窓口です。両親が申請する場合は、相手の署名も必要になることがあります。
4. **遡及期間を逃さない。** 育児給付は最大3生活月までしか遡って支給されません。申請が遅れると、受給できる月を失う可能性があります。
5. **勤務時間と収入が変わったら届け出る。** 受給中の就労時間や収入は給付額・資格に影響します。申請時の予定と実績が違う場合は、給付窓口へ連絡します。

一般的に必要となるのは、出生証明書、出生前の所得を示す給与明細または税務資料、出産手当の証明、身分証・滞在許可、振込先などです。自営業、外国籍、海外勤務、複数の雇用主などの場合は追加資料が求められることがあります。

NRW州では[州の家族ポータル](https://www.familienportal.nrw/de/elterngeld)からオンライン申請や申請書を確認できます。他州では申請窓口やオンライン手続きが異なるため、子どもの住所を基準に担当窓口を探してください。

## 税金で気を付けること

育児給付そのものは非課税ですが、税率計算に反映される「進行税率の適用対象」です。そのため、育児給付以外の所得にかかる税率が上がる場合があります。育児給付を受けた年の確定申告が必要になることもあるため、受給通知と年間の給付額を保管してください。

## 申請前チェックリスト

- [ ] 前年の課税所得を確認した（給与の額面年収だけで判断していない）。
- [ ] 外国籍の場合、在留資格と就労許可の条件を確認した。
- [ ] 両親それぞれの出生後の勤務時間を確認した。
- [ ] 生活月単位で基本給付・プラス給付の案を作った。
- [ ] 出産手当が基本給付の月数に与える影響を確認した。
- [ ] 出生証明書、給与明細、税務資料などを準備した。
- [ ] 出生後3生活月以内に申請できるよう担当窓口を確認した。

## よくある誤解

**育児休業を取らないと給付を受けられない？**  
いいえ。育児休業は必須ではありません。ただし、給付中の就労は原則週32時間以下です。

**17万5,000ユーロは額面給与の上限？**  
いいえ。前年の課税所得の基準です。夫婦は両親の課税所得を合算します。

**出産後3か月以内なら、いつ申請しても同じ？**  
遡及支給は最大3生活月です。誕生日を基準とする生活月で数えるため、暦月の末日までと誤解しないでください。

**外国籍なら受給できない？**  
いいえ。国籍と在留資格によって条件が異なります。対象となる在留資格もありますが、個別確認が必要です。
