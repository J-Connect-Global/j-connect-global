# 公開求人の紹介掲載の方針（下書き）

計画書 第7章「営業前から、企業が公開している日本語人材の求人を『紹介と元ページへのリンク』の形で掲載（転載はしない）」の実行案です。**まだ掲載していません。**

## 現状
- 求人データ（assets/data/jobs/jobs.json）は4件で、すべて「求人サンプル」。求人ページは掲示板に次いで見られている（GA4、10/16〜11/12で24回）。

## 掲載のルール案
1. 企業が自社の採用ページで公開している求人だけを紹介する。人材紹介会社の求人の転載はしない。
2. 載せるのは、職種、勤務地、雇用形態、日本語が必要な理由（一文）、元ページへのリンク、確認日だけ。仕事内容の全文はコピーしない。
3. 「紹介掲載（J-Connectが公開情報を紹介しています。応募は企業の採用ページから）」と明示する。
4. 月1回、元ページが残っているか確認し、なくなっていれば掲載を止める。
5. 企業から削除の依頼があれば、すぐに止める。

## データの項目（追加案）
| 項目 | 内容 |
| --- | --- |
| listing_type | `referral`（紹介）／`direct`（企業からの掲載） |
| source_url | 元の求人ページのURL |
| source_checked_at | 元ページを確認した日 |

## 探し方（候補の出し方）
- 日系企業の採用ページ、日独の商工会議所の会員企業一覧、在デュッセルドルフ日本国総領事館の日系企業の案内など、公開されている情報から探す。
- この環境から外部の企業サイトの多くを開けないため、候補の洗い出しは手元のブラウザで行う必要がある。
