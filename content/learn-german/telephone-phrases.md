# 電話でよく使うドイツ語｜名乗り方・聞き返し・予約・留守電フレーズ

ドイツ語の電話は、相手の表情が見えず、名前・数字・時刻が一度に出てくるため、対面より難しく感じます。しかし、最初から長い文を作る必要はありません。

**名前 → 用件 → 希望する対応 → 確認**の4段階に分ければ、A1〜A2の短い表現でも進められます。

## 電話前に書く4項目

電話をかける前に、次を紙または画面へ準備します。

| 項目 | 例 |
| --- | --- |
| 名前 | Yoshi Nagamatsu |
| 顧客・予約番号 | Kundennummer 123456 |
| 用件 | 予約変更、請求確認、故障連絡 |
| 希望する結果 | 新しい日程、メール回答、折り返し |

相手に聞かれそうな住所、生年月日、電話番号も用意します。ただし、相手が本物か確認できない不審な着信には、顧客番号、銀行情報、認証コードを伝えないでください。

## 最短の電話スクリプト

> Guten Tag. Mein Name ist [氏名].
> Ich rufe wegen [用件] an.
> Meine Kundennummer lautet [番号].
> Ich möchte [希望する対応].

例：

> Guten Tag. Mein Name ist Tanaka.
> Ich rufe wegen meines Termins an.
> Ich möchte den Termin verschieben.

日本語：

> こんにちは。田中と申します。
> 予約の件で電話しています。
> 予約を変更したいです。

## 電話をかける・名乗る

| 場面 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 丁寧に名乗る | Guten Tag. Mein Name ist [氏名]. | こんにちは。[氏名]と申します。 |
| 短く名乗る | Guten Tag, hier ist [氏名]. | こんにちは、[氏名]です。 |
| 会社名も | Ich bin [氏名] von der Firma [会社名]. | [会社名]の[氏名]です。 |
| 初めて電話 | Ich rufe zum ersten Mal bei Ihnen an. | 初めてお電話します。 |
| 折り返し | Ich rufe zurück. Sie hatten mich angerufen. | 折り返しです。先ほどお電話をいただきました。 |
| 着信理由 | Worum geht es? | どのようなご用件ですか。 |
| 相手確認 | Spreche ich mit Frau/Herrn [氏名]? | [氏名]さんでしょうか。 |

電話を受けた側が、会社名や診療所名の後に名字だけを速く言うことがあります。聞き取れなければ、すぐに確認します。

> Entschuldigung, mit wem spreche ich?
> すみません、どなたとお話ししていますか。

## 用件を一文で伝える

`Ich rufe wegen ... an.`は「…の件で電話しています」という基本形です。

| 用件 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 予約 | Ich rufe wegen eines Termins an. | 予約の件で電話しています。 |
| 請求書 | Ich rufe wegen einer Rechnung an. | 請求書の件で電話しています。 |
| 契約 | Es geht um meinen Vertrag. | 契約の件です。 |
| 申請 | Es geht um meinen Antrag vom [日付]. | [日付]の申請の件です。 |
| 配送 | Ich rufe wegen einer Lieferung an. | 配送の件で電話しています。 |
| 故障 | Ich möchte eine Störung melden. | 障害を届けたいです。 |
| 質問 | Ich habe eine Frage zu [内容]. | [内容]について質問があります。 |
| 苦情 | Ich möchte ein Problem mit [内容] klären. | [内容]の問題を解決したいです。 |

いきなり全経緯を話さず、まず用件を一文で示します。担当部署へつながった後に詳細を説明します。

## 担当者・部署につないでもらう

| 目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 人につなぐ | Könnten Sie mich bitte mit Frau Müller verbinden? | Müllerさんにつないでいただけますか。 |
| 部署につなぐ | Könnten Sie mich bitte mit der Vertragsabteilung verbinden? | 契約担当部署につないでいただけますか。 |
| 担当を尋ねる | Wer ist dafür zuständig? | その件は誰が担当ですか。 |
| ここで合うか | Bin ich bei Ihnen richtig? | こちらの窓口で合っていますか。 |
| 内線 | Wie lautet die Durchwahl? | 内線番号は何番ですか。 |
| 待つ | Ja, ich bleibe in der Leitung. | はい、このまま待ちます。 |
| 待てない | Könnten Sie um einen Rückruf bitten? | 折り返しをお願いできますか。 |

`zuständig`は「担当・管轄」という頻出語です。`nicht zuständig`と言われたら、終わらずに次を聞きます。

> An wen kann ich mich wenden?
> どこへ問い合わせればよいですか。

## 聞き返す・速度を落としてもらう

聞き取れないまま `ja` と答えず、止める表現を使います。

| 目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 繰り返し | Könnten Sie das bitte wiederholen? | もう一度言っていただけますか。 |
| ゆっくり | Könnten Sie bitte etwas langsamer sprechen? | もう少しゆっくり話していただけますか。 |
| 書き取り | Könnten Sie das bitte buchstabieren? | 綴っていただけますか。 |
| 数字だけ | Könnten Sie die Nummer bitte noch einmal sagen? | 番号をもう一度言っていただけますか。 |
| 理解確認 | Habe ich richtig verstanden, dass ...? | …という理解で合っていますか。 |
| 聞こえない | Die Verbindung ist schlecht. Ich kann Sie kaum hören. | 回線が悪く、ほとんど聞こえません。 |
| 一部だけ | Den letzten Satz habe ich nicht verstanden. | 最後の文が理解できませんでした。 |
| 書面 | Können Sie mir das bitte per E-Mail schicken? | メールで送っていただけますか。 |

`Ich verstehe nicht.`だけでも通じますが、何をしてほしいかまで続けると会話が進みます。

## 名前・電話番号・日付を確認する

### 名前を綴る

> Mein Nachname ist Nagamatsu: N-A-G-A-M-A-T-S-U.
> 姓はNagamatsuです。N-A-G-A-M-A-T-S-Uです。

文字が聞き取りにくい場合：

> N wie Nordpol, A wie Aachen ...
> NはNordpolのN、AはAachenのA…

決まった綴り用語を完全に暗記する必要はありません。相手に通じる身近な単語を使い、最後に綴りを復唱してもらいます。

### 電話番号を区切る

> Meine Telefonnummer ist 0176 – 123 – 45 – 67.
> 私の電話番号は0176 – 123 – 45 – 67です。

> Könnten Sie die Nummer bitte wiederholen?
> 番号を復唱していただけますか。

### 日付と時刻を復唱する

> Also am Donnerstag, den 6. August, um 14:30 Uhr. Ist das richtig?
> つまり8月6日木曜日、14時30分ですね。合っていますか。

曜日、日付、時刻を3つとも言うと取り違えを減らせます。

## 予約を取る・確認・変更する

| 目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 予約希望 | Ich hätte gern einen Termin. | 予約を取りたいです。 |
| 最短 | Wann ist der nächste freie Termin? | 次の空きはいつですか。 |
| 午前 | Haben Sie vormittags etwas frei? | 午前に空きはありますか。 |
| 確認 | Ich möchte meinen Termin bestätigen. | 予約を確認したいです。 |
| 変更 | Ich möchte den Termin verschieben. | 予約を変更したいです。 |
| キャンセル | Ich muss den Termin leider absagen. | 残念ですが予約をキャンセルしなければなりません。 |
| 遅刻 | Ich verspäte mich voraussichtlich um zehn Minuten. | 10分ほど遅れる見込みです。 |
| 場所 | Könnten Sie mir die Adresse per E-Mail schicken? | 住所をメールで送っていただけますか。 |
| 持ち物 | Was muss ich zum Termin mitbringen? | 予約に何を持参しますか。 |

詳しい日時調整は[予約を取りたいときのドイツ語フレーズ](/germany/ja/learn-german/appointment-phrase/)も参照してください。

## 折り返しを依頼する

> Könnten Sie mich bitte zurückrufen?
> 折り返し電話していただけますか。

続けて必要情報を残します。

> Sie erreichen mich heute bis 17 Uhr unter [番号].
> 本日17時まで[番号]で連絡できます。

> Falls Sie mich nicht erreichen, schicken Sie mir bitte eine E-Mail.
> 電話がつながらない場合は、メールを送ってください。

折り返しの時間帯を約束されたら、`vormittags`、`zwischen 14 und 16 Uhr`のようにメモします。

## 留守番電話に残すメッセージ

留守電は5要素に絞ります。

1. 名前
2. 用件
3. 顧客・予約番号
4. 電話番号
5. 折り返し希望

> Guten Tag. Mein Name ist [氏名].
> Ich rufe wegen [用件] an.
> Meine Kundennummer lautet [番号].
> Meine Telefonnummer ist [番号].
> Bitte rufen Sie mich zurück. Vielen Dank.

長い個人情報、病状、口座情報を留守電へ残さないようにします。

## 自動音声でよく聞く表現

| ドイツ語 | 日本語 |
| --- | --- |
| Bitte wählen Sie eine der folgenden Optionen. | 次の選択肢から選んでください。 |
| Drücken Sie die Eins. | 1を押してください。 |
| Bleiben Sie bitte in der Leitung. | 電話を切らずにお待ちください。 |
| Alle Mitarbeiter sind im Gespräch. | 全担当者が通話中です。 |
| Die voraussichtliche Wartezeit beträgt ... | 予想待ち時間は…です。 |
| Außerhalb unserer Geschäftszeiten ... | 営業時間外は… |
| Ihr Anruf wird aufgezeichnet. | 通話は録音されます。 |
| Sprechen Sie nach dem Signalton. | 発信音の後に話してください。 |
| Zum Hauptmenü drücken Sie die Null. | メインメニューへ戻るには0を押してください。 |

録音への同意や契約承認を求められ、内容が分からない場合は、担当者か書面へ切り替えます。

## 相手からよく聞く表現

| ドイツ語 | 日本語 |
| --- | --- |
| Worum geht es genau? | 具体的にはどのようなご用件ですか。 |
| Haben Sie eine Kunden- oder Vorgangsnummer? | 顧客番号または案件番号はありますか。 |
| Einen kleinen Moment bitte. | 少々お待ちください。 |
| Ich schaue kurz nach. | 少し確認します。 |
| Ich verbinde Sie weiter. | 別の担当へ転送します。 |
| Die Kollegin ist heute nicht im Haus. | 担当者は本日不在です。 |
| Bitte versuchen Sie es später noch einmal. | 後でもう一度お試しください。 |
| Dazu kann ich Ihnen keine Auskunft geben. | その件については回答できません。 |
| Sie erhalten eine schriftliche Bestätigung. | 書面の確認が届きます。 |

`später`と言われたら、`Wann soll ich am besten noch einmal anrufen?`（いつ再度電話するのがよいですか）と具体化します。

## メールへ切り替える

電話で複雑な契約・行政・医療情報を確定させる必要はありません。

- `Kann ich mein Anliegen per E-Mail schicken?`（用件をメールで送れますか）
- `Wie lautet die E-Mail-Adresse?`（メールアドレスは何ですか）
- `Was soll ich in die Betreffzeile schreiben?`（件名には何と書けばよいですか）
- `Bitte bestätigen Sie mir das Ergebnis schriftlich.`（結果を書面で確認してください）
- `Können Sie mir eine Vorgangsnummer nennen?`（案件番号を教えていただけますか）

電話後に短い確認メールを送り、日時、担当者名、合意した次の行動を記録すると安全です。

## 会話例：予約を変更する

**Ich:** Guten Tag. Mein Name ist Tanaka. Ich rufe wegen meines Termins am 6. August an.

**Praxis:** Wie lautet Ihr Geburtsdatum?

**Ich:** Der 12. Mai 1993. Ich muss den Termin leider verschieben.

**Praxis:** Wir hätten am 10. August um 9:20 Uhr etwas frei.

**Ich:** Also Montag, den 10. August, um 9:20 Uhr. Ist das richtig?

**Praxis:** Ja.

**Ich:** Vielen Dank. Muss ich etwas mitbringen?

## 会話例：担当者が不在

**Ich:** Könnten Sie mich bitte mit Herrn Weber verbinden?

**Zentrale:** Herr Weber ist heute nicht im Haus.

**Ich:** Könnten Sie ihn um einen Rückruf bitten?

**Zentrale:** Gern. Wie lautet Ihre Telefonnummer?

**Ich:** 0176 – 123 – 45 – 67. Könnten Sie die Nummer bitte wiederholen?

## よくある失敗

### 最初から事情をすべて話す

担当部署でない人に長く説明しても、もう一度話すことになります。まず用件を一文で伝えます。

### 数字を確認せず切る

日付、時刻、金額、顧客番号は必ず復唱します。

### 分からないまま同意する

契約条件や費用なら、`Ich möchte das zuerst schriftlich prüfen.`（まず書面で確認したいです）と止めます。

### 不審な着信へ個人情報を伝える

一度切り、契約書や公式サイトに載っている番号へ自分からかけ直します。
