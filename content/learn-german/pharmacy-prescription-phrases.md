# 薬局・処方箋で使うドイツ語｜E-Rezept・在庫・服用方法のフレーズ

ドイツのApothekeでは、処方薬の受け取りだけでなく、服用方法、市販薬、相互作用、在庫、夜間・休日の薬局について相談できます。

重要なのは、薬の名前だけで終わらせず、**「何のために」「どの量を」「いつまで」「ほかの薬と一緒に使えるか」**を確認することです。

> 本ページはドイツ語学習用です。薬の選択、服用中止、用量変更を自己判断するための医療情報ではありません。呼吸困難、意識障害、重いアレルギー反応など緊急性がある場合は112へ連絡してください。

## まず覚える12文

| 目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| E-Rezept | Ich möchte ein E-Rezept einlösen. | E-Rezeptを使いたいです。 |
| 保険証 | Kann ich das Rezept mit meiner Gesundheitskarte einlösen? | 健康保険証で処方箋を受け取れますか。 |
| 在庫 | Haben Sie dieses Medikament vorrätig? | この薬は在庫がありますか。 |
| 取り寄せ | Können Sie das Medikament bestellen? | この薬を取り寄せられますか。 |
| 受取時刻 | Wann kann ich es abholen? | いつ受け取れますか。 |
| 服用方法 | Wie soll ich das Medikament einnehmen? | この薬はどう服用しますか。 |
| 1回量 | Wie viel soll ich jeweils nehmen? | 1回にどの量を使いますか。 |
| 回数 | Wie oft am Tag soll ich es nehmen? | 1日何回使いますか。 |
| 期間 | Wie lange soll ich es einnehmen? | どのくらいの期間服用しますか。 |
| 食事との関係 | Soll ich es vor oder nach dem Essen nehmen? | 食前と食後のどちらですか。 |
| 併用 | Verträgt sich das mit meinen anderen Medikamenten? | ほかの薬と併用できますか。 |
| 副作用 | Auf welche Nebenwirkungen soll ich achten? | どの副作用に注意すべきですか。 |

## E-Rezeptを提示する

公的健康保険の処方薬は、通常E-Rezeptで発行されます。薬局ではeGK、対応アプリ、または紙のトークンを使います。

| 状況 | ドイツ語 | 日本語 |
| --- | --- | --- |
| eGKで受取 | Ich möchte das E-Rezept mit meiner elektronischen Gesundheitskarte einlösen. | 電子健康保険証でE-Rezeptを使いたいです。 |
| アプリ | Ich habe das E-Rezept in der App. | E-Rezeptはアプリにあります。 |
| 紙 | Hier ist der Ausdruck aus der Arztpraxis. | こちらが診療所でもらった紙です。 |
| 見つからない | Das Rezept wird nicht angezeigt. Was soll ich tun? | 処方箋が表示されません。どうすればよいですか。 |
| 複数 | Sind auf meiner Karte mehrere Rezepte gespeichert? | 私のカードには複数の処方がありますか。 |
| 一部だけ | Ich möchte heute nur dieses Medikament abholen. | 今日はこの薬だけ受け取りたいです。 |

eGKに処方内容そのものが保存されているわけではなく、薬局がE-Rezeptのシステムから処方を呼び出します。読み取りに失敗した場合は、カード、処方の発行状況、診療所の送信完了を一つずつ確認します。

## 在庫・取り寄せ・別製品

| 場面 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 在庫なし | Ist das Medikament derzeit nicht lieferbar? | 現在この薬は供給されていないのですか。 |
| 入荷予定 | Wann wird es voraussichtlich geliefert? | 入荷見込みはいつですか。 |
| 予約 | Können Sie es für mich reservieren? | 私のために取り置きできますか。 |
| 他店舗 | Wissen Sie, ob eine andere Apotheke es vorrätig hat? | 他の薬局に在庫があるか分かりますか。 |
| 同じ有効成分 | Gibt es ein Präparat mit demselben Wirkstoff? | 同じ有効成分の薬はありますか。 |
| 変更可否 | Darf dieses Präparat durch ein anderes ersetzt werden? | この薬は別製品へ変更できますか。 |
| 医師確認 | Müssen Sie dazu Rücksprache mit der Arztpraxis halten? | 診療所への確認が必要ですか。 |

処方薬の代替可否は、処方内容、保険契約、在庫、医学的条件で変わります。自分で「同じだろう」と判断せず、薬剤師と必要に応じて医師に確認します。

## 市販薬を相談する

`Ich brauche etwas gegen ...`は「…に効くものが必要です」という便利な型ですが、症状の期間と重さも添えます。

| 症状・目的 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 頭痛 | Ich brauche etwas gegen Kopfschmerzen. | 頭痛に使うものが必要です。 |
| 喉 | Ich habe seit zwei Tagen Halsschmerzen. | 2日前から喉が痛いです。 |
| 咳 | Ich habe trockenen Husten. | 乾いた咳があります。 |
| 鼻 | Meine Nase ist verstopft. | 鼻が詰まっています。 |
| 胃 | Ich habe Magenbeschwerden. | 胃の不調があります。 |
| アレルギー | Ich habe Heuschnupfen. | 花粉症があります。 |
| 傷 | Ich brauche etwas zur Wundversorgung. | 傷の手当てに使うものが必要です。 |
| 子ども用 | Ist das für ein Kind im Alter von [年齢] geeignet? | [年齢]歳の子どもに適していますか。 |

続けて、次を伝えます。

- `Die Beschwerden haben gestern begonnen.`（症状は昨日始まりました）
- `Ich habe kein Fieber.`（熱はありません）
- `Ich nehme bereits [薬名].`（すでに[薬名]を使っています）
- `Ich habe eine Allergie gegen [成分].`（[成分]へのアレルギーがあります）

## 服用量・タイミングを確認する

| 確認 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 1回量 | Wie viele Tabletten soll ich auf einmal nehmen? | 1回に何錠飲みますか。 |
| 間隔 | Wie viele Stunden sollen zwischen den Einnahmen liegen? | 服用間隔は何時間ですか。 |
| 最大量 | Was ist die maximale Tagesdosis? | 1日の最大量はどれくらいですか。 |
| 時刻 | Soll ich das morgens oder abends nehmen? | 朝と夜のどちらに飲みますか。 |
| 食前 | Muss ich das nüchtern einnehmen? | 空腹時に服用しますか。 |
| 水 | Soll ich es mit Wasser einnehmen? | 水と一緒に飲みますか。 |
| 飲み忘れ | Was soll ich tun, wenn ich eine Dosis vergessen habe? | 1回忘れたらどうすべきですか。 |
| 中止 | Darf ich das Medikament einfach absetzen? | この薬をそのまま中止してよいですか。 |
| 保管 | Wie muss ich das Medikament aufbewahren? | この薬はどう保管しますか。 |

数字は聞き間違えやすいため、薬の箱やラベルを指して確認します。

> Können Sie die Dosierung bitte auf die Packung schreiben?<br>
> 用量を箱に書いていただけますか。

## 相互作用・アレルギー・妊娠・授乳

| 状況 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 他の薬 | Ich nehme regelmäßig diese Medikamente. | これらの薬を定期的に使っています。 |
| サプリ | Ich nehme außerdem dieses Nahrungsergänzungsmittel. | このサプリメントも使っています。 |
| 相互作用 | Gibt es Wechselwirkungen? | 相互作用はありますか。 |
| アレルギー | Ich bin gegen [成分] allergisch. | [成分]へのアレルギーがあります。 |
| 妊娠 | Ich bin schwanger. Darf ich das einnehmen? | 妊娠しています。服用できますか。 |
| 授乳 | Ich stille. Ist das Medikament geeignet? | 授乳中です。この薬は適していますか。 |
| 持病 | Ich habe eine Nieren-/Lebererkrankung. | 腎臓／肝臓の病気があります。 |
| 運転 | Darf ich nach der Einnahme Auto fahren? | 服用後に運転できますか。 |
| アルコール | Darf ich während der Einnahme Alkohol trinken? | 服用中に飲酒できますか。 |

妊娠・授乳、子ども、高齢者、腎臓・肝臓の病気がある場合は、商品を選ぶ前に必ず伝えます。

## 副作用と受診の目安を聞く

| 確認 | ドイツ語 | 日本語 |
| --- | --- | --- |
| よくある副作用 | Was sind häufige Nebenwirkungen? | よくある副作用は何ですか。 |
| 中止基準 | Bei welchen Beschwerden soll ich das Medikament nicht weiternehmen? | どの症状があれば服用を続けないべきですか。 |
| 医師へ | Wann sollte ich eine Ärztin oder einen Arzt aufsuchen? | いつ医師を受診すべきですか。 |
| 緊急 | Bei welchen Symptomen ist es ein Notfall? | どの症状なら緊急ですか。 |
| 相談先 | Wen kann ich außerhalb der Öffnungszeiten anrufen? | 営業時間外はどこへ連絡できますか。 |

強い症状がすでにある場合は、薬局で長く待つより、116117や112など適切な医療窓口を使います。

## 支払い・Zuzahlung

| 場面 | ドイツ語 | 日本語 |
| --- | --- | --- |
| 自己負担 | Wie hoch ist die Zuzahlung? | 自己負担はいくらですか。 |
| 免除 | Ich habe eine Zuzahlungsbefreiung. | 自己負担の免除があります。 |
| 保険対象外 | Wird das von meiner Krankenkasse übernommen? | 健康保険で負担されますか。 |
| 追加料金 | Entstehen Mehrkosten? | 追加費用がかかりますか。 |
| 領収書 | Könnte ich bitte eine Quittung bekommen? | 領収書をいただけますか。 |
| Privat-Rezept | Ist das ein Privatrezept? | これは私費処方箋ですか。 |

保険が負担するかは、処方、年齢、免除、保険種類などで変わります。レジで価格だけ聞くより、`Zuzahlung`と`Mehrkosten`を分けて確認します。

## 夜間・休日のNotdienst-Apotheke

通常の薬局が閉まっているときは、[aponetのNotdienst検索](https://www.aponet.de/notdienstsuche)で現在営業中の当番薬局を確認できます。検索結果は公式データに基づきますが、出発前に電話で営業状況と在庫を確認すると安全です。

使える表現：

- `Haben Sie heute Notdienst?`（今日は当番薬局ですか）
- `Bis wann haben Sie geöffnet?`（何時まで開いていますか）
- `Haben Sie [薬名] vorrätig?`（[薬名]は在庫がありますか）
- `Fällt eine Notdienstgebühr an?`（夜間・休日対応の追加料金はかかりますか）

## 会話例：E-Rezeptの薬が在庫切れ

**Ich:** Guten Tag. Ich möchte ein E-Rezept mit meiner Gesundheitskarte einlösen.

**Apotheke:** Das Medikament haben wir leider nicht vorrätig.

**Ich:** Können Sie es bestellen? Wann kann ich es abholen?

**Apotheke:** Morgen ab 11 Uhr.

**Ich:** Danke. Können Sie mir bitte noch sagen, wie ich es einnehmen soll?

**Apotheke:** Zweimal täglich eine Tablette, jeweils nach dem Essen.

**Ich:** Also morgens und abends je eine Tablette nach dem Essen. Ist das richtig?

**Apotheke:** Ja, genau.

最後に用量を復唱することで、`zweimal täglich`（1日2回）と`zwei Tabletten`（2錠）の聞き違いを防げます。
