# 登録特典PDF原稿：ドイツ到着後90日チェックリスト（長期移住向け）

J-Connect編集部｜2026年11月16日確認

> **対象：** 日本からドイツへ長期移住する人向けの一般的な確認表です。短期旅行者にすべての項目が当てはまるわけではありません。国籍、滞在目的、家族構成、雇用形態、居住自治体によって必要な手続き・期限は異なります。本人宛ての通知と最新の公式案内を必ず確認してください。チェック欄は「全員に必須」という意味ではありません。

## 到着前

- [ ] パスポートの有効期限と、入国・就労に必要なビザや滞在資格を確認する。
- [ ] 日本の海外転出届、健康保険・年金・住民税、マイナンバーカード、運転免許など、出国前に必要な手続きを確認する。→ [ドイツへ引っ越す前に日本でする手続き](https://j-connect-global.com/germany/ja/living/leaving-japan-before-moving-germany/)
- [ ] 入居先が住民登録できる住所か、貸主から入居証明を受け取れるかを契約前に確認する。→ [住民登録](https://j-connect-global.com/germany/ja/living/anmeldung-guide/)
- [ ] 雇用開始日と健康保険の加入開始日がつながっているか確認する。雇用形態や保険区分によって必要な手続きは異なる。→ [健康保険の選び方](https://j-connect-global.com/germany/ja/living/health-insurance-guide/)

## 到着〜2週間

- [ ] **住民登録が必要か、いつまでに届け出るかを確認する。** 一般則は入居後2週間以内（連邦住民登録法 §17(1)）ですが、国外居住者でドイツ国内に未登録の人には、3か月の滞在に関する特則（同法 §27(2)）があります。短期滞在を含め、滞在期間・住居形態に応じて自治体へ確認してください。長期移住で判断に迷う場合は、予約が取れなくても期限前に窓口へ連絡し、問い合わせ・申請の記録を残します。→ [住民登録の手順](https://j-connect-global.com/germany/ja/living/anmeldung-guide/)
- [ ] 郵便受け・インターホンに、郵便が届く氏名を表示する。税務IDや保険・銀行からの手紙を受け取れるようにする。
- [ ] 健康保険の加入先・開始日を確認し、勤務先から求められた証明を提出する。→ [健康保険の選び方](https://j-connect-global.com/germany/ja/living/health-insurance-guide/)
- [ ] 住民登録の情報を基に税務IDが郵送される。すでにドイツで税務IDを取得したことがある人は、同じ番号を使う。未着なら住所・氏名表示を確認し、連邦中央税務庁の再通知手続きを調べる。→ [税務ID・税務署番号・給与税区分](https://j-connect-global.com/germany/ja/living/tax-id-steuernummer-steuerklasse/)

## 2週間〜1か月

- [ ] 銀行口座を開く。通常口座を断られた場合は、基本口座の申請要件を確認する。→ [銀行口座の開設](https://j-connect-global.com/germany/ja/living/bank-account-germany/)
- [ ] 税務IDを勤務先へ伝える。税務ID・税務署番号・給与税区分は別の番号・制度なので混同しない。
- [ ] 携帯電話・SIMを契約する。本人確認書類、契約期間、解約条件を確認する。→ [携帯電話・SIMの選び方](https://j-connect-global.com/germany/ja/living/mobile-phone-sim-germany/)
- [ ] 電気・インターネットの契約者、開始日、家賃・管理費に含まれる範囲を確認する。→ [電気・インターネットの契約](https://j-connect-global.com/germany/ja/living/electricity-internet-contracts-germany/)
- [ ] 放送負担金は原則1住戸につき1件。シェアハウスや同居では、誰が支払っているか確認する。→ [放送負担金](https://j-connect-global.com/germany/ja/living/rundfunkbeitrag-guide/)
- [ ] 日本国籍の人が海外に3か月以上住所・居所を定めて滞在する場合は、在留届を提出する。3か月未満の短期渡航では、外務省の「たびレジ」を利用する。→ [外務省・在留届FAQ](https://www.ezairyu.mofa.go.jp/RRnet/faq.html)

## 1〜3か月

- [ ] 滞在許可が必要な人は、ビザや現在の滞在資格の期限前に申請・更新の準備をする。国籍・滞在目的・就労状況によって必要性が異なる。→ [滞在許可の申請・更新](https://j-connect-global.com/germany/ja/living/residence-permit-renewal-germany/)
- [ ] かかりつけ医を探す。診療時間外で、翌日まで待てないが生命に関わる状態ではない場合は116117。生命に関わる緊急時は112。→ [医師の予約を取る方法](https://j-connect-global.com/germany/ja/living/doctor-appointment-germany/)
- [ ] 個人賠償責任保険や家財保険は、補償範囲・免責・家族の対象範囲を比較して必要性を判断する。一般に一律の法定加入義務はないが、契約条件などは個別に確認する。→ [個人賠償責任保険と家財保険](https://j-connect-global.com/germany/ja/living/liability-household-insurance-germany/)
- [ ] 日本の運転免許を使う予定がある場合は、ドイツで運転できる期間と切替え条件を早めに確認する。日本はFeV Anlage 11に掲載され、該当する免許区分は理論・実技試験が免除される扱い。ただし、免許の有効性、取得時期、翻訳、申請書類などの条件は別に確認する。→ [日本の運転免許とドイツ](https://j-connect-global.com/germany/ja/living/drivers-license-japan-germany/)
- [ ] 子どもがいる場合は、児童手当の対象条件・必要書類・申請先を確認する。すべての家族に自動的に支給されるわけではない。→ [児童手当の申請](https://j-connect-global.com/germany/ja/living/kindergeld-application-germany/)
- [ ] 子どもがいる場合は、保育施設や保育ママの空き状況、申請時期、自治体の登録方法を早めに確認する。待機期間や手続きは自治体・年齢によって異なる。→ [Kitaと保育ママを探す](https://j-connect-global.com/germany/ja/living/kita-u3-tagesmutter-guide/)
