# 記事標準 2026-11（生活ガイド）

目標：すべての生活ガイドを「読み終えたら、そのまま窓口に行ける」状態にする。
対象の記事は front matter に `article_standard: "2026-11"` を付ける。付けた記事だけ `scripts/validate-editorial-content.mjs` が次を検査する。テンプレートは `/content/living/_template.md`。

## 必須ブロック（H2見出し）

| 見出し | 中身 | validatorの検査 |
| --- | --- | --- |
| まず結論 | 何を、いつまでに、どこで。費用と所要期間の目安 | 数字が1つ以上ある |
| あなたはどのケース？ | 答えが変わる部分だけのケース分岐 | 表がある |
| 手順 | 行動順。各ステップに持ち物・窓口/URL・かかった日数（実例） | 番号付きリストか「### 1.」形式 |
| 落とし穴 | よくある失敗。実例を優先 | 3件以上 |
| そのまま使えるドイツ語 | 窓口での一言、電話の最初の一言、件名つきメール。和訳を併記 | 引用（>）か表にドイツ語、和訳あり |
| 在住者の実例 | 何を聞き、何と回答され、何日かかったか | 「編集部」「読者」「在住者」のいずれかを明記 |
| 日本側の手続き | 該当する場合のみ | 任意 |
| 公式情報・参考ソース | 法令、連邦・州・市の公式ページ | 全項目にリンクと「YYYY年M月D日確認」 |

標準の記事では、従来の「ドイツ語の文例は Learn German へ」という規則を外す（`validateGermanUsage` を適用しない）。

## ケース分岐の標準軸

- 雇用形態：駐在（日本の社会保険継続）／現地採用／自営業・フリーランス／学生・ワーホリ
- 家族：単身／夫婦（日本人同士）／国際結婚／子どもあり
- 滞在段階：渡独前／到着90日以内／滞在中／永住・帰化検討／本帰国
- 住所：デュッセルドルフ市内／周辺市／NRW以外

## 公開方針（2026年11月13日決定）

- 書き手は「J-Connect編集部」。地域は「デュッセルドルフ近郊」、時期は「2026年」、家族は「外国籍の配偶者」と書く。
- 書かないもの：配偶者の国籍、居住自治体が分かる情報（市・郡の窓口、園名、地域の制度名）、窓口・施設・会社の名前と連絡先、翻訳の言語と金額、氏名・住所・電話・保険番号・具体的な出産予定日。
- 特定につながらない店名・商品名は書いてよい。
- validator は標準の記事で、居住自治体名、保育登録システム名、関係した保険会社名、配偶者の国籍につながる国名、メールアドレス、電話番号、翻訳の金額を検出すると失敗する。

## 品質チェック（公開の条件）

- [ ] 結論に数字（期限・費用・日数）が入っている
- [ ] ケース分岐が1つ以上ある
- [ ] ドイツ語の文例かテンプレートが1つ以上ある
- [ ] 落とし穴が3件以上ある
- [ ] 財務・健康・法律の数値はすべて一次情報で確認し、確認日を記載している
- [ ] 実体験は事実と推測を分けている
- [ ] 個人を特定できる情報がない
