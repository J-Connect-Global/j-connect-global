# ドイツの介護保険が改革へ｜子どものいない人は2027年から上乗せ0.9％、扶養の配偶者にも負担案

ドイツ政府は、公的介護保険（Pflegeversicherung）の財政を立て直すための改革法案「介護再編法（PNOG）」を閣議決定しました。保険料率は3.6％のまま据え置く一方で、子どものいない人の上乗せ分を2027年1月から引き上げる案です。

このニュースでは、ドイツで働いて社会保険に入っている方に向けて、改革案の中身を整理します。子どものいない人の手取りがいくら減るのか、扶養に入っている配偶者がいる家庭にどんな負担が加わる案なのか、そしてまだ決定ではない点はどこかが分かるはずです。

## 何が決まったのか

連邦保健省によると、連邦政府は介護再編法の政府案を閣議で決定しました（[連邦保健省](https://www.bundesgesundheitsministerium.de/presse/pressemitteilungen/kabinett-beschliesst-pflegeneuordnungsgesetz)）。目的は、介護保険の財政を安定させることです。対策をとらなければ、2027年には約76億ユーロの赤字になるおそれがあったとされています（[連邦政府](https://www.bundesregierung.de/breg-de/aktuelles/pflegeneuordnungsgesetz-2454862)）。

政府は、一般の保険料率を**3.6％のまま**保つとしています。そのかわり、次のような方法で収入を増やす案です（同上）。

| 変更の案 | 時期 |
| --- | --- |
| 子どものいない人の上乗せ：0.6％ → **0.9％** | 2027年1月1日から |
| 保険料を計算する月収の上限：5,812.50ユーロ → 6,375ユーロ | 2027年1月1日から |
| ミニジョブの雇用主も介護保険料を負担 | 2027年1月1日から |
| 扶養に入っている配偶者の分に**0.52％**の上乗せ | 2028年1月1日から |

（出典：[連邦保健省](https://www.bundesgesundheitsministerium.de/presse/pressemitteilungen/kabinett-beschliesst-pflegeneuordnungsgesetz)、[連邦保健省：よくある質問](https://www.bundesgesundheitsministerium.de/service/gesetze-und-verordnungen/guv-21-lp/pnog)）

## 子どものいない人：手取りはいくら減る？

介護保険には、子どものいない人だけが払う「上乗せ（Kinderlosenzuschlag）」があります。今は0.6％で、改革案では2027年1月から**0.9％**になります（[連邦保健省](https://www.bundesgesundheitsministerium.de/presse/pressemitteilungen/kabinett-beschliesst-pflegeneuordnungsgesetz)）。

この上乗せ分は、雇用主と半分ずつではなく、働く人が全額を払います。そのため、0.3％の引き上げは、そのまま手取りの減少になります。

| 月の給与（額面） | 上乗せの増加分（月額） |
| --- | --- |
| 3,000ユーロ | 約9ユーロ |
| 4,000ユーロ | 約12ユーロ |
| 6,375ユーロ以上（上限） | 約19ユーロ |

（J-Connectによる概算。保険料を計算する月収の上限6,375ユーロを超える部分には、保険料はかかりません。）

なお、今の制度では、23歳未満の人には上乗せがかかりません。また、子どもがいる人は上乗せの対象外です。日本で生まれた子どもも含め、子どもがいることを保険組合に届け出ていない場合は、一度確認しておくと安心です。

## 扶養に入っている配偶者がいる家庭：2028年から上乗せ案

日本人の家庭で影響が大きそうなのが、配偶者の扱いです。今の制度では、収入が少ない配偶者は、家族保険（Familienversicherung）として、追加の保険料なしで介護保険に入れます。

改革案では、**2028年1月1日から**、家族保険で入っている配偶者や登録パートナーがいる場合、その保険の元になっている加入者の保険料に**0.52％**の上乗せをするとしています（[連邦保健省：よくある質問](https://www.bundesgesundheitsministerium.de/service/gesetze-und-verordnungen/guv-21-lp/pnog)）。たとえば、月の給与が4,000ユーロなら、月約21ユーロの負担増になる計算です（J-Connectによる概算）。

ただし、次のような場合は上乗せがかからないとされています（同上）。

- 家庭に一定の年齢未満の子どもがいる
- 自分で生活できない障害のある子どもがいる
- 配偶者が、家族を週10時間以上家で介護している
- 配偶者が、年金の支給開始年齢に達している

子どもの年齢の線引きについて、連邦保健省の資料の中でも説明が分かれている部分があります。今後の審議で変わる可能性もあるため、決まった内容を確認してから家計の計画に入れるのがよいでしょう。

## ミニジョブで人を雇っている場合

今は、ミニジョブで働く人について、雇用主は介護保険料を払っていません。改革案では、2027年からミニジョブの雇用主も介護保険料を負担することになります（[連邦政府](https://www.bundesregierung.de/breg-de/aktuelles/pflegeneuordnungsgesetz-2454862)）。家事の手伝いなどでミニジョブの人を雇っている家庭も、費用が少し増える可能性があります。ミニジョブのルールは「[ドイツのMinijob 2027ガイド](/germany/ja/living/minijob-grenze-2027/)」で紹介しています。

## まだ決定ではない：今後の流れ

今回まとまったのは政府の**法案**で、まだ法律として決まったわけではありません。連邦議会は2026年11月5日に、この法案を審議する予定です（[連邦議会](https://www.bundestag.de/dokumente/textarchiv/2026/kw45-de-pflegeneuordnungsgesetz-1225076)）。審議の中で、上乗せの率や例外の条件が変わる可能性があります。

消費者団体や労働組合は、配偶者の分への上乗せが収入の少ない家庭の負担になるとして、反対や見直しを求めています。

## 今のうちにできること

1. **給与明細の「介護保険」の欄を確認**：子どものいない人は、上乗せ分が含まれているはずです。1月の給与明細と比べる準備をしておきましょう。
2. **子どもの届け出を確認**：子どもがいるのに上乗せを払っている場合は、保険組合に子どもの出生証明書などを出すと、上乗せがなくなります。
3. **健康保険料もあわせて確認**：2027年は健康保険の追加保険料も変わる可能性があります。「[【2027年】ドイツの健康保険料は上がる？](/germany/ja/events/news/health-insurance-zusatzbeitrag-2027/)」もあわせてどうぞ。

2027年1月からのそのほかの変更は「[【2027年1月から】ドイツで何が変わる？](/germany/ja/events/news/germany-january-2027-changes/)」でまとめています。
