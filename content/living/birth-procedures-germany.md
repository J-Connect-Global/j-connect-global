# ドイツ出産の手続き完全ガイド｜出生届・保険・手当・国籍・パスポート

ドイツで赤ちゃんが生まれると、出生の登録、健康保険、手当、日本への届出など、複数の手続きが同時に始まります。この記事は、日本国籍の親がいる家庭や国際家庭に向けて、出産前から産後までの主な手続きを、期限・申請先・必要書類とともに整理したガイドです。自分の家庭に必要な項目を選び、夫婦や家族で分担して進めるために使ってください。

病院の選び方や妊婦健診は[妊娠・出産の全体ガイド](/germany/ja/living/pregnancy-birth-germany/)、陣痛・破水から入院までの流れは[出産当日のガイド](/germany/ja/living/birth-day-germany/)で確認できます。ここでは、役所、保険、職場、給付、公館に提出する書類に重点を置きます。

妊娠中の準備から保育申込みまでの記事は、[家族・子育ての案内](/germany/ja/living/routes/family/)から時期別に選べます。

## まず全体像：出生証明書を起点に、複数の申請を並行する

出産前に準備するのは、親の身分・婚姻関係の書類、職場への通知、保険と給付の申請計画です。出生後はドイツの出生証明書を取得し、子どもの保険、出産手当の追加手続き、育児給付、児童手当、日本の出生届を進めます。国籍とドイツでの滞在資格の確認も、出生直後から始めて構いません。

**図の読み方：**番号は全体像をつかむためのもので、すべてを順番に完了させる必要はありません。日本国籍の留保は、子どもが出生によって外国籍も取得した場合に必要です。ドイツ国籍・滞在資格は、旅券の取得を待たず確認してください。育児給付の「生後月」は出生日を起点として数えます。保険と出産手当の加入・申請先は、保険の種類と就業状況によって異なります。

## 期限と申請先の早見表

**法定の届出期限、給付の遡及期間、準備の目安は別のものです。**「3か月」という数字だけを覚えず、何を、どこへ、いつまでに届けるのかを確認します。

| 手続き | 主な提出先 | 時期・期限の扱い |
| --- | --- | --- |
| 職場への妊娠・予定日の連絡 | 雇用主 | 妊娠中。就業上の保護と勤務調整のため早めに |
| 育児休業の通知 | 各親の雇用主 | 子が3歳になる前の休業は原則開始7週間前。3～8歳の期間は13週間前 |
| 出産手当の産前申請 | 母親の保険者など | 出産予定日の証明取得後。受給資格により申請先が異なる |
| 両親自身の出生証明書の準備 | 日本人の証明は管轄の日本公館で取得し、出生地の戸籍登録所へ | 出産前に準備。電子戸籍の識別符号取得、証明申請、原本受領の時間を見込む |
| 認知・共同親権の手続き | 青少年局・戸籍登録所・公証人など | 未婚家庭など、該当する場合。出産前に確認すると進めやすい |
| ドイツの出生通知 | 出生地の戸籍登録所 | 原則出生後1週間以内。施設出産は施設が通知 |
| 出生証明書の取得 | 出生地の戸籍登録所 | 親の必要書類を提出し、出生登録後に取得 |
| 子どもの健康保険加入 | 加入予定の保険者 | 出生後速やかに。民間保険の新生児特例には原則2か月の期限 |
| 出産手当の産後手続き | 母親の保険者・雇用主 | 出生証明を用意でき次第 |
| 育児給付の申請 | 子の居住地の給付窓口 | 出生後。遡及支給は最大3生後月のため早期提出 |
| 児童手当の申請 | 家族給付窓口 | 出生後できるだけ早く。遡及支給は最大6か月 |
| 日本の出生届・必要な国籍留保 | 管轄の日本公館または日本の届出先 | 出生の日を含めて3か月以内。郵送は公館への到着日 |
| 国籍・滞在許可の確認 | 戸籍登録所・居住地の外国人局 | 出生直後から。職権交付の対象でない子の滞在許可申請は法第81条で出生後6か月以内 |
| 日本などの旅券申請 | 各国の公館・旅券窓口 | 通常は各国の登録後。海外旅行を計画する前に余裕を持って |
| 在留届への子ども追加 | 日本公館・オンライン在留届 | 出生後、親の同居家族情報を更新 |

ドイツの出生登録は[連邦家族ポータル](https://familienportal.de/familienportal/lebenslagen/schwangerschaft-geburt/anmeldung-standesamt)、育休期限は[勤務先への通知案内](https://familienportal.de/familienportal/familienleistungen/elternzeit/faq/wann-und-wie-muss-ich-elternzeit-beantragen--124810)、日本の期限は[総領事館の出生届案内](https://www.dus.emb-japan.go.jp/itpr_ja/konsular_koseki_04.html)に基づきます。例外のある手続きは、以下の該当する章も確認してください。

## 出産前：親の書類、名前、職場との調整を整える

### 出生登録に使う親の書類を先に確認する

戸籍登録所（Standesamt）は、赤ちゃんだけでなく、親の身元、婚姻関係、親子関係、名前も確認します。外国の書類を取り寄せ、認証や翻訳を準備する必要がある家庭は、出産後に始めると時間がかかります。

確認する基本項目は次のとおりです。これは全家庭共通の提出一覧ではなく、自分の必要書類を問い合わせるための一覧です。

- 両親の有効な旅券・身分証明書、ドイツの滞在許可。
- 両親自身の出生に関する証明書。赤ちゃんの証明とは別で、日本人の親は日本公館での発行を確認する。
- 婚姻している場合の婚姻証明書、必要に応じて日本の戸籍関係書類。
- 離婚歴などがある場合、その事実と確定を示す書類。
- 未婚家庭では認知、共同親権、氏名に関係する書類。
- 外国語の書類に必要なドイツ語訳、アポスティーユなどの認証の要否。

**どの日本の書類が使えるか、翻訳者に条件があるか、発行時期の制限があるかは、出生地の窓口に確認します。**自分で訳したものが認められる手続きと、資格を持つ翻訳者の訳が必要な手続きを混同しないことが大切です。

たとえば[デュッセルドルフ市の案内](https://www.duesseldorf.de/standesamt/geburt/fragen)では、外国語書類にドイツで認められた翻訳者による訳を求めています。身分証のコピーと証明書原本の扱いも異なるため、案内どおりに分けて準備します。

**特に見落としやすいのは、父・母それぞれの出生証明書です。**日本人の親については、[両親の出生証明書を準備する](#両親の出生証明書を準備する)で、マイナポータルでの戸籍情報の取得から、日本公館へのオンライン申請、紙の原本の受け取りまでを説明します。

### 国際家庭は、名前の表記を先に相談する

ドイツの登録名、日本の戸籍名、旅券のローマ字表記は、同じ入力ルールではありません。複数の名、ハイフン、アクセント付きの文字、両親の姓を組み合わせた姓などを希望する場合は、出生前から双方の窓口へ相談します。

日本の戸籍に使える文字や姓の扱い、外国式の綴りを旅券に載せるための証明は、日本公館で確認します。日本公館の案内では、ドイツの出生証明書の名と日本の戸籍の名が異なる登録が可能な例も示されていますが、**名前の違いを後から証明する場面まで含めて**決めると安心です。

### 未婚の場合、認知と共同親権は分けて確認する

父親としての法的な認知（Vaterschaftsanerkennung）と、共同親権の宣言（Sorgeerklärung）は別の手続きです。認知を済ませただけで、常に共同親権まで成立するわけではありません。手続き先と必要な同意を、青少年局などへ確認してください。

特に、**未婚の日本人父と外国人母の間に生まれる子**は、日本国籍の出生時取得に胎児認知が関わります。ドイツ側の認知だけで日本側の届出まで自動的に完了すると考えず、出産前に管轄の日本公館へ相談することを勧めます。[総領事館の出生届案内](https://www.dus.emb-japan.go.jp/itpr_ja/konsular_koseki_04.html)に、この場合の扱いが記載されています。

## 両親の出生証明書を準備する

赤ちゃんの出生登録では、**これから生まれる子の証明書とは別に、父・母自身がいつ、どこで生まれたかを示す証明**が必要になることがあります。デュッセルドルフ市は、婚姻している両親について、それぞれの出生証明書を基本書類に挙げています。必要な親の範囲や追加資料は、婚姻・認知などの状況に応じて確認します。

日本人の親は、日本の戸籍情報を根拠に、管轄の日本大使館・総領事館で出生証明書を発行してもらう方法があります。ここではNRWを管轄する在デュッセルドルフ日本国総領事館の案内を例に、**戸籍を電子的に提出してオンライン申請し、後日、紙の証明書原本を窓口で受け取る流れ**を説明します。他地域では居住地を管轄する公館の案内を使ってください。

### 最初に、3種類の書類・情報を区別する

| 書類・情報 | 取得先 | 渡す先・用途 |
| --- | --- | --- |
| 日本の戸籍情報を確認するための識別符号 | マイナポータルなど | 日本公館の証明申請で入力・提示し、公館に戸籍を確認してもらう |
| 日本人の親自身の出生証明書 | 管轄の日本公館 | 赤ちゃんの出生登録に使うため、出生地の戸籍登録所へ提出する |
| 赤ちゃんのドイツの出生証明書 | 赤ちゃんの出生地の戸籍登録所 | 出生登録後、保険・給付・日本の出生届などに使う |

マイナポータルで取得する「戸籍電子証明書提供用識別符号」は、行政機関が戸籍の内容を確認するための**16桁の数字で、有効期間は3か月**です。紙の戸籍謄本や、自分でダウンロードしてドイツの役所へ提出する出生証明書そのものではありません。識別符号を日本公館へ伝えることで、紙の戸籍謄本の提出を省ける仕組みです。[総領事館の電子戸籍の案内](https://www.dus.emb-japan.go.jp/itpr_ja/11_000001_01119.html)で確認できます。

### 1．ドイツの提出先と、日本側の申請条件を確認する

出生予定地の戸籍登録所へ、日本公館が発行する出生証明書を使えるか、言語、必要部数、発行時期、追加の戸籍・翻訳・認証が必要かを確認します。日本公館で発行できることと、ドイツの窓口がその書類だけで出生登録を受け付けることは別なので、先に提出条件を合わせます。

電子申請を始める前に、次を用意します。

- 国外で利用できるマイナンバーカードと、有効な電子証明書・暗証番号、カードを読み取れる対応端末。
- 本人の有効な日本のパスポートと、申請に必要な本人・出生の情報。
- オンライン在留届（ORRネット）の登録・ログイン情報。住所と管轄公館も確認する。
- ドイツ側の提出先の正式名称、出生登録に使うという申請理由、必要部数。

海外からの識別符号取得は、国外転出後も使えるよう手続きをしたマイナンバーカードを持つ場合に可能です。古いカードを持っているだけで利用できると判断せず、[マイナポータルの海外利用の案内](https://faq.myna.go.jp/faq/show/11441?site_domain=default)を確認してください。

### 2．マイナポータルで戸籍の識別符号を取得する

1. [マイナポータル](https://myna.go.jp/)にログインし、「さがす」から「証明書」を選ぶ。
2. 「戸籍電子証明書提供用識別符号の取得手続き」を開き、利用条件を確認して開始する。
3. 本人情報を確認し、必要に応じてマイナンバーカードを読み取る。本籍と筆頭者氏名も点検する。
4. 画面の案内に従って電子署名を付け、申請を送信する。ログイン用と署名用の暗証番号を混同しない。
5. 「やること」で申請状況を確認する。ステータスが「完了」になった後、申請状況の詳細で識別符号を確認する。

具体的な画面は[公式操作マニュアル](https://img.myna.go.jp/manual/03-10/0236.html)に掲載されています。取得手続きを送信した段階と、符号を受け取れる段階は区別してください。戸籍の符号は公館での申請に使う情報として安全に保管し、取得日と有効期限も控えます。**この時点では、親の出生証明書の発行はまだ終わっていません。**

### 3．日本公館へ、親本人の出生証明書をオンライン申請する

[総領事館のオンライン申請案内](https://www.dus.emb-japan.go.jp/itpr_ja/k_certification_mibun_online.html)から、[オンライン在留届（ORRネット）](https://www.ezairyu.mofa.go.jp/)へ進みます。公館のサイトは案内の入口で、実際の申請はORRネットのシステムで行います。

1. ORRネットにログインし、「旅券・証明のオンライン申請を行う」へ進む。
2. 証明の申請で「出生証明」を選び、今回証明するのが日本人の父または母本人であることを確認する。出生前に用意する親の証明に、まだ生まれていない赤ちゃんの情報は入力しない。
3. 氏名・旧姓・生年月日・出生地など、求められる証明事項を入力する。「出生地」は本籍地や現在の住所とは別なので、取り違えない。証明対象者の「父・母」の欄は、その大人本人の父母、つまり赤ちゃんから見た祖父母の情報になる。
4. 提出先の戸籍登録所名と申請理由、必要部数、言語などを、ドイツ側で確認した条件に合わせる。ドイツ語の証明を希望する場合も公館の案内に従う。
5. 戸籍の提出方法で、取得した識別符号を入力する。パスポートなど、画面や公館が求める資料もアップロードする。
6. 紙の証明書を取りに行く場合は、交付方法を「紙の証明書・窓口受領」とする。電子交付を選んでいないかを確認して送信し、受付情報を保存する。

符号の入力により戸籍を電子的に提出する方法は、[総領事館の戸籍提出の案内](https://www.dus.emb-japan.go.jp/itpr_ja/11_000001_01119.html)に示されています。オンラインでは証明願の内容を画面で入力するため、通常、サイト掲載の申請用紙を別にアップロードする必要はありません。窓口申請に使う様式は、[証明事務の「出生証明、婚姻証明」](https://www.dus.emb-japan.go.jp/itpr_ja/k_certification.html)から確認できます。

### 4．審査完了後、紙の原本を日本公館で受け取る

送信後はメールと申請状況を確認し、追加資料の依頼があればシステム上で対応します。**申請の受付通知と、受け取り可能になった審査完了通知は別です。**交付準備ができたという案内を確認してから、窓口の受付時間・予約の要否・持参物を確認して来館します。

受領には、日本のパスポートなど、申請でアップロードした資料の原本を持参します。識別符号で戸籍を提出した場合は、紙の戸籍謄本の提出を省く扱いですが、別の追加資料を求められた場合はその案内に従ってください。紙の戸籍謄本を使って申請した場合は、その原本も持参します。

手数料は最新の案内を確認し、オンライン申請で選べるクレジットカード決済、または窓口での現金払いなど、指定の方法で支払います。代理受領は、本人の署名付き委任状と代理人のパスポートなどを要するため、事前に条件を確認します。

[総領事館の証明事務案内](https://www.dus.emb-japan.go.jp/itpr_ja/k_certification.html)では、出生証明・婚姻証明は通常、申請の翌日から数えて4開館日以降の交付とされています。休日や追加確認を見込み、実際の受領日は審査完了の案内に従ってください。識別符号取得から原本受領までを同日で済ませる前提にはせず、出産前に準備します。

受け取った原本は氏名・旧姓・生年月日・出生地・親の氏名などを点検し、控えを保存します。その原本を、ドイツ側の案内どおりに病院の書類窓口または出生地の戸籍登録所へ渡します。**「日本公館で受領した」で止めず、「ドイツの出生登録の必要書類として提出した」まで確認します。**

### 電子交付・紙の戸籍・外国人の親で手順が変わる

**電子戸籍を使うことと、出生証明書を電子で受け取ることは別の選択です。**電子戸籍の識別符号を使って申請し、紙の出生証明書を窓口で受け取ることもできます。e-証明書を希望する場合は、ORRネットからの申請、カード決済、戸籍の識別符号の入力などの条件があります。電子ファイルやその印刷物をドイツの提出先が受理するとは限らないため、[e-証明書の公式案内](https://www.dus.emb-japan.go.jp/itpr_ja/11_000001_01107.html)と提出先の回答を確認してから選びます。

マイナポータルが利用できない場合は、本籍地の市区町村で紙の戸籍謄本を取り寄せ、公館の窓口・オンラインなどの申請方法を相談します。デュッセルドルフ総領事館の紙の戸籍の条件は、出生証明では発行から6か月以内、婚姻証明では3か月以内です。自治体のオンライン請求は紙の証明書の郵送である場合もあるので、識別符号の取得と混同しないようにします。

一方の親が外国籍の場合、その親の出生証明書は母国の登録機関・公館などの方法を別途確認します。**日本人配偶者の戸籍に婚姻が記載されているだけで、外国人の親本人の出生証明まで代用できるとは判断しません。**必要な翻訳・認証もドイツの提出先に確認します。

## 職場：産前産後の保護と育児休業を区別する

産前産後保護（Mutterschutz）は、母親の就業上の保護です。通常は予定日の6週間前から出生後8週間までで、早産・多胎などには延長の規定があります。一方、育児休業（Elternzeit）は、親が子育てのために仕事を休む制度です。さらに育児給付は金銭給付であり、勤務先への休業通知とは申請先が違います。

育児休業を取りたい親は、それぞれ自分の勤務先へ期間を通知します。子の3歳の誕生日前の休業は原則7週間前までです。出生から休業を始める親は、予定日を添えて「出生から」と通知すると、実際の出生日がずれた場合の扱いを整理できます。

母親が通常8週間の産後保護期間の直後から育児休業を取る場合も、開始7週間前の通知が必要です。出産後に準備すると余裕が小さいため、妊娠中に期間を相談しておくと進めやすくなります。

現在の制度ではテキスト形式での通知が可能で、メールも選択肢です。期間と受領日が分かる雇用主の確認を保存し、複数回に分ける場合は最初の2年間の取得予定も整理します。詳しくは[連邦家族ポータルの通知案内](https://familienportal.de/familienportal/familienleistungen/elternzeit/faq/wann-und-wie-muss-ich-elternzeit-beantragen--124810)と[育児休業法第16条](https://www.gesetze-im-internet.de/beeg/__16.html)を確認してください。

## 出産手当：産前申請と産後の追加提出がある

出産手当（Mutterschaftsgeld）の申請先と金額は、母親の保険と雇用状況で変わります。公的保険に本人加入して働いている母親では、保険者の給付と雇用主の補助が組み合わされるのが一般的です。家族加入、民間保険、自営業などは同じ手順とは限りません。

### 産前にすること

1. 婦人科や助産師から、出産予定日の証明を受け取る。
2. 自分の保険者の申請方法を確認し、証明、勤務先、振込先などを提出する。
3. 雇用主にも予定日の証明を渡し、保護期間と雇用主補助の処理を確認する。

TKでは、予定日証明を「Meine TK」やアプリなどから提出できます。[産前の申請案内](https://www.tk.de/techniker/versicherung/tk-leistungen/schwangerschaft-und-familie/antrag-mutterschaftsgeld-2009100)から最新の手続きに進んでください。他の保険者に加入している場合は、その保険者の案内を使います。

### 出生後にすること

出生証明書、または保険者が認める出生の証明を追加提出します。早産や特定の延長理由では追加の医師の証明が必要な場合があります。勤務先にも実際の出生日を知らせ、産後期間の確定を確認します。

TKは産後の支払い後、育児給付窓口向けの証明を発行します。この証明を保存しておくと、次の育児給付申請に使えます。[TKの産後手続き](https://www.tk.de/techniker/versicherung/tk-leistungen/schwangerschaft-und-familie/geburt-mitteilen-restzahlung-mutterschaftsgeld-2009108)で、利用できる出生証明の種類も確認できます。

## 出生直後：ドイツの出生登録と出生証明書を取得する

### 窓口は、原則として赤ちゃんが生まれた場所

出生通知は、原則として出生後1週間以内に、出生地の戸籍登録所へ行います。病院・助産院などで生まれた場合は施設が通知し、自宅出産では医師や助産師の証明を用いて届けます。

**出生地と自宅の市町村が違う場合、出生登録は出生地、育児給付は子どもの居住地というように、担当窓口が分かれます。**たとえば近隣市に住み、デュッセルドルフの病院で出産した家庭は、住所だけを見て全申請先を決めないようにします。

病院の通知と、親の書類提出は別です。退院前に、病院が何を送付するのか、親が追加提出するものは何か、出生証明書の受け取り方を確認します。

![出生地の戸籍登録所、子の居住地の窓口、保険者と勤務先、日本公館が担当する手続きを整理した図](/assets/images/living/birth-procedures-offices.svg "住所が同じでも申請先は一つではありません。児童手当は家族給付窓口へ別途申請します。")

### 出生証明書は、使う先ごとに管理する

ドイツの出生証明書（Geburtsurkunde）は、各種申請の起点になる書類です。証明書の取得時には、保険、出産手当、育児給付、児童手当、日本の出生届、外国人局など、予定している提出先を伝えます。

用途が記された無料証明が交付される場合と、通常の証明・多言語証明を有料で注文する場合があります。デュッセルドルフでは給付申請用の無料証明が送られる案内がありますが、種類と部数は自治体ごとに確認してください。

原本を提出する先もあるため、「1通をコピーして全部に使う」と考えず、各窓口が原本・コピー・電子データのどれを受け付けるかを一覧にします。日本の届出に使う原本を、別の申請で送ってしまわないように分けて保管すると便利です。

名前、出生日、時刻、出生地、両親の情報を受け取り時に確認します。誤記があれば、ほかの申請へ広がる前に発行元へ連絡してください。

## 子どもの住民登録と税務識別番号を確認する

ドイツ国内で生まれ、親または母親と同じ住居に入る新生児については、通常、別途の転入届は必要ありません。戸籍登録所から住民登録機関へ出生の登録が通知されます。親と異なる住居に入る場合などは、別途の登録が必要になります。[連邦住民登録法第17条](https://www.gesetze-im-internet.de/bmg/__17.html)が根拠です。

ただし、住民登録と健康保険加入、外国人局の手続きは別です。「役所が登録してくれたから全部済んだ」とは判断できません。必要な住民登録証明がある場合は、居住地の窓口へ取得方法を確認します。

税務識別番号（Steuer-ID）は、通常は出生後に自動で割り当てられ、郵送されます。児童手当などに使うため、届いた通知を保存してください。出生後3か月以内に通知が届かない場合は、住所と登録状況を確認し、[連邦中央税務庁の再通知案内](https://online.portal.bzst.de/SharedDocs/Leistungsbeschreibung/DE/erneute_mitteilung_der_ID-Nr.html?nn=23996)を利用します。

## 健康保険：赤ちゃんの加入と親の育休中の保険を確認する

### 公的保険の家族加入でも、申請が必要

親の公的健康保険に子どもを家族加入させられる場合、保険者へ加入を申請します。出生証明、加入させる親の情報、もう一方の親の保険・収入などが確認されることがあります。

TKでは出生後に家族加入を申請でき、条件を満たす場合の加入開始は出生日です。出生証明を添付し、「Meine TK」または指定の郵送手続きを使います。通常のメール添付だけで申請完了にはならない点も、[TKの加入案内](https://www.tk.de/techniker/versicherung/tk-leistungen/schwangerschaft-und-familie/entlastung-fuer-familien/versichert-als-familie-in-der-familienversicherung/antrag-familienversicherung-2005612)で確認できます。

片方が公的保険、片方が民間保険の家庭では、収入や婚姻関係などにより無料の家族加入ができない場合があります。妊娠中に両方の保険者へ確認し、出生後の加入先を決めておくと安心です。

### 民間保険の新生児加入には期限のある特例

親の民間医療保険と同じ保険者に子を加入させる制度には、条件付きで、出生後2か月以内に遡及加入を届け出る特例があります。親の加入期間や保障の範囲にも条件があります。すべての民間・旅行保険に同じ保障が付くという意味ではありません。[保険契約法第198条](https://www.gesetze-im-internet.de/vvg_2008/__198.html)と契約内容を確認してください。

### 母親・父親自身の保険も確認する

育休や無給期間に、親の保険料がどうなるかは、公的保険の強制加入・任意加入・家族加入、民間保険、休業中のほかの収入などで違います。子どもの加入申請と同時に、「自分の無給期間の保険料と保障」も問い合わせてください。基本の制度は[健康保険ガイド](/germany/ja/living/health-insurance-guide/)で整理しています。

## 産後の医療：小児科・助産師・健診を予約する

行政手続きと並行して、退院後の支援もつなぎます。病院で受けた赤ちゃんの検査と、退院後に予約する健診を区別し、退院書類と黄色い健診冊子を保管してください。

退院前には、小児健診U2が済んでいるか、未実施の検査と受診先を確認します。U2は通常、生後3～10日ですが、早く退院した場合や自宅出産では家族が速やかに予約し、未実施の新生児検査を含めた時期を医療者と確認する必要があります。[BIÖGのU2案内](https://www.kindergesundheit-info.de/themen/frueherkennung-u1-u9-und-j1/untersuchungen-u1-bis-u9/u2-untersuchung/)を参照してください。

小児健診U3の標準的な時期は、生後4～5週です。小児科に出生日を伝えて予約し、保険証の発行待ちであれば、受診に使う加入確認の方法を保険者へ聞きます。[BIÖGのU3案内](https://www.kindergesundheit-info.de/themen/frueherkennung-u1-u9-und-j1/untersuchungen-u1-bis-u9/u3-untersuchung/)で確認できます。

産後訪問の助産師には出産・退院を連絡し、母親の産後診察は婦人科の案内に沿って予約します。書類作業は分担し、母体の回復と赤ちゃんの受診予定を後回しにしないことが大切です。

## 育児給付：休業計画を生後月に合わせて申請する

育児給付（Elterngeld）は、子どもの養育による収入減少などを支える制度です。勤務先へ育休を通知するだけでは受給できず、子どもの居住地を担当する給付窓口へ、出生後に申請します。

### 受給資格を先に確認する

基本条件には、子どもと同居して自分で養育すること、ドイツに居住すること、原則週32時間を超えて働かないことなどがあります。外国籍の親には滞在資格などの追加条件があります。

2025年4月1日以降の出生では、前年の課税所得が17万5,000ユーロを超える場合は対象外です。両親がいる場合はその所得を合わせて確認します。**額面給与の合計ではなく、課税所得を確認する制度**なので、給与額だけで結論を出さず、税務通知と[公式の資格案内](https://familienportal.de/familienportal/familienleistungen/elterngeld/faq/kann-ich-elterngeld-bekommen--155116)を確認します。

基本給付（Basiselterngeld）は通常月300～1,800ユーロで、出生前の収入、出生後の収入、各種加算などで変わります。期間を延ばす給付（ElterngeldPlus）などもあります。「育休を何か月取るか」と「どの給付を何か月受けるか」を一緒に決めます。

### 暦月ではなく、出生日から数える

たとえば11月10日に生まれた子の第1生後月は11月10日～12月9日、第2生後月は12月10日～1月9日です。休業を12月1日～31日に設定すると、給付の2つの生後月にまたがり、その月の就労・所得の確認が必要になります。

出生予定日で仮の計画を作り、出生後に実際の日付へ直します。出産手当の対象日、各親の休業、復職後の時間・収入も、同じ表に入れると確認しやすくなります。

### 両親の同時受給と出産手当の重なりに注意

基本給付は、通常は1人最大12月分、条件を満たす両親で合計14月分を分ける仕組みです。両親の合計で数えるため、2人が同じ生後月に基本給付を受けると2月分を使います。

2024年4月1日以降の出生では、両親が基本給付を同時に受けられるのは、原則として最初の12生後月内の1生後月です。早産・多胎などには例外があり、一方が延長型の給付を使う場合は扱いが異なります。[同時受給の公式案内](https://familienportal.de/familienportal/familienleistungen/elterngeld/faq/was-aendert-sich-fuer-geburten-ab-1-april-2024-beim-elterngeld-237122)で確認してください。

同じ子の産後の出産手当などを受ける母親は、その対象になる生後月を基本給付の受給月として数えるのが原則です。手当の方が高ければ育児給付の追加振込がなくても、月数には影響します。[出産手当との調整](https://familienportal.de/familienportal/familienleistungen/elterngeld/faq/kann-ich-elterngeld-und-mutterschaftsleistungen-bekommen--124776)も、両親の計画時に確認します。

### 必要書類をまとめて、早めに提出する

一般的には、出生証明、両親の情報、受給する生後月、振込先、所得の証明を準備します。雇用されている母親では産前保護開始月より前の給与資料、もう一方の親では出生月より前の給与資料が基本になるなど、対象期間が違います。自営業・副業・所得の除外月などは個別の確認が必要です。

出産手当と雇用主補助の証明、復職後の就労時間・収入見込み、外国籍の場合の滞在許可なども確認します。最終的な一覧は[連邦の申請案内](https://familienportal.de/familienportal/familienleistungen/elterngeld/faq/wie-kann-ich-elterngeld-beantragen--124762)と居住地の申請フォームで照合してください。

遡及支給は最大3生後月です。これは「3か月を過ぎたら将来分も一切申請できない」という意味ではありませんが、遅れると過去分を失う可能性があります。書類の発行が遅れている場合は、申請を先に受け付けてもらい、証明を追完できるか窓口へ早めに確認します。下書き保存と正式な申請送信も区別してください。

### NRWの申請入口

[NRW家族ポータルの育児給付ページ](https://www.familienportal.nrw/de/elterngeld)で、子どもの居住地を入力して担当窓口とオンライン申請へ進みます。申請書PDFと説明書も同じページにあります。オンライン入力は出生前から準備できますが、正式な申請は出生後です。

BundIDのログイン方法によって、完全なペーパーレス申請に必要な本人確認が異なります。「アカウントを作った」「入力を保存した」だけで提出済みとせず、最後の署名・送信方法と受付確認を見ます。

## 児童手当：育児給付とは別の申請をする

児童手当（Kindergeld）は、親の育児休業を補う給付とは別制度です。2026年の支給額は、対象の子ども1人につき月259ユーロです。外国籍の親は滞在資格なども審査されるため、ドイツで生まれたことだけで受給が決まるわけではありません。

### 両親が同じ子について二重に申請しない

同じ子の児童手当は、原則として受給者となる1人に支給されます。両親で誰を申請者にするか決め、必要な同意を整えます。育児給付を夫婦がそれぞれ受ける場合でも、児童手当まで各人が同じ子について二重申請する仕組みではありません。

### 申請内容と受付を確認する

家族給付窓口（Familienkasse）へ、申請者と子どもの税務識別番号、氏名・出生情報、家族関係、振込先などを提出します。外国籍・国外との関係がある家庭には、追加資料が求められる場合があります。

[連邦雇用庁の家族・子ども向け入口](https://www.arbeitsagentur.de/familie-und-kinder)から出生後の申請へ進めます。完全オンライン提出ができる本人確認方法と、印刷・署名・送付が必要な方法があるため、画面の最終案内に従ってください。

支給の遡及は原則最大6か月です。2027年の送金日はKindergeld番号の末尾で異なるため、[Kindergeld 2027年の支給日一覧](/germany/ja/living/kindergeld-auszahlungstermine-2027/)で該当月を確認できます。日本の出生届の3か月期限や育児給付の3生後月とは別で、児童手当に一律の「出生後3か月以内」という申請期限があるわけではありません。それでも給付開始と追加資料の確認に時間がかかるため、早めに進めます。[申請と遡及の公式案内](https://familienportal.de/familienportal/familienleistungen/kindergeld/faq/wie-wird-kindergeld-beantragt-und-ausgezahlt--124954)を確認してください。

## 日本の出生届：3か月以内の到着を最優先にする

ドイツ側の出生登録を済ませても、日本の戸籍への届出は自動では行われません。日本国籍の取得に該当する子について、管轄の日本大使館・総領事館、または日本の届出先へ出生届を提出します。

### 外国籍も出生時に取得した子は、国籍留保が重要

子どもが外国で生まれ、出生によって外国の国籍も取得した場合、日本の出生届とともに日本国籍を留保する意思を表示する必要があります。出生の日を含めて3か月以内に届け出なければ、出生時にさかのぼって日本国籍を失います。

ここでいう外国籍はドイツ国籍だけではありません。外国籍の親の国籍を出生時に取得する場合も含めて確認します。外国の旅券をまだ申請していなくても、国籍そのものを出生時に取得している可能性があります。

**郵送の場合は、公館に届いた日が届出日で、消印ではありません。**出生証明書の発行が遅れそうなら、期限直前まで待たず日本公館へ相談してください。

### 書式・部数・和訳は管轄公館の案内で確認する

基本は出生届、ドイツの出生証明書、その日本語訳です。部数、原本、署名、追加書類は公館の案内で確認します。NRWの居住者は、通常[在デュッセルドルフ日本国総領事館の出生届ページ](https://www.dus.emb-japan.go.jp/itpr_ja/konsular_koseki_04.html)が入口です。

同館の案内には、[出生届のPDF](https://www.dus.emb-japan.go.jp/files/101063906.pdf)、日本語訳の書式、記入例が掲載されています。書式は改訂されることがあるため、実際に提出するときは案内ページから最新版を開いてください。郵送は、事前に相談・確認してから送るよう案内されています。

出生した病院の正確な住所、出生時刻、日本の本籍地、親子の氏名も確認して記入します。日本への届出とドイツ側への提出で、同じ訳文を使えるとは限りません。

## 国籍と滞在資格：赤ちゃんの法的な立場を確認する

### ドイツで生まれた全員がドイツ国籍になるわけではない

親の一方がドイツ国籍なら、原則として子も出生によりドイツ国籍を取得します。両親が外国籍の場合、ドイツ国内での出生に加え、出生時に一方の親が、少なくとも5年間適法に通常の居住を続け、無期限の滞在権など法定の条件を満たす場合に取得します。[ドイツ国籍法第4条](https://www.gesetze-im-internet.de/stag/__4.html)で確認できます。

「5年住んでいる」だけでは判定できません。滞在権の種類と出生時点の状況を、戸籍登録所・外国人局に確認します。古い案内の「8年」という条件を、そのまま使わないようにしてください。

### ドイツ国籍でない子は、滞在許可の手続きを確認する

外国人局（Ausländerbehörde）へ、子の出生、国籍、両親の滞在許可、居住地を伝えます。出生証明、親の旅券・滞在許可、子の旅券、写真などの提出方法と、まだ発行されていない書類の扱いを確認します。

両親または単独親権者が対象となる滞在資格を持つ場合など、職権で子の滞在許可を交付する規定があります。一方、職権交付の対象でないドイツ国内出生の子については、滞在法第81条に出生後6か月以内の申請規定があります。親がビザ・ビザ免除で滞在している場合なども扱いが変わります。[滞在法第33条](https://www.gesetze-im-internet.de/aufenthg_2004/__33.html)と[第81条](https://www.gesetze-im-internet.de/aufenthg_2004/__81.html)を確認してください。

この6か月を「すべての子が無条件に6か月滞在できる」と読み替えないことが大切です。EU国籍などでは別の制度も関わります。**各国の旅券が全部揃うまで連絡を止めず、出生後早めに、自分の家庭の手順と期限を確認します。**問い合わせメールだけで正式申請になっているかも、窓口に確認してください。

## パスポート：戸籍反映と発給時間を見込んで準備する

赤ちゃんも海外渡航には本人の有効な旅券など、渡航に必要な書類が必要です。親の旅券に名前を追加するだけでは済みません。取得する国籍ごとに、登録と旅券申請の要否を確認します。

### 日本の旅券は、通常は出生届の戸籍反映後

日本の出生届を公館に提出した当日、そのまま通常の新規旅券まで完成するわけではありません。まず日本の戸籍への記載を確認し、最新の戸籍証明または利用できる戸籍電子証明書の識別符号などを準備して申請します。

NRWの総領事館は、戸籍への反映に約4～6週間、旅券は審査終了から受け取りまで約4週間を案内しています。これは目安で、修正・繁忙・輸送などで変わります。戸籍反映待ちと旅券作成期間は別なので、出産直後の旅行をこの目安だけで確約しないようにします。

18歳未満は5年旅券です。乳児の写真、親権者の同意、申請方法、子本人を連れて行く必要のある受け取りの方法は、[総領事館の旅券案内](https://www.dus.emb-japan.go.jp/itpr_ja/k_passport.html)で確認してください。戸籍反映前の緊急帰国には別の渡航書の相談ができますが、通常の旅行と同じ扱いではありません。

### 出国だけでなく、ドイツに戻る条件も確認する

子の旅券ができても、ドイツに再入国するための滞在許可や必要な証明が別に関わることがあります。外国人局へ旅行予定を伝え、出国・再入国に使える書類を確認してから予約します。外国籍も持つ子は、その国の入出国で使う旅券についても公館へ確認します。

## 日本の在留届に子どもを追加する

海外で子どもが生まれたら、親の在留届に同居家族として追加します。オンラインで提出した親は、オンライン在留届の変更手続きから登録します。書面で提出している場合は、公館の案内に従って変更届を提出します。

**出生届、在留届の変更、ドイツの滞在許可は別の手続きです。**日本の戸籍への登録を済ませただけでは、在留届の家族欄まで更新されたとは限りません。[外務省の在留届FAQ](https://www.ezairyu.mofa.go.jp/RRnet/faq.html)の「海外で子供が生まれた」項目が入口です。

## 家庭によって追加する手続き

### 生活費・出産準備費の支援

所得や世帯状況によって、児童加算（Kinderzuschlag）、住宅手当（Wohngeld）、生活保障の支援などを確認します。すべての家庭に同じ給付が追加されるわけではなく、収入・資産・居住・滞在資格・他制度との調整が関わります。[連邦家族ポータルの給付一覧](https://familienportal.de/familienportal/familienleistungen)で該当制度を探してください。

経済的に困難な妊婦向けの「母と子」連邦財団の支援は、原則として出生前に妊娠相談窓口で申請する制度です。産後に全手続きを始めればよいとは限らないため、該当しそうなら妊娠中に[財団の公式FAQ](https://www.bundesstiftung-mutter-und-kind.de/bumuki/faq-haeufig-gestellte-fragen-230424)を確認します。

### 育児期間の年金記録

ドイツの年金保険では、子育て期間が年金記録に関わります。出生直後の全家庭共通の必須提出ではありませんが、後で記録を確認し、必要な申告を行います。

両親で育児期間をどちらに付けるかを変えたい場合は、早めの共同申告が重要です。父親へ配分する共同宣言は、遡れる期間が2暦月に限られるため、出生後の確認事項に入れます。[ドイツ年金保険の案内](https://www.deutsche-rentenversicherung.de/BadenWuerttemberg/DE/Presse/Pressemitteilungen/2025/250505_kindererziehungszeiten.html)で、記録申告と配分の手続きを区別できます。

### 税務、保育、ほかの国への届出

出産手当や育児給付を受けた年は、税率計算や確定申告に関わります。給付の証明を保管し、確定申告では子どもの付表（Anlage Kind）も確認します。児童手当と子の控除は、税務署が有利な扱いを比較する仕組みです。[家族向け税負担軽減の公式案内](https://familienportal.de/familienportal/familienleistungen/steuerentlastungen)を参照してください。

保育園や家庭的保育を使いたい場合は、自治体の申込み時期と予約方法も確認します。育休終了の直前に探し始めると間に合わない地域もあります。[保育園・U3申込みガイド](/germany/ja/living/kita-u3-tagesmutter-guide/)で、NRWの需要申告、デュッセルドルフ・Erkrathの登録後の手順を確認し、希望する復職時期から逆算してください。

日本以外の外国籍の親がいる家庭は、その国の出生登録、国籍確認、旅券申請も追加します。両国籍の取得を旅券の有無だけで判断せず、それぞれの公館へ確認します。日本の公的医療保険に引き続き加入する駐在家庭などは、日本側の出産給付や保険者への通知の対象になるかも、加入先で確認してください。

## 書類管理：提出済みから完了までを追う

申請ごとに、担当者、正式な提出日、受付番号、追加提出、決定通知、初回入金・証明受領を記録します。オンラインの下書き画面だけを保存して「提出済み」にしないことが大切です。

| 管理するもの | 記録例 |
| --- | --- |
| 原本の行き先 | 日本の出生届用原本1通、給付用の用途別証明など |
| 正式な提出 | 送信完了PDF、郵送の到着確認、窓口の受領記録 |
| 追加資料 | 依頼日、提出期限、何を誰が取得するか |
| 決定内容 | 対象月、振込先、金額、親子の氏名・日付 |
| 完了確認 | 保険の加入確認、給付の決定・入金、戸籍記載、旅券受領など |

手続きが止まった場合は、別の窓口にも必要な書類かを確認し、どこを先に動かせるか相談します。「すべての書類が揃ってから全申請を始める」と決めず、期限のある届出と、追完できる申請を分けて進めます。

## よくある質問

### マイナポータルで戸籍を取得したら、親の出生証明書も準備完了？

識別符号の取得は、日本公館に戸籍情報を確認してもらうための準備です。続いて公館へ親本人の出生証明書を申請し、紙の原本または受理される電子証明書を受領して、ドイツの提出先へ渡します。マイナポータルの符号をドイツの役所へ渡すだけでは、この流れは完了しません。

### 病院が出生を通知してくれるなら、親は何もしなくてよい？

病院の通知に加え、親の身分・婚姻・名前などの必要書類が揃う必要があります。さらに保険・給付・日本の出生届などは、それぞれ別に進めます。病院が担当する範囲を退院前に確認してください。

### ドイツの出生証明書がまだ届かない。申請は全部待つ？

保険者、給付窓口、日本公館、外国人局へ、発行待ちであることを知らせます。代わりに使える証明、先に受け付けられる申請、追加提出の方法は窓口ごとに違います。特に日本の届出と滞在許可の期限は、発行待ちだから自動で延びると考えないようにします。

### 日本の出生届とパスポートは同じ日にできる？

通常の新規旅券申請は、子が戸籍に記載されてから必要な証明を用意して行います。出生届を提出しただけでは戸籍記載まで完了していません。緊急帰国の場合は、通常の旅券とは別の渡航書を公館に相談します。

### 外国のパスポートを作らなければ国籍留保は不要？

国籍を出生時に取得しているかが基準です。旅券未発行でも外国籍を取得している場合があります。各国の国籍条件を確認し、日本の出生届に必要な留保を行ってください。

### 育児給付と児童手当は、夫婦がそれぞれ申請する？

育児給付は、受給する各親について月・所得・就労条件を確認します。児童手当は、同じ子について受給者を1人に決める制度です。申請書の配偶者欄があることと、2人分の独立した受給があることは別です。

### 子の住民登録が自動なら、外国人局へ連絡しなくてよい？

住民登録と滞在資格は別です。子の国籍と親の滞在許可によって手順が違うため、ドイツ国籍でない子については外国人局で確認します。

### 図の書類だけで、どの家庭でも申請できる？

図は主な書類と窓口の全体像を示しています。国籍、婚姻関係、保険・雇用・所得状況により、追加書類や署名、翻訳・認証、原本の部数が変わります。各窓口の最新のチェックリストと照合してから提出してください。

### 最初に家族で決めるとよいことは？

「誰が出生証明書と公館への届出を担当するか」「誰が保険と給付を担当するか」「勤務先との連絡は各人がいつ行うか」の3点です。期限を共有カレンダーへ入れ、原本の保管場所と申請の受付記録を共有すると、産後の負担を減らせます。
