# ドイツ建物近代化法が2026年7月29日施行｜暖房交換は何が変わった？

ドイツのGebäudemodernisierungsgesetz（建物近代化法）の主要部分が、2026年7月29日に施行されました。大きな変更は、新築・既存建物の暖房について **再生可能エネルギー65%という全国一律の方式要件が廃止され、所有者が選べる暖房方式の範囲が広がった** ことです。

ヒートポンプ、地域熱、ハイブリッド、バイオマスに加え、ガス・石油暖房も選択肢として残ります。しかし、「化石燃料を将来も現在と同じ価格・条件で使える」「地域熱計画を見なくてよい」「動いている暖房を急いで交換した方が得」という結論にはなりません。

暖房は15〜25年単位の投資です。設置できる機器より、建物の熱需要、地域インフラ、燃料・電気価格、保守、補助、2045年までの総費用を比べる必要があります。

## まず結論：変わったこと・残ったこと

| 論点 | 2026年7月29日以後 |
| --- | --- |
| 全国一律65%要件 | 廃止 |
| 暖房方式 | 所有者が技術中立的に選択 |
| ガス・石油暖房 | 設置選択肢として残る |
| 2045年 | 暖房用燃料の完全な気候中立という方向は残る |
| グリーンガス・オイル | 2028年以降の比率詳細を別法で定める予定 |
| バイオ混合 | 2029年以降の段階的混合を予定 |
| 地域熱計画 | 投資判断上の重要性は残る |
| 補助 | 継続するが2026年7月21日から条件変更 |
| 賃貸 | 不経済な設備による過大なNebenkostenから入居者を守る仕組みが関係 |

法律上設置できることと、20年の総費用で合理的なことは同じではありません。特にガス・石油暖房は本体価格が低く見えても、将来の気候中立燃料、CO₂関連費用、網利用料、供給見通しを含めます。

## 正常に動く暖房を今すぐ交換する必要は？

今回の変更だけを理由に、正常に動く暖房を全世帯が直ちに交換するルールではありません。次の三つに分けて考えます。

### まだ安定して動く

年次点検を続け、故障時の代替案、地域熱計画、建物改修の順序を準備します。慌てて契約するより、熱需要と複数方式の見積りを取得する期間にできます。

### 頻繁に故障する・部品供給が不安

修理費、残り寿命、冬季の緊急交換リスクを比較します。真冬に故障して選択肢が狭まる前に、仮設暖房、工事期間、在庫を確認します。

### 修理不能・安全上の問題がある

使用停止や交換を優先します。ガス臭、排気問題、漏水、繰り返す安全停止などは、法改正の比較より先に資格ある業者へ連絡します。

## 方式を比べる前に建物を測る

暖房機のカタログだけで選ぶと、過大・過小能力、騒音、追加配管、電気容量不足が起きます。最低限、次を揃えます。

- 過去3年のガス・石油・地域熱・電気使用量
- 暖房と給湯の内訳が分かる範囲
- 建物面積、築年、断熱、窓、屋根、地下室
- ラジエーターまたは床暖房と必要な供給温度
- 寒い日に現在設備が使う最高温度
- 配管、煙突、タンク、電気契約・分電盤
- 屋外機・燃料保管・蓄熱槽を置ける場所
- 騒音・隣地境界・文化財・管理規約等の制約

`Heizlastberechnung`（暖房負荷計算）を依頼し、単に現在機器と同じkWへ置き換えないようにします。過去の機器が大きすぎた可能性もあります。

## 主な方式の比較軸

| 方式 | 強みになり得る点 | 先に確認するリスク |
| --- | --- | --- |
| ヒートポンプ | 電化、再エネ電力との相性、冷却対応の可能性 | 建物負荷、供給温度、電気容量、屋外機騒音 |
| 地域熱 | 建物内設備を簡素化しやすい | 接続時期、基本料金、価格改定、事業者選択、接続義務 |
| ハイブリッド | 既存設備を活用しピークを分担 | 制御複雑性、二系統保守、燃料契約継続 |
| バイオマス | 建物条件によって高温供給へ対応 | 燃料保管、配送、粉じん、清掃、価格 |
| ガス・石油 | 既存配管・設置条件を活かせる場合 | 将来燃料、CO₂費用、網縮小、2045年、資産価値 |
| 太陽熱等との組合せ | 給湯・暖房負荷の一部を補助 | 屋根条件、季節差、主暖房との制御 |

特定方式を先に決めるより、同じ熱需要・同じ評価期間で少なくとも二つの方式を比べます。

## 20年総費用の計算表

広告の本体価格ではなく、次を合計します。

`総費用 = 初期工事 − 確定補助 + 20年のエネルギー + 基本料金 + 保守・修理 + 資金調達 + 撤去・更新 − 残存価値`

初期工事には次が含まれるか確認します。

- 旧設備・タンク・煙突の撤去
- 配管、ラジエーター、床暖房の改修
- 電気容量・分電盤・メーター工事
- 掘削、基礎、壁貫通、防音
- 設計、許可、バランシング、試運転
- 足場、内装復旧、消費税

エネルギー単価は一つの予想に固定せず、低・中・高の三つで感度分析します。ガス・石油では将来の気候中立燃料とCO₂関連費用、地域熱では基本料金と価格式、ヒートポンプでは電気単価と年間効率を変えて比較します。

## 2026年7月21日からの補助変更

連邦政府の案内では、建物・暖房の補助は継続し、主に次の調整が行われました。

- 課税所得等の対象基準が3万ユーロ未満の世帯では所得ボーナスが従来30%から40%へ
- 4万ユーロまでの世帯は30%
- 5万ユーロまでの世帯は10%
- 家族には、判定所得から一度1万ユーロを差し引く子ども加算
- 補助対象費用の上限は2万8,000ユーロへ低下
- この上限は半年ごとに750ユーロずつさらに低下する予定
- 早期交換のKlimageschwindigkeitsbonusは期間・率が調整

これは概要です。自分の所得、所有形態、建物、既存設備、申請日、工事契約の条件によって結果が変わります。**最大補助率を全員が受け取れるわけではありません。**

2026年7月20日までに承認済みの申請は原則として新条件の影響を受けないと案内されています。`beantragt`（申請した）と `zugesagt`（承認された）を区別し、個別通知を確認してください。

## 補助申請で失敗しやすい点

- 申請前に取消不能な工事契約を結ぶ
- 補助込みの自己負担額だけで業者を比較する
- 対象外工事・上限超過・税を見落とす
- 所得ボーナスの判定資料を誤る
- 工事完了・請求・証明書の期限を忘れる
- ローン承認前に工事開始する
- 補助不承認時の契約解除条件がない

業者の「補助申請を代行します」という説明でも、申請者、提出内容、責任、手数料、データアクセスを確認します。

## 自治体のWärmeplanungをどう読む？

地域熱計画は、地区ごとにFernwärme（地域熱）、電化、水素・ガス網等の将来像を示す判断材料です。ただし、地図上で将来の地域熱区域になっていても、接続日、料金、容量、個別建物への配管が確約されたとは限りません。

自治体・事業者へ聞く項目：

- 自宅住所の計画区分と、計画の確定段階
- 道路本管と建物接続の予定年
- 接続申込時期、工事費、補助
- 接続義務・使用義務の有無
- 基本料金・従量料金・価格改定式
- 最低契約期間と解約条件
- 計画が遅延・変更した場合の扱い
- 工事まで既存設備を何年維持すべきか

「数年後に地域熱が来るかもしれない」場合、既存機の延命、仮設・小規模交換、ハイブリッド、先行配管なども含めて比較します。

## 一戸建て所有者の実行手順

1. 直近3年の消費量と請求書を集める
2. 独立したエネルギー相談で建物全体の改修順序を確認
3. 暖房負荷、供給温度、電気・配管条件を測る
4. 自治体熱計画と地域熱事業者へ住所単位で確認
5. 二つ以上の方式で同じ前提の見積りを取る
6. 20年総費用を低・中・高価格で比較
7. 補助申請と契約の順序を確認
8. 工事停止期間、冬季の代替、保証、保守を契約へ入れる
9. 設置後に油圧調整、設定、消費量を確認

断熱や窓改修を先に行うと必要暖房能力が下がる場合があります。一方、暖房が危険・修理不能なら、理想の改修順序を待てないこともあります。

## 分譲マンション・WEGの注意

Wohnungseigentümergemeinschaft（区分所有者共同体）では、一人の所有者だけで中央暖房を決められません。管理会社、管理委員会、所有者総会の手順を確認します。

- 暖房が共用部分か専有部分か
- 現状調査・計画費を誰が承認するか
- 議決に必要な多数と招集期限
- Sonderumlage（特別負担金）または積立金
- 各住戸のラジエーター・メーター工事
- 賃貸に出している所有者の通知義務
- 補助申請の主体と所得ボーナスの扱い

総会では本体価格だけでなく、資金調達、月額負担、工期、住戸内工事、代替暖房を議案資料に含めます。

## 賃貸住宅の入居者が確認すること

暖房方式を決めるのは通常、所有者・家主側です。入居者が自分で中央設備を発注するものではありません。ただし、工事・家賃・Nebenkostenへの影響は確認が必要です。

- 工事内容、開始日、終了予定
- 暖房・温水の停止時間
- 住戸への立入りと鍵の扱い
- 騒音、粉じん、家具移動
- 仮設暖房・シャワー等の代替
- Modernisierungsankündigungの内容と期限
- 家賃への転嫁、将来の暖房単価
- 新メーター、検針、請求方法

費用転嫁や家賃値上げには別の賃貸法ルールが関係します。署名・異議・Härteeinwand等の期限が書かれている場合は、Mietervereinや消費者相談窓口へ早めに相談してください。

家主へ送る確認文：

> Bitte teilen Sie mir schriftlich mit, welche Arbeiten in meiner Wohnung erforderlich sind, wann Heizung und Warmwasser ausfallen und welche Ersatzversorgung vorgesehen ist. Bitte erläutern Sie außerdem die voraussichtlichen Auswirkungen auf Miete und Heizkosten.

## 中古住宅を買う人の確認リスト

- 暖房の種類、製造年、整備記録、故障履歴
- 直近3年の消費量・請求書
- Energieausweisの種類と発行日
- 煙突掃除・安全検査の記録
- 地下タンク、漏れ、撤去費
- 自治体熱計画と地域熱接続の見通し
- 過去の補助・融資に伴う条件
- 既存契約の承継・解約費用
- WEG議事録、積立金、予定される特別負担
- 購入後5年の断熱・暖房・屋根予算

売主の「新法で交換不要」という説明だけで価値を判断せず、技術状態と将来費用を別々に見ます。

## 契約前の赤信号

- 「法律で今月中にこの方式へ交換必須」と急がせる
- 住所・建物を見ず、電話だけで能力と補助額を確定する
- 補助金が必ず受け取れる前提の価格だけを示す
- 見積りに電気・配管・撤去・復旧がない
- 将来燃料・基本料金・保守をゼロで計算する
- 申請前に全額契約・高額前払いを求める
- 工期、遅延、追加費用、キャンセルが書かれていない
- 一つの方式しか比較させない

訪問販売や遠隔契約では撤回権が関係することがありますが、工事開始同意等で扱いが変わり得ます。その場で署名せず、契約書を保存して確認します。

## よくある誤解

### ガス・石油暖房が完全に自由になった？

選択肢として残りましたが、2045年の気候中立、将来の混合比率、燃料・CO₂費用、網の維持は残ります。設置可能と経済合理性を分けます。

### 65%要件がないので断熱は不要？

断熱は法的方式要件だけのためではありません。必要能力、室温、エネルギー費、資産価値に影響します。費用対効果と建物状態で判断します。

### ヒートポンプは古い家では必ず無理？

築年だけでは決まりません。熱負荷、供給温度、ラジエーター、断熱、電気、設置場所を測ります。逆に新しい家でも設計・設定が悪ければ効率は落ちます。

### 地域熱の予定区域なら待てばよい？

接続時期と料金が確定していない場合があります。既存暖房の残り寿命と、遅延時の代替案が必要です。

## まとめ

新法は暖房方式の選択を柔軟にしましたが、長期の気候中立目標と将来燃料条件は残っています。所有者は「何を設置できるか」ではなく、**建物の熱需要、自治体計画、初期工事、20年の運転費、補助、2045年までのリスク**を同じ表で比較してください。

賃貸入居者は、方式を選ぶ立場でなくても、工事、停止期間、代替、家賃・暖房費の通知を文書で確認します。WEGと中古住宅購入では、総会資料・積立金・既存設備・将来工事も重要です。

賃貸の基本は[ドイツ賃貸ガイド](/germany/ja/living/rent-apartment-germany/)、電気契約は[電気・インターネット契約ガイド](/germany/ja/living/electricity-internet-contracts-germany/)も参考になります。

この記事は一般情報で、法務・税務・建築・エネルギーの個別助言ではありません。契約前に公式制度、自治体、KfW等の個別通知、資格のある専門家へ確認してください。
