# ドイツの賃貸住宅で暖房が故障したら？大家への連絡・記録・修理・家賃の注意点

J-Connect編集部｜2026年11月17日確認｜公開前草稿

> **編集状態：未公開。** 賃貸借法に関する内容のため、公開前にドイツの賃貸借法に詳しい専門家による確認が必要です。画像、記事レジストリ、生成HTML、検索インデックス、サイトマップはまだ作成していません。

ドイツの賃貸住宅で暖房が動かない、部屋が十分に暖まらない、給湯まで止まったときは、まず安全を確認し、大家または管理会社へすぐに知らせることが重要です。この記事では、故障の切り分け、連絡時に残す記録、修理が進まない場合の相談先、家賃を減額する前に知っておきたい法律上の注意点を整理します。暖房器具やガス設備を自分で分解・修理する必要はありません。

## まず結論：最初にすること

1. **ガス臭などの危険がないか確認する。** ガス臭がある場合は通常の故障連絡を続けず、下の緊急対応に従ってください。
2. **暖房が止まった日時、影響する部屋、室温を記録する。** 可能なら温度計の写真、暖房操作部の表示、エラー番号も残します。
3. **大家または管理会社へすぐに連絡する。** 電話で急ぎの状況を伝えた後、メールや管理アプリなど記録が残る方法でも同じ内容を送ります。
4. **建物の緊急連絡先を確認する。** 冬の全面停止や漏水など、通常の営業時間まで待てない状況では、契約書・入居時資料にある緊急窓口を使います。
5. **家賃を自己判断で差し引かない。** 家賃減額が認められる場合はありますが、金額は故障の程度や期間などで変わります。減額前に賃貸借法の専門家へ相談してください。

## 1. 暖房の故障か、部屋ごとの問題かを切り分ける

大家や修理担当者へ状況を正確に伝えるため、危険のない範囲で次を確認します。ボイラー、ガス配管、電気設備を開けたり、工具で分解したりしないでください。

| 状況 | 確認すること | 連絡時に伝えること |
| --- | --- | --- |
| すべての部屋で暖房が止まった | 他の部屋のラジエーターも冷たいか、操作部にエラーが出ているか | 建物全体または住戸全体で止まっている可能性 |
| 1部屋だけ暖まらない | 他の部屋は暖まるか、サーモスタットの設定が変わっていないか | 部屋名、暖房器具の状態、いつからか |
| 暖房は動くが室温が上がらない | 窓・扉の開閉、暖房の設定、室温の推移 | 設定と実測温度、時間帯 |
| お湯も出ない | 台所・浴室の給湯も止まっているか | 暖房と給湯の両方に影響しているか |
| 水漏れ、焦げた臭い、異音がある | 原因を探すために設備を触らない | 発生場所と危険の有無を伝え、緊急窓口へ |

住戸全体の暖房が止まっている場合と、ラジエーター1台だけの不具合では、修理担当者や緊急度が異なることがあります。原因を自分で断定せず、観察できた事実を伝えてください。

## 2. ガス臭がするときは、暖房の故障対応より安全を優先する

ガス設備のある住宅でガス臭がする場合、照明や電気機器のスイッチを操作しないでください。室内で電話やスマートフォンを使わず、火気を避け、可能なら窓や扉を開けます。安全にできる場合に限りガス栓を閉め、同じ建物の人には呼び鈴ではなくノックで知らせ、速やかに建物の外へ出ます。

外へ出てから、ガス事業者・ネットワーク事業者の緊急窓口へ連絡してください。連絡先が分からない場合は消防へ連絡します。室内で電話をかけないことが重要です。これはドイツガス・水道専門協会の消費者向け安全案内に沿った対応です。

- [ドイツガス・水道専門協会：ガス臭がするときの行動](https://www.dvgw.de/themen/gas/verbraucherinformationen/was-tun-bei-gasgeruch)

## 3. 大家・管理会社には、発生後すぐに知らせる

賃貸住宅の維持に関する基本的な責任は、ドイツ民法典第535条に定められています。貸主は、契約に沿って住める状態を保つ義務を負います。一方、同法第536c条は、入居中に不具合が発生した場合、借主が貸主へ遅滞なく知らせることを求めています。

この不具合の通知は、ドイツ語で「不具合の通知」と呼ばれます。口頭だけでなく、後から日時と内容を確認できる方法で記録を残してください。

連絡には、次の情報を入れます。

- 住所、部屋番号、氏名
- 暖房が止まった、または十分に暖まらなくなった日時
- 影響する部屋と、暖房・給湯のどちらに問題があるか
- 室温と測定した時刻。複数の部屋で違いがあればそれぞれ記録
- 操作部に表示されたエラー番号や、確認できる異常音・水漏れ
- 写真や動画を添付できる場合は、その記録
- 修理担当者の訪問可能時間と、折り返しを受け取れる連絡先

電話で伝えた場合も、後から同じ内容をメールなどで送り、「いつ、誰に、何を伝えたか」を保存します。管理会社のアプリを使う場合は、送信履歴や受付番号を保存してください。

## 4. 暖房期間と室温の目安をどう考えるか

ドイツの賃貸住宅で暖房が必要になる時期や室温については、契約内容、建物の状況、判例などを確認する必要があります。全国一律の法律に「すべての住宅で何月何日から何度」と単純に書かれているわけではありません。

ドイツ賃借人協会は2026年10月1日公表の案内で、遅くとも10月1日には暖房期間が始まり、日中は室温20〜22度、夜間はおおむね18度を確保できる設定が必要という見解を示しています。これは同協会の説明であり、あらゆる賃貸契約にそのまま当てはまる一律の法律上の数値として扱わないでください。

同協会は、冬に暖房が止まった場合や、必要な室温に届かない場合は、借主ができるだけ早く貸主へ知らせ、室温を記録するよう案内しています。

- [ドイツ賃借人協会：2026年の暖房期間と借主・貸主の権利・義務（2026年10月1日公表、ページ更新2026年11月16日確認）](https://mieterbund.de/aktuelles/meldungen/heizperiode-gestartet/)

## 5. 連絡したのに修理が進まないとき

貸主や管理会社から返事がない、修理担当者が来ない、応急対応だけで再発する場合は、連絡履歴を整理して、書面で再度状況を伝えます。全面停止で室温が下がり続ける場合は、通常の修理依頼として何日も待つのではなく、契約書や入居時資料にある緊急連絡先を使ってください。

それでも対応が進まない場合は、次の順で相談します。

1. 送信日時、相手、返答、室温の記録を時系列に並べる。
2. 管理会社や貸主へ、修理の予定と次の連絡時刻を文書で確認する。
3. 地域の借主協会や賃貸借法を扱う弁護士へ相談する。
4. 修理を自分で依頼する前に、費用負担と法的条件を確認する。

ドイツ民法典第536a条第2項には、一定の条件下で借主が自ら不具合を修理し、必要な費用の補償を求められる場合が定められています。代表的なのは、貸主が修理の遅滞に陥っている場合、または住宅の維持・回復のために直ちに修理する必要がある場合です。これは「貸主に連絡せず、好きな業者を呼んで請求できる」という意味ではありません。修理内容・緊急性・費用の妥当性が問題になるため、緊急の安全対応を除き、専門家に相談してから進めてください。

- [ドイツ民法典第536a条：損害賠償と借主による修理](https://www.gesetze-im-internet.de/bgb/__536a.html)
- [ケルン借主協会：住宅の不具合と家賃減額](https://www.mieterverein-koeln.de/service-fuer-mieter/mieterwissen-von-a-z/maengel-und-mietminderung/)

## 6. 家賃の減額を考える前に

ドイツ民法典第536条は、住宅の不具合によって契約どおりの使用ができない、または使用しにくくなった場合の家賃の減額を定めています。ただし、軽微な不具合は対象外となることがあり、どの程度の減額になるかは、暖房の停止範囲、期間、季節、室温、住戸の使い方への影響などによって変わります。

**法律に「暖房が止まったら家賃を一律何％減らせる」と決められているわけではありません。** ドイツ賃借人協会は、室温が16〜18度にしかならない例について20〜30％という目安を紹介していますが、これは同協会の例示であり、あなたの住宅で同じ割合を差し引いてよいという保証ではありません。

家賃を一方的に減らすと、貸主との間で未払い・滞納をめぐる争いになるおそれがあります。減額の対象期間、基準となる家賃、割合、通知方法を、借主協会や賃貸借法に詳しい弁護士に確認してから判断してください。

- [ドイツ民法典第536条：住宅の不具合による家賃減額](https://www.gesetze-im-internet.de/bgb/__536.html)

## 7. よくある質問

### 暖房が止まったら、必ず大家が修理するのですか？

賃貸住宅を契約どおりに使える状態に保つことは、原則として貸主の義務です。ただし、故障の原因、借主の使い方、契約内容など個別の事情は確認が必要です。まずは発生状況を記録して、貸主へ知らせてください。

### 暖房期間は毎年10月1日からですか？

ドイツ賃借人協会は遅くとも10月1日からとする見解を示していますが、全国一律の日付を法律が定めていると断定することはできません。契約内容、建物、外気温、実際の室温などを確認してください。

### 何度まで下がったら家賃を減らせますか？

法律に全国共通の単一の室温ラインや減額率があるわけではありません。室温だけでなく、故障の範囲、期間、季節、生活への影響などを踏まえて判断されます。温度を記録し、減額する前に専門家へ相談してください。

### 修理業者を自分で呼んでもよいですか？

ドイツ民法典第536a条第2項には、貸主の遅滞や、住宅を維持するために直ちに修理が必要な場合の例外があります。ただし、条件を満たすか、費用が補償されるかは個別判断です。通常の故障では、先に貸主へ連絡し、修理を依頼してください。

### 週末や夜間に暖房が止まったら？

契約書、入居時資料、管理会社の案内にある緊急連絡先を確認してください。建物全体の暖房停止、漏水、ガス臭などは、通常の営業時間まで待てない場合があります。ガス臭があるときは、室内で電話や電気スイッチを使わず、建物の外へ出てから緊急窓口へ連絡してください。
