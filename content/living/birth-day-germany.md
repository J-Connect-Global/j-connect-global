# ドイツの出産当日ガイド｜陣痛・破水から赤ちゃん誕生まで

ドイツの病院で出産する日は、症状に気づいて連絡するところから、母体と赤ちゃんの産後の観察まで続きます。このページは、出産する本人と付き添いの人が「今は誰に連絡し、何を伝えるか」を共有するための日本語ガイドです。一般的な病院出産を扱い、病院・助産師から受けた個別の指示を優先します。

## まず連絡先を確認する

**大量出血、意識障害、重い呼吸困難などの緊急時は112へ。病院への電話がつながるのを待たないでください。** 命に関わるか判断できない場合も、緊急通報で状況を伝えます。[ドイツの緊急電話の公式案内](https://gesund.bund.de/notfallnummern)を確認してください。

規則的に強まる陣痛や破水の疑いがあるときは、出産予定の分娩室（Kreißsaal）へ連絡します。受診時期を「陣痛が5分間隔になるまで」と一律に決めないことが大切です。妊娠週数、これまでの経過、病院までの距離によって指示は変わります。

## 症状が出たときの連絡早見表

| 気づいたこと | 次にすること |
| --- | --- |
| 少量の血が混じった粘液、おしるし | これだけでは分娩開始の確定ではありません。出血が増える、痛みが強い、判断に迷う場合は分娩室へ相談します。 |
| 軽く不規則な陣痛 | 症状の変化を確認します。不安がある、休めない、痛みが強くなる場合は相談します。 |
| 規則的に強まる陣痛 | 間隔・持続時間・妊娠週数を伝え、分娩室の来院指示に従います。 |
| 破水したかもしれない | 少量ずつの漏れでも連絡します。始まった時刻、液体の色・においを伝え、陣痛を待たずに相談します。 |
| 胎動が普段より明らかに少ない、羊水が緑・褐色、出血 | 直ちに分娩室へ連絡し、医療者の評価を受けます。翌日まで待ちません。 |
| 大量出血、意識障害などの緊急状態 | 112へ通報します。自分たちでの移動を優先しません。 |

**37週未満で陣痛や破水の疑いがあるときは、間隔がそろうのを待たずに相談してください。** 早産のサインは[NRW家族ポータル](https://www.familienportal.nrw/de/schwangerschaft/gesundheit/fruehgeburt)、羊水の変化・胎動減少は[NHSの医療情報](https://www.nhs.uk/pregnancy/labour-and-birth/signs-that-labour-has-begun/)でも確認できます。NHSは症状の説明の参考であり、英国の電話番号・受診経路はドイツに適用しません。

## 出産前に二人で決めておくこと

![ドイツの診療所で妊娠中の受診について受付と確認する様子](/assets/images/living/german-clinic-reception-editorial-v1.webp "連絡先・必要書類・来院方法は、出産前の相談で確認しておく")

連絡先や荷物は、症状が始まってから探さずに済む形にしておきます。付き添いは夫に限りません。本人が希望するパートナー、家族などと共有してください。

- 第一希望と代替病院の分娩室直通番号、夜間入口
- 病院が指定する来院基準と移動方法
- 妊婦健診記録（Mutterpass）、保険証、身分証、入院バッグ
- 子どもや家族への連絡担当、帰宅時の赤ちゃんの移動手段
- 本人が望む支援と、触れてほしくないときの伝え方

電話では「妊娠何週か」「初産か」「いつから何が起きているか」を先に伝えます。陣痛の間隔、破水の有無、出血、胎動、病院までの所要時間も伝えられるようにします。完璧なドイツ語を準備することより、症状を伝えて確認を受けることが優先です。

## 病院に着いてから

### 母体と赤ちゃんの状態を確認する

病院では、症状と妊娠経過を聞き、母体と赤ちゃんの状態、分娩の進み具合を評価します。検査や処置は状況に応じて変わり、全員が同じ順序で受けるわけではありません。まだ分娩が進んでいない場合は、説明を受けていったん帰宅することもあります。

### 陣痛に対処し、希望を伝える

本人は楽な姿勢や呼吸を探し、痛みへの対応を医療者に相談します。鎮痛薬や硬膜外麻酔（PDA）を含む選択肢は、状態や施設の体制により異なります。我慢できないときは、そのまま伝えて構いません。

付き添いは、本人が希望する声かけや支え、連絡、荷物の管理を担当します。本人の代わりに希望を決めず、触れ方や支援をその都度確認します。説明が分からなければ、本人に直接、ゆっくり説明してもらうよう頼みます。

### 出産方法が変わることもある

経腟分娩では、子宮口が開く段階を経て赤ちゃんが生まれます。母子の状態によって、吸引分娩などの補助や帝王切開が必要になることもあります。変更は本人や付き添いの失敗ではありません。可能な範囲で、理由と次の対応を医療者に確認してください。[連邦保健ポータルの出産解説](https://gesund.bund.de/geburt)に、各方法の基本がまとまっています。

## 赤ちゃんが生まれた後もケアは続く

誕生後は、赤ちゃんの状態確認と並行して、胎盤の娩出、出血や母体の状態の確認が続きます。母子が安定していれば、肌と肌のふれあいや授乳の支援につながります。治療が必要なときはそちらが優先されます。写真や家族への連絡は、本人の希望と医療者の案内に合わせます。[分娩と誕生直後のケアの公式解説](https://www.familienplanung.de/geburt/rund-um-die-geburt/wie-verlaeuft-eine-geburt/)も参考になります。

## よくある疑問

### 陣痛が5分間隔になるまで待ってよい？

全員に当てはまる待機基準ではありません。「5分間隔・1回1分・1時間」は一部で使われる目安ですが、破水、胎動減少、出血、37週未満の症状があればそれを待たずに連絡します。出産施設が示した個別の基準を優先してください。

### 付き添いがいない場合は？

病院へそのことを伝え、移動や説明で必要な支援を相談します。この図の役割分担を二人で全部行う必要はありません。本人だけで書類や連絡を抱えず、スタッフに必要な支援を伝えてください。

### この図は出生届や手当の申請も扱う？

このページは出産当日の医療の流れに絞っています。出生届、子どもの保険、育児給付、日本への届出は、[妊娠・出産の全体ガイド](/germany/ja/living/pregnancy-birth-germany/)で別に確認できます。
