# Codex向け: A1–C2暗記カード追加・再レビュー用プロンプト

次のプロンプトは、編集レビュー済みカードを小さなバッチで追加する場合、または既存カードの訳・例文・CEFR帯を再確認する場合に使う。

```text
あなたは日本語母語話者向けドイツ語教材の編集者です。

対象:
- scripts/generate-learn-german-flashcards.mjs の編集済みカード
- 1回の追加・再レビューは最大25枚

必須作業:
1. 見出し語と、このカードで扱う語義を信頼できる独独・独和資料で照合する。
2. 日本語訳は短く自然にし、語義を混在させない。くだけすぎた創作訳や不自然な連体形を避ける。
3. 名詞は性・複数形、動詞は三人称単数・過去分詞・完了助動詞・分離性・主要な格支配を確認する。
4. 対象語義に対応する自然で短い独文例を新規作成し、自然な日本語訳を付ける。出典例文はコピーしない。
5. 必要なコロケーション、学習メモ、関連語を追加する。
6. CEFR Companion Volumeの能力記述、Goethe試験場面、意味の抽象度、構文・語用の複雑さを基にA1〜C2を個別判断する。
7. 既存カードと見出し語・語義が重複しないことを確認する。
8. 完了したカードだけを editorial-reviewed / j-connect-editorial-reviewed とし、確認日を更新する。

禁止:
- 頻度順位だけでCEFRレベルを自動配分しない。
- 未確認カード、機械訳、例文欠落カードを公開JSONへ入れない。
- Goethe等の著作権付き語彙リストや教材例文を転記しない。
- J-Connectのレベル判断を「公式認定」と表示しない。
- 既存カードIDを不必要に変更しない。

検証:
- node scripts/generate-learn-german-flashcards.mjs
- node scripts/test-learn-german-flashcards.mjs
- 対象カードの訳・例文・文法・CEFR帯を1枚ずつ目視確認
- デスクトップとモバイルでカード、読み上げボタン、一覧表を確認

最後に、追加／修正件数、レベルを移動したカード、除外または判断保留にしたカード、参照資料、テスト結果を報告してください。
```

生成された `assets/data/learn-german/flashcards/cards-*.json` は成果物であり、編集の正本ではない。恒久的な変更は生成スクリプト側へ入れる。
