# 登録特典PDF原稿：ドイツ到着後90日チェックリスト

J-Connect編集部｜2026年11月16日確認

> この資料は日本からドイツへ引っ越す人向けの一般的な確認用チェックリストです。国籍、滞在目的、家族構成、雇用形態、居住自治体によって必要な手続き・期限は異なります。個別の判断は、最新の公式案内と本人宛ての通知で確認してください。

## 到着前
- [ ] パスポートの有効期限と、入国・就労に必要なビザや滞在資格を確認する。
- [ ] 日本の海外転出届、健康保険・年金・住民税、マイナンバーカード、運転免許など、出国前に必要な手続きを確認する。→ [ドイツへ引っ越す前に日本でする手続き](https://j-connect-global.com/germany/ja/living/leaving-japan-before-moving-germany/)
- [ ] 入居先が住民登録できる住所か、貸主から入居証明を受け取れるかを契約前に確認する。→ [住民登録](https://j-connect-global.com/germany/ja/living/anmeldung-guide/)
- [ ] 雇用開始日と健康保険の加入開始日がつながっているか確認する。→ [健康保険の選び方](https://j-connect-global.com/germany/ja/living/health-insurance-guide/)

## 到着〜2週間
- [ ] 入居後、原則14日以内に住民登録をする。一般的にはパスポート、貸主の入居証明、申請書などを用意する。予約方法・必要書類は自治体ごとに異なる。→ [住民登録の手順](https://j-connect-global.com/germany/ja/living/anmeldung-guide/)
- [ ] 郵便受け・インターホンに、郵便が届く名前を表示する。税務IDや保険・銀行からの手紙を受け取れるようにする。
- [ ] 健康保険の加入先・開始日を確認し、勤務先から求められた証明を提出する。→ [健康保険の選び方](https://j-connect-global.com/germany/ja/living/health-insurance-guide/)
- [ ] 住民登録後に税務IDが郵送されることを確認する。届かない場合は住所・氏名表示を確認し、一定期間たっても未着なら税務当局の案内に従って再通知を依頼する。→ [税務ID・税務署番号・給与税区分](https://j-connect-global.com/germany/ja/living/tax-id-steuernummer-steuerklasse/)

## 2週間〜1か月
- [ ] 銀行口座を開く。通常口座を断られた場合は、基本口座の申請要件を確認する。→ [銀行口座の開設](https://j-connect-global.com/germany/ja/living/bank-account-germany/)
- [ ] 税務IDを勤務先へ伝える。税務ID・税務署番号・給与税区分は別の番号・制度なので混同しない。
- [ ] 携帯電話・SIMを契約する。本人確認書類、契約期間、解約条件を確認する。→ [携帯電話・SIMの選び方](https://j-connect-global.com/germany/ja/living/mobile-phone-sim-germany/)
- [ ] 電気・インターネットの契約者、開始日、家賃・管理費に含まれる範囲を確認する。→ [電気・インターネットの契約](https://j-connect-global.com/germany/ja/living/electricity-internet-contracts-germany/)
- [ ] 放送負担金は原則1住戸につき1件。シェアハウスや同居では、誰が支払っているか確認する。→ [放送負担金](https://j-connect-global.com/germany/ja/living/rundfunkbeitrag-guide/)
- [ ] 日本に3か月以上滞在する場合は、在外公館へ在留届を提出する。3か月未満の渡航は「たびレジ」を利用する。→ [日本出発前の手続き](https://j-connect-global.com/germany/ja/living/leaving-japan-before-moving-germany/)

## 1〜3か月
- [ ] 滞在許可が必要な人は、ビザや現在の滞在資格の期限前に申請・更新の準備をする。EU・EEA・スイス国籍の人など、滞在許可が不要なケースもある。→ [滞在許可の申請・更新](https://j-connect-global.com/germany/ja/living/residence-permit-renewal-germany/)
- [ ] かかりつけ医を探す。夜間・休日の医療相談は116117、生命に関わる緊急時は112を利用する。→ [医師の予約を取る方法](https://j-connect-global.com/germany/ja/living/doctor-appointment-germany/)
- [ ] 個人賠償責任保険や家財保険は義務ではないが、補償範囲と免責を比較して必要性を判断する。→ [個人賠償責任保険と家財保険](https://j-connect-global.com/germany/ja/living/liability-household-insurance-germany/)
- [ ] 日本の運転免許を使う予定がある場合は、ドイツで運転できる期間と切替え条件を早めに確認する。日本の免許は条件を満たせば試験免除の対象になる場合がある。→ [日本の運転免許とドイツ](https://j-connect-global.com/germany/ja/living/drivers-license-japan-germany/)
- [ ] 子どもがいる場合は、児童手当の対象条件・必要書類・申請先を確認する。→ [児童手当の申請](https://j-connect-global.com/germany/ja/living/kindergeld-application-germany/)
- [ ] 子どもがいる場合は、Kita（保育施設）や保育ママの空き状況、申請時期、自治体の登録方法を早めに確認する。→ [Kitaと保育ママを探す](https://j-connect-global.com/germany/ja/living/kita-u3-tagesmutter-guide/)
