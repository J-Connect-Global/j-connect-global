# ドイツワインは「白」の国？｜13の産地、リースリング、ラベルの「カビネット」「シュペートレーゼ」の読み方

ドイツと聞くとビールを思い浮かべる人が多いと思いますが、ライン川やモーゼル川の斜面に広がるぶどう畑を見ると、ここがワインの国でもあることに気づきます。秋にはぶどうの収穫を祝うワイン祭りが、各地の村で開かれます。

ドイツには13のワイン産地があり、最も多く植えられているぶどうはリースリングです。産地と品種の特徴、ラベルに書かれたドイツ語の意味を知っておくと、売り場で甘口か辛口か、どんなワインかの見当がつけられます。

## ドイツには13のワイン産地がある

ドイツワイン協会（Deutsches Weininstitut）によると、ドイツには法律で決められた13のワイン産地があります（[ドイツワイン協会：13の産地](https://www.deutscheweine.de/regionen)）。その多くは、ライン川やその支流に沿った、ドイツの南西部に集まっています。

ぶどう畑の面積は、2025年で約10万2,000ヘクタールです（[連邦統計局](https://www.destatis.de/DE/Themen/Branchen-Unternehmen/Landwirtschaft-Forstwirtschaft-Fischerei/Wein/_inhalt.html)）。

| 産地 | 特徴 |
| --- | --- |
| ラインヘッセン（Rheinhessen） | 最も大きな産地。ドイツのぶどう畑の4分の1以上（約2万7,500ヘクタール） |
| プファルツ（Pfalz） | 2番目に大きな産地（約2万3,800ヘクタール）。リースリングの面積は最大 |
| モーゼル（Mosel） | 急な斜面のぶどう畑で有名。白ワインの割合がドイツで最も高い |
| ミッテルライン（Mittelrhein） | 最も小さな産地の一つ（約460ヘクタール）。ライン川の渓谷沿い |
| アール（Ahr） | ボンの南にある小さな産地（約530ヘクタール）。赤ワインで知られる |

（面積はドイツワイン協会の資料による。年によって少しずつ変わります。[ドイツワイン協会：13の産地のプロフィール](https://www.deutscheweine.de/news-medien/meldungen/meldung/783/die-13-deutschen-weinbaugebiete-im-profil)）

NRWに住む人にとって身近なのは、ライン川を南へさかのぼったところにあるミッテルライン、モーゼル、アールです。ケルンやボンから電車で日帰りできる距離にあり、秋のワイン祭りの季節には多くの人が訪れます。ライン川沿いの過ごし方は「[ライン川でのんびり過ごす](/germany/ja/living/rhine-river-relax-guide/)」でも紹介しています。

## 約7割が白ワイン、主役はリースリング

ドイツは、白ワインの国です。連邦統計局によると、2025年にドイツで作られたワインとぶどうの果汁（ワインになる前のもの）は約755万ヘクトリットルで、そのうち**69.6%が白ワイン**、30.4%が赤ワイン（ロゼなどを含む）でした（[連邦統計局：2025年のワイン生産](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/03/PD26_105_412.html)）。

白ワインのぶどうの中で、最も多く植えられているのが**リースリング**です。連邦統計局によると、リースリングはドイツのぶどう畑の4分の1近くを占めています（[連邦統計局](https://www.destatis.de/DE/Themen/Branchen-Unternehmen/Landwirtschaft-Forstwirtschaft-Fischerei/Wein/_inhalt.html)）。さわやかな酸味と、果物や花のような香りが特徴で、辛口から甘口まで、さまざまなスタイルのワインが作られます。

ドイツのワイン産地は、ぶどう栽培ができる地域としてはヨーロッパの中でも北にあります。夏の昼は暖かく、夜は涼しい気候の中で、ぶどうはゆっくりと熟し、酸味が残ります。これが、ドイツの白ワインのすっきりした味わいを生んでいます。

赤ワインでは、ピノ・ノワールにあたるシュペートブルグンダー（Spätburgunder）がよく知られています。

## ラベルの読み方（1）：熟し方を表す「プレディカート」

ドイツワインのラベルには、「カビネット」「シュペートレーゼ」など、見慣れない言葉が書かれていることがあります。これは「プレディカート（Prädikat）」と呼ばれる品質の段階で、収穫したときのぶどうの熟し方（糖度）によって決まります。

プレディカートを名乗るには、申請して公的な審査を受け、審査番号を受け取る必要があります（[ワイン法 第20条](https://www.gesetze-im-internet.de/weing_1994/__20.html)）。ドイツワイン協会によると、段階は次の6つです（[ドイツワイン協会：プレディカート](https://www.deutscheweine.de/qualitaetstandard/449/pr%C3%A4dikate)）。

| プレディカート | ぶどうの状態 |
| --- | --- |
| カビネット（Kabinett） | よく熟したぶどう。軽やかな味わい。糖分を加えることはできない |
| シュペートレーゼ（Spätlese） | 遅めに収穫した、完全に熟したぶどう |
| アウスレーゼ（Auslese） | 完全に熟したぶどうや、貴腐ぶどうを選んで収穫 |
| ベーレンアウスレーゼ（Beerenauslese） | 貴腐ぶどうや、熟しすぎたぶどうの粒を手で選ぶ |
| トロッケンベーレンアウスレーゼ（Trockenbeerenauslese） | 貴腐で干しぶどうのように縮んだ粒を手で選ぶ。品質の段階の頂点 |
| アイスヴァイン（Eiswein） | 木の上で凍ったぶどうを、凍ったまま収穫して搾る |

「貴腐ぶどう」とは、特別なカビの働きで水分が抜け、糖分がぎゅっと濃くなったぶどうのことです。ベーレンアウスレーゼやトロッケンベーレンアウスレーゼは、とても甘く、デザートワインとして楽しまれます。ドイツワイン協会は、トロッケンベーレンアウスレーゼはどの年でも作れるわけではない、としています（[ドイツワイン協会：プレディカート](https://www.deutscheweine.de/qualitaetstandard/449/pr%C3%A4dikate)）。

## ラベルの読み方（2）：甘さを表す言葉

注意したいのは、プレディカートは「ぶどうの熟し方」を表すもので、**ワインの甘さそのものではない**ことです。ドイツワイン協会によると、アウスレーゼでも、糖分を残さずに発酵させて辛口に仕上げることがあります（[ドイツワイン協会：味の表示](https://www.deutscheweine.de/wein-probieren/195/geschmacksrichtungen)）。

ワインの甘さは、ラベルに書かれた次のような言葉で分かります（[ドイツワイン協会：味の表示](https://www.deutscheweine.de/wein-probieren/195/geschmacksrichtungen)）。

| ラベルの言葉 | 意味 | 残っている糖分の目安（1リットルあたり） |
| --- | --- | --- |
| トロッケン（trocken） | 辛口 | 4グラムまで（酸味とのバランスによっては9グラムまで） |
| ハルプトロッケン（halbtrocken） | やや辛口 | 12グラムまで（酸味とのバランスによっては18グラムまで） |
| リープリッヒ（lieblich） | やや甘口 | 45グラムまで |
| ズース（süß） | 甘口 | 45グラムを超える |

辛口が好きなら「trocken」、食事に合わせやすいやや辛口なら「halbtrocken」を探してみてください。スーパーのワイン売り場でも、この言葉がラベルの目立つところに書かれていることが多くあります。

## ワインを楽しむヒント

1. **秋はワイン祭りの季節**：9月から10月にかけて、ぶどうの産地の村々でワイン祭りが開かれます。地元のワインを少しずつ試せる、楽しい催しです。
2. **できたての「新酒」も**：秋には、発酵中の甘く濁ったぶどうの飲み物「フェーダーヴァイサー（Federweißer）」が出回ります。アルコールを含むので、飲みすぎに注意してください。
3. **ワイン農家を訪ねる**：多くのワイン農家（Weingut）は、試飲と直売をしています。気に入ったワインを、生産者から直接買う楽しみがあります。
4. **ドイツのビールとの飲み比べも**：ドイツのビールの話は「[ドイツの「ビール純粋令」とは？](/germany/ja/events/columns/german-beer-purity-law/)」で紹介しています。

ドイツでは、ビールやワインは16歳から購入・飲酒できます。お酒は適量を守り、飲んだら運転しないでください。

ラベルのドイツ語が少し読めるようになると、ワイン売り場はぐっと楽しい場所になります。次の週末は、リースリングのボトルを1本選んで、どの産地の、どんな段階のワインなのか、ラベルを眺めてみてはいかがでしょうか。
