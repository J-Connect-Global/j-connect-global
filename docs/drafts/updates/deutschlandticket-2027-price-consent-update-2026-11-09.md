## 更新する理由

現行記事はDBの既存契約に関する11月30日の回答期限を説明している。2026年11月5日公表の連邦政府「Deutschlandticket：質問と回答」ページは、2027年1月から66.80ユーロになることに加え、多くの契約は自動調整される一方、一部の契約では利用者の同意が必要で、その場合は交通事業者が対象者に連絡すると説明している。連絡がないことだけを根拠に自動継続を断定せず、購入先の契約画面・メールも確認する。全国共通の期限と誤読されないよう、DBの期限と全国的な説明を並べて示す。

## 追加する本文案

連邦政府も2026年11月5日公表の公式FAQで、Deutschlandticketは2027年1月1日から月額66.80ユーロになると説明しています。交通事業者から継続への同意を求める連絡が届いた場合は、その事業者の期限までに手続きが必要です。一方、事業者から連絡がない場合は、新料金で自動的に継続されると連邦政府は案内しています。

したがって、2026年11月30日を全ての利用者に共通する全国一律の回答期限と考えないでください。本文で説明している11月30日はDBの対象契約に関する期限です。Rheinbahn、KVB、VRR内の別事業者、大学経由の学生向け券などは、実際の販売元から届くメール、アプリ、契約者ページの案内を優先してください。

## 2026-11-09 DB FAQの追加照合：契約区分とJobticketの未確認点

DBの最新FAQを再確認した結果、既存契約と新規契約の違いは明確だが、Jobticketの例外は同FAQだけでは確認できない。本文を実装する際は、次のように区別する。

| 対象 | 2027年の継続手続き |
| --- | --- |
| 2026年10月14日までにDBで購入した既存契約 | 契約者本人が2026-11-30までに66.80ユーロと追加運賃条件への同意または解約を回答。回答がなければ2026-12-31で終了 |
| 2026年10月15日以降にDBで購入した契約 | 購入時と注文確認で新価格・追加条件を通知済みのため、別途同意は不要。自分で解約しない限り新条件で継続 |
| DBのJobticket | 原則2026-11-30までに回答。2027年の月額は最大63.46ユーロから個別の勤務先補助を差し引く。勤務先が月額を全額負担し、DBとの枠組み契約を維持する場合は本人の同意不要。2026-10-15以降の注文も別途同意不要 |
| DB以外の交通事業者から購入した契約 | DBの11月30日期限を流用しない。連邦政府FAQは、同意が必要な場合は交通事業者が対象者に連絡すると説明している。事業者から連絡がない場合の扱いも、購入先の契約画面・メール・アプリで確認する |

追加で明記する実務上の注意：

- DBのFAQは、同意・解約の操作を契約者本人（注文者）が行うよう案内している。家族が利用者で、別の人が契約者なら、契約者に確認する。
- 11月30日までに回答せず終了扱いになったDB契約は、2026年12月31日まではAbo PortalまたはDB Navigatorから再有効化できる。12月31日を過ぎた後は、2027年分を新規購入する必要がある。
- DBの法人向けFAQは、2027年のJobticket月額を最大63.46ユーロ（個別の勤務先補助を差し引く前）と明記している。これは従業員の固定負担額ではない。勤務先が月額を全額負担し、DBとの枠組み契約を維持する場合は本人の同意不要。独自に一律の本人負担額を算出しない。
- DB Regioの追加運賃条件は、2027年1月1日以降の将来の価格変更について、利用者の都度同意を不要にする趣旨。今回の2027年価格・条件への既存契約者の同意手続き（11月30日まで）とは区別する。
- 2026年10月15日以降の購入に関する例外はDBのFAQに基づく。全国の他事業者の購入日・同意方法へ一般化しない。
