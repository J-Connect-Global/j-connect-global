# ドイツの9月物価は3.3％上昇｜2023年12月以来の高さ、エネルギーが14.9％上昇

ドイツ連邦統計局は2026年10月13日、9月の消費者物価が前年同月比で3.3％上昇したと発表しました。8月の2.9％からさらに伸びが高まり、2023年12月以来の高い水準です。

このニュースでは、ドイツで暮らす方に向けて、今回の物価上昇の中身を整理します。何が値上がりして何が値下がりしたのか、10月から始まった燃料税の一時的な引き下げがどう関係するのか、そして家計で気をつけたい点が分かるはずです。

## 今回の発表で分かったこと

連邦統計局によると、2026年9月の消費者物価指数は前年同月比で**3.3％**上昇しました。9月30日に発表された速報値と同じ数字です（[連邦統計局：9月の確定値](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/10/PD26_364_611.html)）。

伸び率は、7月が2.8％、8月が2.9％、9月が3.3％と、3か月続けて高まりました。連邦統計局は、3％を超えたのは今年初めてで、2023年12月以来の高さだとしています（同上）。

| 項目（前年同月比） | 2026年9月 |
| --- | --- |
| 物価全体 | +3.3％ |
| エネルギー | +14.9％ |
| 食品 | +0.4％ |
| 物（財）全体 | +3.8％ |
| サービス | +2.7％ |
| 食品とエネルギーを除いた物価（コア） | +2.4％ |

（出典：[連邦統計局](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/10/PD26_364_611.html)）

## 物価を押し上げたのは「エネルギー」

今回の物価上昇の中心は、エネルギーです。エネルギーの価格は前年同月比で**14.9％**上昇し、3か月続けて伸びが高まりました（[連邦統計局](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/10/PD26_364_611.html)）。

ただし、エネルギーの中でも動きは分かれています。

- **値上がりしたもの**：暖房用の灯油と、ガソリン・軽油などの自動車の燃料。前の月からの上昇も、主にこの2つによるものでした。
- **値下がりしたもの**：電気（−5.5％）、ガス（−2.8％）、地域暖房（−1.0％）は、前の年より安くなっていました。

つまり、車をよく使う家庭や、灯油で暖房している家庭ほど、値上がりを強く感じやすい状況です。一方で、電気やガスで暖房している家庭では、エネルギーの上昇をそれほど感じないかもしれません。

## 食品はほぼ横ばい、でも品目によって大きな差

食品全体の値上がりは**0.4％**にとどまりました。ただし、品目ごとに見ると、動きは大きく違います（[連邦統計局](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/10/PD26_364_611.html)）。

- **値上がり**：卵（＋15.2％）、生鮮野菜（＋12.0％）、魚（＋4.5％）
- **値下がり**：食用の油脂（−15.0％）、乳製品（−5.5％）、生の果物（−4.9％）

野菜や卵をよく買う家庭では、「食品はほぼ横ばい」という数字ほど楽になった実感はないかもしれません。全国の平均と自分の家計の実感がずれる理由は、8月の記事「[ドイツの8月物価は2.9％上昇](/germany/ja/events/news/germany-inflation-august-2026/)」でも紹介しています。

## 10月からの燃料税の引き下げ

ガソリンや軽油の値上がりを受けて、連邦議会は2026年9月25日、燃料にかかるエネルギー税を一時的に引き下げることを可決しました（[連邦議会](https://www.bundestag.de/dokumente/textarchiv/2026/kw39-de-versicherung-aufsicht-1216898)）。

連邦政府によると、**2026年10月1日から12月31日まで**、ガソリンと軽油のエネルギー税が1リットルあたり約14セント（14.04セント）下がります。付加価値税の分も合わせると、1リットルあたり約17セントの負担軽減になる計算です（[連邦政府：2026年10月の法改正](https://www.bundesregierung.de/breg-de/aktuelles/gesetzliche-neuregelungen-oktober-2026-2454624)）。

連邦統計局は、この引き下げは10月1日からのもので、9月の数字にはまだ表れていないとしています（[連邦統計局](https://www.destatis.de/DE/Presse/Pressemitteilungen/2026/10/PD26_364_611.html)）。10月以降の物価の数字で、燃料の値段がどれだけ下がるかが注目されます。ただし、税金が下がった分がすぐにガソリンスタンドの価格に反映されるとは限りません。

## 家計で気をつけたいこと

1. **暖房の燃料を確認**：灯油で暖房している場合は、値上がりの影響を受けやすくなっています。冬の暖房の使い方は「[ドイツの冬のカビ・結露対策](/germany/ja/events/columns/germany-winter-mold-ventilation/)」も参考にしてください。
2. **燃料は年内が安くなる可能性**：燃料税の引き下げは12月31日までです。1月からは元の税率に戻る予定なので、年明けに給油代が上がる可能性があります。
3. **電気・ガスの契約を見直す**：電気とガスの価格は前年より下がっています。契約の更新時期が近い場合は、料金を比べてみる価値があります。
4. **来年の負担もあわせて考える**：2027年は健康保険料などの変更もあります。「[【2027年1月から】ドイツで何が変わる？](/germany/ja/events/news/germany-january-2027-changes/)」で確認しておきましょう。

10月の物価の速報値は、10月の終わりに連邦統計局から発表される予定です。
