# ドイツの引っ越しチェックリスト｜退去・入居・住所変更の順番

ドイツ国内の引っ越しは、旧居の解約条件を確認し、引渡し日の記録を残し、新住所の登録・契約先への連絡を進める順番で整理できます。この記事は、退去・入居を控えた人が「いつ、何を、どこまで終えればよいか」を確認するチェックリストです。住民登録の期限と、家具処分・ごみ回収などの生活準備を分けて、抜けを防ぎます。

まだ物件が決まっていない人は[賃貸・家探しの全体ガイド](/germany/ja/living/rent-apartment-germany/)、契約や信用証明から確認したい人は[住まい・引っ越しの案内](/germany/ja/living/routes/housing/)へ進んでください。

## 引っ越し前後のチェックリスト

| 時期 | やること | 完了の目安 |
| --- | --- | --- |
| 新居契約前後 | 旧居の解約条件と新旧の家賃が重なる期間を確認 | 入居・退去の日程と費用を把握した |
| 引っ越し前 | 電気・通信の移転、郵便転送、粗大ごみの回収を手配 | 受付確認と開始・回収日を保存した |
| 旧居の引渡し | 鍵の本数、傷、メーター番号・数値を記録 | 引渡し記録と写真を双方で確認した |
| 新居の引渡し | 入居確認書、郵便受け、ごみ置場を確認 | 書類と建物ルールを受け取った |
| 実際の入居後 | 住民登録と契約先への住所変更 | 役所の手続きと民間契約を別々に確認した |
| 後日 | 最終請求・敷金精算の照合 | 不明な請求に問い合わせた |

日程は家庭ごとの準備目安です。法律・契約上の期限と同じではありません。各手続きの条件は以下で確認してください。

### 法律上の期限と準備の目安

| 項目 | 期限・条件 | 保存するもの |
| --- | --- | --- |
| 旧居の通常解約 | 一般的な無期限住宅賃貸では、月の第3営業日までの到着で翌々月末終了が基本 | 署名した通知の控え、相手に届いた記録 |
| 新居の住民登録 | 原則、実際の入居から2週間以内 | 登録完了後の確認書。予約だけで完了とはしない |
| 入居確認書 | 住居提供者が登録期限内に発行。届かなければ役所へ速やかに連絡 | 家主等からの確認書、発行依頼の記録 |
| 電気 | 希望会社で入居日から使うなら使用開始前に契約を整える | 新旧それぞれの開始・終了確認と検針写真 |
| 自宅の通信 | 移転可能性を早めに確認。同じサービスが提供できない場合の特別解約は1か月の通知期限 | 移転回答、解約確認、機器返送記録 |

電気や通信を「何週間前まで」と一律の法律上の期限に置き換えないでください。契約条件と工事・手配期間を考慮し、日程が決まった時点で確認します。

![旧居解約から契約移転、引っ越し当日の記録、入居後の住民登録、住所変更までの時系列](/assets/images/living/moving-timeline.svg "ドイツ国内の引っ越しは、旧居・新居・住所変更の三つに分けて考える")

## ドイツの引っ越しは、二つの住居をつなぐ作業

引っ越し当日だけを予定しても、住居の変更は完了しません。旧居では解約通知、退去時の状態確認、メーターの精算があり、新居では鍵の受取、入居時の記録、住民登録があります。その間に電気や通信の契約が重なるため、しばらく二つの住所を管理する期間が生まれます。

ドイツでは、口頭の合意よりも、日付、写真、書面の記録が後の精算を支えます。これは家主を疑うためではなく、入居時からあった傷と自分が付けた傷を分け、双方が同じ状態を共有するための習慣です。

## 最初に押さえる五つの時点

| 時点 | その時点で確定させること |
| --- | --- |
| 新居を決めたとき | 入居日、家賃、敷金、住民登録の可否 |
| 旧居を解約するとき | 契約上の通知期限、退去日、後任入居者の扱い |
| 引っ越し前 | 電気・通信の移転、郵便転送、運搬方法 |
| 鍵を受け渡す日 | 部屋の状態、鍵の本数、メーター数値 |
| 新居へ実際に入った後 | 二週間以内の住民登録と各契約先への住所変更 |

賃貸借の通常解約は、借主側では原則として約三か月前の通知になります。ただし、期限付き契約、最低利用期間、家具付きの一室などでは条件が違うことがあります。引っ越し日を決める前に契約書の解約条項を読みます。

## 旧居を閉じる

### 解約通知は「届いた日」で考える

住宅賃貸の解約は法律上の書面形式が必要です。通常は契約者本人が署名した紙を相手へ届けます。普通のメール、WhatsApp、署名を撮影したPDFを送るだけでは、この形式を満たしません。電子署名を使う場合は法定要件が別にあるため、一般的な送信方法と混同しないでください。

通知には契約者、対象物件、解約の意思、希望終了日を明記します。複数人で契約している場合は、契約者全員による解約・署名の扱いも確認してください。宛先と受取権限を確認し、控えと到着を証明できる記録を残します。

通常の無期限住宅賃貸では、月の第3営業日までに相手へ届くと、翌々月末の終了になるのが基本です。例えば11月末に終えたいなら、原則9月の第3営業日までの到着が基準になります。「投函日から3か月」「発送していればよい」という意味ではありません。休日、契約上の解約制限、特別な賃貸形態がある場合は、具体的な日付を専門相談で確認します。

次の入居者を自分で見つければ必ず早く解約できる、という全国共通の権利はありません。早期終了の合意がある場合は、終了日と残る支払いを書面で確認します。連絡表現は[大家・不動産会社へのドイツ語](/germany/ja/learn-german/landlord-housing-email-phrases/)を参照できますが、メール文例は正式な解約書面の代わりにはなりません。

### 退去時の状態を合意する

壁の塗装や清掃をどこまで行うかは、契約と住居の状態によって異なります。「ドイツでは退去時に必ず白く塗る」と一律には言えません。大きな修繕費が関わる場合や契約条項に疑問がある場合は、借家人協会や消費者相談窓口へ契約書を見せて確認します。

鍵を返す日は、家主または管理会社と部屋を回り、**引渡し記録（Übergabeprotokoll）**を作ります。日付、鍵、部屋の状態、メーター数値を記し、双方が写しを持ちます。写真は部屋全体と傷の位置関係が分かるように撮り、元のデータを保管します。

記録に残す項目は、旧居でも新居でも共通です。

- 住所、住戸、日時、立会人、鍵の種類と本数
- 各部屋の状態、傷・汚れの場所、写真の対応関係
- 電気・ガス・水道などのメーター番号と数値
- 引き継ぐ設備と、修理が必要な点
- 合意した対応、写しの受取り、精算の連絡先

納得していない損害や金額を「すべて了承した」と読める欄へ署名しないでください。事実の記録と、誰が費用を負担するかの合意は分けて確認します。

![ドイツの住居でメーターと部屋の状態を記録しながら鍵を引き渡す様子](/assets/images/living/apartment-utility-setup-editorial-v1.webp "AI生成の編集イメージ。実際の住居や引渡しの写真ではありません。")

### 敷金の返還には時間がかかることがある

敷金は、鍵を返した日に必ず全額戻るものではありません。家主は損傷や未払いを確認し、暖房・共益費の年次精算が残る場合は、合理的な範囲を留保することがあります。

返還先の銀行口座と新住所を家主へ知らせ、引渡し記録と最終家賃の支払記録を保管します。長期間説明なく返還されない場合は、書面で内訳と時期を問い合わせます。

「6か月たてば必ず全額返る」といった一律の期限で判断しないでください。最後の家賃の支払いと敷金返還も別であり、自分の判断で家賃の引き落としを止めると未払いになります。返還額に差がある場合は、控除項目、請求書、留保額の根拠を確認します。

## 新居を始める

### 鍵を受け取る前後に記録する

新居でも、家具を運び込む前に部屋の状態を見ます。床、壁、窓、水回り、備え付けキッチンに目立つ傷があれば、写真と引渡し記録に残します。電気、ガス、水道、暖房のメーターは、番号と数値が同じ写真に入るように撮ると、契約先へ伝えやすくなります。

管理会社から、ごみ置場、自転車置場、洗濯室、地下室、静かな時間など建物のルールを聞きます。これらを最初に知ると、隣人との不要な摩擦を避けられます。

### 家具処分と新居のごみ回収を別々に準備する

不要な家具は、退去日直前では希望日に収集されないことがあります。居住地の粗大ごみ案内で、対象品目、申込み、出す場所と時間を確認してください。道路へ先に出してから申込みをするのは避けます。

新居では、段ボールを折り畳む場所と回収日を確認します。デュッセルドルフの黄色い資源容器は、包装以外の対象製品も受け入れるため、他都市から転居した人は以前の分別方法との違いにも注意してください。[ごみ分別・住所別収集日の調べ方](/germany/ja/living/germany-waste-sorting-guide/)から公式窓口へ進めます。

### 入居確認書を受け取る

家主は、住民登録に必要な入居確認書を、法律上の期限内に発行する義務があります。賃貸契約書だけでは通常代用できません。発行されない場合は、放置せず住民登録窓口へ事情を伝えます。

正式名称は**入居確認書（Wohnungsgeberbestätigung）**です。通常は家主や権限を持つ管理会社、転貸なら住居を提供する主契約者から受け取り、新住所の住民登録窓口へ提出します。入居日、住所、入居者名、住居提供者等の情報を確認してください。登録後に役所から受け取る登録確認書とは別の書類です。

## 住民登録は実際の入居から二週間以内

新居へ実際に入った人は、原則として二週間以内に新住所を登録します。ドイツ国内で新住所へ移る場合、通常は旧住所を別に抹消する必要はなく、新しい登録によって更新されます。ドイツを離れ、国内に別の住居を持たない場合は、退去の届出が必要です。

予約枠が二週間以内に取れない自治体もあります。自治体の案内に従って早めに予約し、予約日と取得日が分かる確認を残します。必要書類とオンライン手続きの有無は[住民登録ガイド](/germany/ja/living/anmeldung-guide/)で確認してください。

### デュッセルドルフ・近郊で窓口を選ぶ

- 市内から市内の転居：[住所変更の案内](https://service.duesseldorf.de/suche/-/vr-bis-detail/dienstleistung/208/show)を確認する。
- Erkrathなど他の市からデュッセルドルフへ：[市外からの住所登録](https://service.duesseldorf.de/suche/-/vr-bis-detail/dienstleistung/227/show)を確認する。
- デュッセルドルフから別の市へ：新住所の市の窓口へ届け出る。近隣でも担当自治体は変わる。

市内転居では日本のパスポートなどの本人確認書類と入居確認書を用意し、代理人利用や家族一括の条件も確認します。オンライン申請は利用できる本人確認手段や対象者に条件があるため、日本のパスポートや滞在許可証があれば必ず完結できるとは考えず、自治体の案内から適用条件を確認してください。

![新居の書類と住所変更先を確認する日本人居住者](/assets/images/living/japanese-resident-paperwork-editorial-v1.webp "AI生成の編集イメージ。実在の人物や手続きの写真ではありません。")

## 住民登録だけでは変わらない住所

役所で住所を更新しても、民間の契約先へ自動的に共有されるわけではありません。自分に関係する相手を四つに分けると漏れを見つけやすくなります。

### 公的な相手

外国人局、税務署、家族給付、年金、車両登録などです。手続きによって住民登録情報が参照される場合もありますが、進行中の申請があるなら担当窓口へ直接知らせます。滞在許可証の住所欄の扱いも自治体で確認します。

### 仕事と学業

勤務先、大学、学校、保育先へ、新住所と有効日を伝えます。給与、税務書類、在籍証明などが旧住所へ送られないようにします。

### お金と保険

銀行、健康保険、賠償責任保険、家財保険、自動車保険などです。住居の広さや地域により保険条件が変わる場合もあるため、単なる郵送先変更で済むか確認します。

### 日常の契約

電気、通信、放送負担金、通販、定期購読などです。郵便転送は取りこぼしを減らす補助であり、契約先の住所変更そのものではありません。

### 住所変更先と準備する情報

| 連絡先 | 用意しておく情報・書類 | 完了を確認する方法 |
| --- | --- | --- |
| 住民登録窓口 | 本人確認書類、入居確認書、必要なら家族・代理の書類 | 新住所が記載された登録確認書を保管 |
| 銀行・保険 | 顧客番号、新住所、有効日。必要とされた証明 | 会員ページや受付回答で反映を確認 |
| 勤務先・学校・保育先 | 新住所、転居日、必要なら緊急連絡先 | 人事・事務担当の更新確認 |
| 外国人局・進行中の公的申請 | 申請番号、在留情報、新住所、必要なら登録確認書 | 担当窓口へ連絡し、管轄変更の要否を確認 |
| 電気・ガス | 契約番号、新旧住所、日付、検針値・メーター番号 | 新旧の開始・終了日を照合 |
| 自宅の通信 | 契約番号、新住所、希望日、回線設備への立入り条件 | 移転注文・工事日・料金を確認 |
| 放送負担金 | 自分の登録番号。合流なら既存支払者の登録番号も | 変更または重複整理の回答を保管 |

すべての相手へパスポートのコピーを送る必要はありません。会員ページなど正式な経路を使い、相手が必要とする情報だけを提出します。

## 電気とガス

引っ越し前に、現在の契約を新居へ移せるか、旧居で終了させるかを供給会社へ確認します。契約を放置すると、旧居と新居の両方で請求が発生する可能性があります。

電力会社の技術的な「24時間切り替え」は、既存契約を24時間で解約できる制度ではありません。希望会社で入居日から供給を受けたい場合は、電気を使う前に契約を整えます。未契約で使用を始めると通常は地域の基本供給の契約が成立し、その後で選んだ会社へ過去にさかのぼって移すことはできません。これは電気の案内であり、ガスの手続きまで同じと決めつけないでください。

旧居の退去時と新居の入居時に、メーター番号、数値、日付を記録します。新居で契約が決まっていなくても電気が使える場合、地域の基本供給に自動的に入っていることがあるため、請求元を確認してください。

詳しい契約の見方は[電気・インターネット契約ガイド](/germany/ja/living/electricity-internet-contracts-germany/)にまとめています。

## インターネットと携帯電話

通信契約は、同じ条件のサービスを新住所で提供できるなら、そのまま移転するのが原則です。提供できない場合は、一か月の期限で特別解約できる可能性があります。回線工事や技術者の訪問には時間がかかるため、入居日が決まった時点で可否を調べます。

「引っ越すから必ず無料で解約できる」とは限りません。新住所で同等サービスを提供できるかどうかと、契約上の移転手数料を確認します。

## 放送負担金

放送負担金は住居単位です。自分が支払者として転居する場合は住所変更を行い、すでに別の人が支払う住居へ入る場合は、その人の登録番号を使って自分の重複登録を整理します。住民登録や郵便転送だけでは変更されません。

手続きの考え方は[放送負担金ガイド](/germany/ja/living/rundfunkbeitrag-guide/)にまとめています。

## 家族、車、ペットがいる場合

子どもの学校や保育先は、転居先によって担当区域や送迎時間が変わります。転校が必要か、在籍を続けられるかを早めに相談します。保育先は空きに限りがあるため、新住所が決まった時点で新しい自治体の窓口へ連絡します。

車は登録住所、自動車保険、住民用駐車許可を確認します。犬を飼っている場合は、自治体の犬税、登録、州の飼育規則が転居先でも引き継がれるかを確認します。

## 引っ越し後、一度だけ行う見直し

一か月ほど経ったら、旧住所宛ての郵便、旧居の引き落とし、新居の請求をまとめて見ます。銀行明細で二重請求がないか、電気・通信の開始日が正しいか、敷金返還の連絡先が届いているかを確認します。

この一度の見直しで、住所変更漏れと契約の重複の多くを発見できます。旧口座や旧メールアドレスをすぐ閉じず、精算が終わるまで連絡を受けられる状態にしておくと安心です。

## まとめ

ドイツ国内の引っ越しは、荷物を運ぶ日より前から始まり、旧居の精算が終わるまで続きます。旧居を記録して閉じ、新居の状態を記録して住民登録を行い、生活上の相手へ新住所を知らせる、という三段階で考えると全体を見失いません。書面と写真を残す文化を味方にし、二つの住居が重なる短い期間を落ち着いて管理してください。

## よくある疑問

### 役所へ住所変更をすれば、銀行や保険も変わりますか

自動で全部変わるわけではありません。銀行、保険、勤務先、通信、放送負担金などへそれぞれ届け出てください。郵便転送も住所変更届の代わりにはなりません。

### 入居確認書をまだ受け取れていません

家主・管理会社へ発行を依頼し、間に合わない場合は住民登録窓口へ速やかに連絡します。書類がないため予約も連絡もせず放置する、という対応は避けてください。

### インターネットは転居すると無料解約できますか

必ずではありません。現契約のサービスを新住所でも提供できるなら、移転して継続するのが基本です。提供できない場合の特別解約と、契約満了による解約を分けて事業者に確認します。
