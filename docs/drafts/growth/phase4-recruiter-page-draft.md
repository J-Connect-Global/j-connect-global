# 日本人を採用するときの滞在許可と手続き｜採用担当者向けガイド

ドイツで日本人を採用するとき、会社側が知っておきたい滞在許可の種類、年収の条件、採用から入社までの期間をまとめました。日本国籍の人は、ビザなしで入国してからドイツ国内で滞在許可を申請できるため、ほかの国の人より手続きが短くなることがあります。

## まず結論
- 日本国籍の人は、就労令第26条第1項により、職種や会社の所在地を問わず、連邦雇用庁の同意を受けて働ける（同意には、ドイツ・EUの求職者を優先するかの審査が付く）。滞在許可は滞在法第19c条（2026年11月14日に条文を確認）。
- 大学卒で年収の条件を満たす場合は、EUブルーカードも選べる。2026年の年収の条件は原則5万700ユーロ、人手が足りない職業などは4万5,934.20ユーロ（当サイトのEUブルーカードの記事、2026年10月29日確認）。
- 入社までの期間は、外国人局の予約の取りやすさで大きく変わる。

## 許可の種類
| 許可 | 合う人 | 会社側で用意するもの |
| --- | --- | --- |
| 第19c条（日本国籍など特定の国籍） | 職種・学歴を問わない採用。連邦雇用庁の同意（優先審査つき）が必要 | 雇用契約書、仕事内容と労働条件の説明（同意の審査に使う） |
| EUブルーカード（第18g条） | 大学卒・年収の条件を満たす専門職 | 雇用契約書、年収の証明 |
| 専門人材（第18a・18b条） | 職業資格・大学卒の専門人材 | 雇用契約書、資格の認定 |
| 企業内転勤（ICTカード） | 日本の本社からの派遣 | 派遣の契約、本社での雇用の証明 |

## 採用から入社まで（流れ）
1. 内定・雇用契約書の締結
2. 本人の入国（日本国籍はビザなしで入国できる）
3. 住民登録（入居から2週間以内）
4. 外国人局での滞在許可の申請（予約が必要）
5. 審査中の証明、または許可が出てから就労開始（許可の種類と外国人局の運用による）
