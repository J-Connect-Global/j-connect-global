# 記事の主画像（表紙画像）の差し替え手順（2026-10-29）

2026年10月21日〜29日に公開した42本の記事の主画像は、図形を組み合わせた簡単なイラストです。一覧やSNSでの見え方を良くするため、写真のようなAI生成の編集イメージに差し替えます。

## 対象

- `docs/article-image-generation-2026-10-29.json` の42件（新しい順）
- 各項目には、生成用のプロンプト（英語）、代替テキスト、AI画像であることを示す説明文、出力先が入っています。
- 既存のAI画像（`docs/article-image-generation-2026-10-20.json`）と同じ基準です。文字・ロゴ・実在の人物は入れず、主役を中央70%に置き、240pxのサムネイルでも主題が分かる構図にします。

## 必要なもの

- 環境変数 `GEMINI_API_KEY`（Gemini APIのキー。環境設定のNetwork secretsか環境変数として登録し、新しいセッションで読み込みます）
- 必要なら `GEMINI_IMAGE_MODEL` でモデルを変更（既定は `imagen-4.0-generate-001`）

## 手順

1. 試しに数件だけ生成する

   ```
   python3 scripts/generate-cover-images.py --manifest docs/article-image-generation-2026-10-29.json --limit 3
   ```

2. 生成した画像を目で確認する。不自然な手や顔、文字のようなもの、主題とのずれがあれば、その項目のプロンプトを直して `--only <slug>` で作り直す
3. 残りをまとめて生成する（成功した項目は `status: "generated"` になり、次回は飛ばされます）
4. `git add -A` → `npm run build` → `npm run validate`
   - 写真はイラストよりファイルが大きいため、`content/quality-baselines/image-asset-budget.json` の上限を超える可能性があります。超えた場合は上限を引き上げ、PRに書きます。
5. 375px・1280pxで記事上部、一覧のサムネイル、スマートフォンでの切れ方を確認する
6. PR → CI → マージ → 本番の表示確認

## 注意

- 生成されたPNGの原本はリポジトリの外（既定は `/tmp/cover-raw`）に保存されます。リポジトリには入れません。
- 説明文は「AI生成の編集イメージ。…」とし、実在の施設（ケルン大聖堂、ベルリンの壁、ルール地方の炭鉱跡）は「実際の〜を撮影したものではありません」と明記しています。
- 外部の写真の作者・ライセンスをAI画像に流用しません。
