# ドイツの後払い・分割払いはどう変わる？2026年11月20日からの新ルール

2026年11月20日から、ドイツでは消費者向け融資の保護範囲が広がり、200ユーロ未満の小口ローンや短期・無利息の融資、後払い・分割払いの一部も対象になります。オンラインで後払いを選ぶ人や、小口の融資を申し込む人に向けて、対象になる契約と例外、契約前に確認すべきことを整理します。重要なのはサービス名ではなく、資金を誰が出すか、支払い猶予や手数料がどう設計されているかです。

<text></text>

**確認日：2026年11月13日／主な規定の施行日：2026年11月20日**

## まず結論

| 確認したいこと | 2026年11月20日からの扱い |
| --- | --- |
| 200ユーロ未満の小口ローン | 従来の金額による適用除外が見直され、対象になる契約が広がる |
| 3か月以内に返す短期ローン | 低コストを理由に従来は除外されていた契約も、保護の対象に含まれる |
| 無利息・無手数料の融資 | 一部の消費者信用ルールが適用される範囲が広がる |
| 後払い・分割払い | 多くの方式が対象になり得る。ただし、すべての支払猶予が対象ではない |
| 既存契約 | 原則として11月20日より前に成立した契約には旧法が継続適用される。無期限契約などには例外がある |

この改正は、2026年5月12日付の法律として同年5月18日に公布されました。消費者信用に関する主要な規定は11月20日に施行されます。法律の公布日と、消費者が新しいルールの適用を受け始める日を混同しないでください。

## どのような支払いが対象になるのか

### 対象が広がる契約

改正前の一般的な消費者ローンでは、純融資額が200ユーロ未満の契約や、3か月以内に返済し費用が少額の契約などが、一定の消費者信用ルールの適用外でした。11月20日からは、この金額・期間による除外が見直されます。

| 契約の例 | 新ルールを確認すべき理由 |
| --- | --- |
| 200ユーロ未満の小口ローン | 金額が小さいことだけで、従来の保護対象外とは限らなくなる |
| 3か月以内に返す短期ローン | 返済期間が短く、費用が少ないことだけを理由にした従来の除外が見直される |
| 無利息・無手数料の融資 | 利息がゼロでも、契約の形によって消費者保護の対象になる |
| 後払いサービス | 販売店以外の事業者が資金を立て替える方式や、分割返済を伴う方式などは、契約内容の確認が必要 |
| 分割払い | 商品代金の支払方法に見えても、実質的に融資や支払猶予に当たる場合がある |

「後払い」という広告名だけで対象かどうかは判断できません。販売店が直接支払期限を延ばしているのか、別の金融・決済事業者が立て替えているのか、利息や手数料があるのかを契約書で確認します。

### 対象外となることがある契約

法律には例外もあります。次の条件を満たす方式は、一般的な消費者ローンのルールがそのまま適用されない場合があります。

- **販売店が直接設ける短い支払猶予：** 第三者が融資や立替えをせず、販売店自身が無償で支払期限を延ばし、商品・サービスの提供後50日以内に全額を支払う方式は、一定条件のもとで対象外です。情報社会サービスを提供する大規模事業者の通信販売などでは、より短い14日以内という条件があります。
- **一定の支払猶予付きデビットカード：** 銀行・決済機関が提供し、40日以内に返済し、利息がなく、決済サービスの手数料も少額であるなど、法律所定の条件を満たすものは対象外です。
- **すでに発生した請求の無償延期：** 既存の請求を無償で支払猶予するだけの契約には、別の扱いがあります。
- **不動産関連の融資：** 住宅や土地の取得・維持を目的とする融資は、一般消費者ローンとは別の規定で扱われます。

これらは細かな条件を伴う法律上の例外です。アプリ名、カードの名称、広告の「手数料無料」という表示だけで対象外と決めつけないでください。

## 利用者に関係する主な変更

### 契約前に確認できる情報が増える

対象となる契約では、契約前に受け取る情報や説明のルールが強化されます。毎月の返済額だけでなく、総返済額、利息、手数料、返済日、支払いが遅れた場合の負担を確認してください。追加サービスがセットになっている場合は、別々に解約できるか、その場合に何が変わるかも確認します。

### 契約方法と、最初から選択された項目の扱い

一般的な消費者ローンでは、契約に必要な形式が「文字で内容を確認できる形式」に整理されます。メールや電子書面などが使われる場合がありますが、画面に表示された内容を保存し、契約相手と条件を確認することが重要です。

また、最初からチェック済みの追加オプションに同意したことにする方式は認められません。追加サービスや保険などを付ける場合は、何に同意するのかを確認して自分で選択します。

### 自動審査でも、人による確認を求められる場合がある

対象となる一般消費者ローンの信用力審査で個人データの自動処理が使われた場合、借り手は人による介入を求められます。審査の仕組みやリスクについて説明を受け、自分の事情を伝え、審査と融資判断の見直しを求める権利が定められています。

審査に通ることが保証されるわけではありません。自動審査で断られた場合は、通知に記載された手続きに従って、人による確認と判断理由の説明を求められるか確認してください。

### 支払いが難しくなったときの対応

対象となる一般消費者ローンでは、返済に困難が生じた人を、利用しやすい債務相談サービスへ案内する義務や、状況に応じて強制執行の前に返済条件の見直しを検討する義務が設けられます。返済期間の延長、一定期間の支払猶予、金利の引下げなどが例として挙げられています。

これは、支払いをしなくてよいという意味でも、必ず返済延期が認められるという意味でもありません。支払いが難しいと分かった時点で、期限を過ぎる前に事業者へ連絡し、利用できる相談窓口と返済方法を確認してください。

## 11月20日より前に結んだ契約はどうなる？

法律の経過規定では、原則として11月20日より前に存在していた消費者ローン、支払猶予、関連する商品・サービスの契約などには、旧法を引き続き適用します。ただし、無期限の一般消費者ローンなどには一部の新しい規定を適用する例外があります。

そのため、既存の後払い契約がすべて11月20日に自動的に新ルールへ切り替わる、と考えるのは正確ではありません。契約日、契約期間、融資・支払猶予の提供者を確認してください。契約内容が分からない場合や、すでに支払いをめぐる争いがある場合は、消費者相談窓口や法律専門家に相談してください。

## 申し込む前に確認すること

後払い・分割払いを選ぶ前に、次の点を確認すると、支払額や返済日を見落としにくくなります。

1. **誰と契約するのか：** 販売店自身なのか、別の金融・決済事業者なのか。
2. **総額はいくらか：** 商品の現金価格、利息、手数料、追加サービス料を合わせた金額。
3. **いつ、何回払うのか：** 初回支払日、各回の金額、最終支払日、自動引落しの有無。
4. **遅れたら何が起きるか：** 遅延費用、利息、督促、契約解除の条件。
5. **返品・キャンセル時はどうなるか：** 商品の返品と融資・支払契約の扱いが連動するか。
6. **契約内容を保存したか：** 申込画面、契約条件、支払予定表、事業者からのメールを保管する。
7. **審査に納得できない場合の窓口はどこか：** 自動審査の人による確認を求める手続きが示されているか。

SCHUFAなどの信用情報と、銀行・決済事業者が行う個別の返済能力審査は同じものではありません。信用情報の確認方法は[ドイツのSCHUFAガイド](/germany/ja/living/schufa-guide/)で説明しています。口座やカードの基本は[ドイツの銀行口座ガイド](/germany/ja/living/bank-account-germany/)を参照してください。

## 契約書で見かける言葉

| ドイツ語 | 日本語での意味 |
| --- | --- |
| Kauf auf Rechnung | 請求書払い。商品を受け取った後に代金を払う方式 |
| Ratenzahlung | 分割払い |
| Zahlungsaufschub | 支払猶予 |
| Kreditwürdigkeitsprüfung | 返済能力・信用力の審査 |
| Gesamtkosten | 利息や手数料を含む総費用 |
| Widerrufsrecht | 法律や契約で認められる撤回権 |

言葉の意味だけで契約の法的な分類は決まりません。契約書に書かれた提供者、支払い条件、手数料、第三者の関与を合わせて確認します。

## よくある疑問

### すべての後払いサービスが新しい法律の対象になりますか？

いいえ。多くの後払い・分割払いが対象になり得ますが、販売店が直接設ける無償の短期支払猶予や、条件を満たす支払猶予付きデビットカードなどの例外があります。ブランド名だけで判断せず、契約の仕組みを確認してください。

### 11月20日より前に申し込んだ後払いも、新ルールに変わりますか？

原則として、11月20日より前に存在していた契約には旧法が継続適用されます。無期限契約などには例外があるため、契約日と契約の種類を確認してください。

### 新しいルールで、延滞料金や返済義務がなくなりますか？

いいえ。支払義務がなくなる制度ではありません。返済が難しい場合の相談や返済条件の見直しに関する保護が強化されますが、個別の条件と適用範囲があります。

### SCHUFAの点数は自動的に上がりますか？

いいえ。新しい規則はスコアの作成・利用や自動審査の手続きに関するもので、点数の自動上昇や過去の登録情報の一括削除を約束するものではありません。誤った情報があれば、登録内容を確認して訂正を求めます。
